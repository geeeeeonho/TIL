# 총정리

| 목적      | 문법              | 예시                |
| ------- | --------------- | ----------------- |
| 그룹별 요약  | `groupby()`     | 요일별 팁 평균          |
| 여러 통계   | `.agg()`        | 평균·범위·개수 동시 계산    |
| 직접 계산   | `lambda`, `def` | 최댓값−최솟값, 비율       |
| 여러 열 계산 | `.apply()`      | 가중평균              |
| 격자 요약   | `pivot_table()` | 카테고리×등급 평균표       |
| 빈도표     | `crosstab()`    | 프로그램×등급 방문 수      |
| 키로 병합   | `merge()`       | 운동 기록에 프로그램 정보 추가 |
| 표 연결    | `concat()`      | 월별 데이터 쌓기         |

## `groupby` · `agg`

```python
# 요일별 팁 평균
df.groupby('day')['tip'].mean()

# 카테고리×회원등급별 여러 통계
report = gym_full.groupby(
    ['카테고리', '회원등급']
).agg(
    평균운동시간=('운동시간', 'mean'),
    운동시간범위=('운동시간', lambda s: s.max() - s.min()),
    주요시간대=('시간대', lambda s: s.mode().iloc[0]),
    방문건수=('운동시간', 'size')
)
```

```text
groupby → 기준별로 묶음
agg → 그룹별 여러 결과 생성
```

## `apply`

여러 열을 함께 사용해야 할 때 사용함.

```python
def weighted_tip(g):
    return np.average(g['tip'], weights=g['size'])

df.groupby('day').apply(weighted_tip)
```

## `pivot_table`

그룹 결과를 행×열 격자로 표현함.

```python
gym_full.pivot_table(
    index='카테고리',
    columns='회원등급',
    values='운동시간',
    aggfunc='mean'
)
```

```text
행 → 카테고리
열 → 회원등급
값 → 평균 운동시간
```

## `crosstab`

범주 조합별 개수나 비율을 계산함.

```python
# 방문 건수
pd.crosstab(gym['프로그램'], gym['회원등급'])

# 프로그램별 회원등급 비율
pd.crosstab(
    gym['프로그램'],
    gym['회원등급'],
    normalize='index'
)
```

## `merge`

키가 같은 다른 표의 정보를 옆에 붙임.

```python
gym_full = gym.merge(
    program_info,
    on='프로그램',
    how='left'
)
```

```text
gym          → 왼쪽 표, 모든 운동 기록 유지
program_info → 오른쪽 표, 카테고리·난이도·정원 추가
```

```python
왼쪽표.merge(오른쪽표, on='키', how='left')
```

* `inner`: 양쪽 공통 키만 유지
* `left`: 왼쪽 표 전체 유지
* `right`: 오른쪽 표 전체 유지
* `outer`: 양쪽 모든 키 유지

## `concat`

표를 그대로 위·아래 또는 옆으로 연결함.

```python
# 아래로 쌓기
pd.concat([january, february], ignore_index=True)

# 옆으로 붙이기
pd.concat([left_cols, right_cols], axis=1)
```

```text
concat(axis=0) → 같은 열끼리 아래로 쌓음
concat(axis=1) → 같은 인덱스끼리 옆으로 붙임
```

## 선택 기준

```text
그룹별 평균·합계       → groupby
여러 통계 동시 계산    → agg
여러 열로 복잡한 계산  → apply
보기 좋은 격자표       → pivot_table
조합별 개수·비율       → crosstab
키가 같은 정보 결합    → merge
같은 구조의 표 연결    → concat
```
