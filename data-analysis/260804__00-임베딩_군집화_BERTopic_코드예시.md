### 한국어 토크나이저 준비

Kiwi 형태소 분석기를 이용해 명사만 추출.

```python
kiwi = Kiwi()
```

일반 불용어 목록 불러오기:

```python
with open("data/stopwords_ko.json", encoding="utf-8") as f:
    STOPWORDS_GENERAL = set(json.load(f))
```

현재 리뷰 데이터에서만 불필요한 도메인 불용어 추가:

```python
STOPWORDS_DOMAIN = {
    "제품", "구매", "사용", "정말", "진짜",
    "완전", "그냥", "너무", "정도", "많이"
}
```

일반 불용어 목록에 있지만 현재 리뷰에서는 의미가 있는 단어는 다시 유지:

```python
KEEP_WORDS = {"아이", "시간"}
```

최종 불용어 집합:

```python
KOREAN_STOPWORDS = (
    STOPWORDS_GENERAL | STOPWORDS_DOMAIN
) - KEEP_WORDS
```

한국어 토크나이저 함수:

```python
def korean_tokenizer(text):
    """문서에서 의미 있는 명사 중 두 글자 이상인 단어만 반환."""

    return [
        token.form
        for token in kiwi.tokenize(str(text))
        if token.tag.startswith("NN")
        and len(token.form) > 1
        and token.form not in KOREAN_STOPWORDS
    ]
```

## 2. 한국어 임베딩 생성과 저장

한국어 문장을 768차원 벡터로 바꾸는 임베딩 모델 사용.

```python
emb_model = SentenceTransformer(
    "jhgan/ko-sroberta-multitask"
)
```

임베딩과 UMAP 2차원 좌표의 저장 경로:

```python
emb_path = "data/reviews_sun_embeddings.npy"
umap_path = "data/reviews_sun_umap2d.npy"
```

저장된 임베딩이 없을 때만 새로 생성:

```python
if not os.path.exists(emb_path):
    print("저장된 임베딩이 없어 지금 만듭니다.")

    texts = (
        pd.read_csv("data/reviews_sun.csv")["text"]
        .astype(str)
        .tolist()
    )

    embeddings = emb_model.encode(
        texts,
        show_progress_bar=False
    )

    np.save(emb_path, embeddings)
```

저장된 UMAP 좌표가 없을 때만 생성:

```python
if not os.path.exists(umap_path):
    print("저장된 2차원 좌표가 없어 지금 만듭니다.")

    embeddings = np.load(emb_path)

    coords = UMAP(
        n_components=2,
        n_neighbors=15,
        min_dist=0.1,
        metric="cosine",
        random_state=42
    ).fit_transform(embeddings)

    np.save(umap_path, coords)
```

## 4. 코사인 유사도로 비슷한 리뷰 찾기

0번 리뷰와 전체 리뷰 사이의 코사인 유사도 계산.

```python
sims = cosine_similarity(
    emb[0:1],
    emb
)[0]

print(len(sims))
```

출력 예시:

```text
545
```

유사도가 높은 순서대로 인덱스 정렬:

```python
sorted_indices = sims.argsort()[::-1]
```

첫 번째 결과는 자기 자신이므로 제외하고 다음 3개 선택:

```python
top3 = sorted_indices[1:4]

print(top3)
```

출력 예시:

```text
[39 98 68]
```

- `sims[i]`: 0번 리뷰와 `i`번 리뷰의 유사도
- `argsort()`: 값을 정렬한 인덱스 반환
- `[::-1]`: 내림차순으로 뒤집기
- `[1:4]`: 자기 자신을 제외한 상위 3개 선택

## 5. HDBSCAN으로 직접 군집화

미리 계산한 UMAP 2차원 좌표 불러오기:

```python
coords = np.load(
    "data/reviews_sun_umap2d.npy"
)
```

HDBSCAN 모델 생성:

```python
hdb_15 = HDBSCAN(
    min_cluster_size=15,
    metric="euclidean"
)
```

각 리뷰에 군집 번호 부여:

```python
labels = hdb_15.fit_predict(coords)
```

- 일반 군집: `0`, `1`, `2`, ...
- 노이즈: `-1`

군집 수와 노이즈 수 계산:

```python
n_groups = len(set(labels) - {-1})
n_noise_g = (labels == -1).sum()

print("군집 개수:", n_groups)
print("노이즈 개수:", n_noise_g)
```

출력 예시:

```text
군집 개수: 7
노이즈 개수: 274
```

coords = np.load(

## 7. BERTopic으로 리뷰 주제 추출

BERTopic은 임베딩으로 문서를 군집화한 뒤, 각 군집의 대표 키워드를 추출해 토픽으로 표현.

### 데이터 준비

```python
df = pd.read_csv(
    "data/reviews_sun.csv"
)

docs = (
    df["text"]
    .astype(str)
    .tolist()
)

emb = np.load(
    "data/reviews_sun_embeddings.npy"
)
```

`docs[i]`와 `emb[i]`는 같은 리뷰에 해당해야 함.

### UMAP 설정

BERTopic 내부 군집화에서는 임베딩을 5차원으로 축소.

```python
umap_model = UMAP(
    n_components=5,
    n_neighbors=15,
    min_dist=0.0,
    metric="cosine",
    random_state=42
)
```

- `n_components=5`: 5차원으로 축소
- `n_neighbors=15`: 주변 15개 데이터를 참고
- `min_dist=0.0`: 비슷한 문서가 가깝게 모이도록 설정
- `metric="cosine"`: 임베딩 사이의 코사인 거리 사용
- `random_state=42`: 결과 재현

### HDBSCAN 설정

```python
hdbscan_model = HDBSCAN(
    min_cluster_size=15,
    metric="euclidean",
    prediction_data=True
)
```

- `min_cluster_size=15`: 최소 15개 문서가 모여야 군집으로 인정
- `metric="euclidean"`: 축소된 좌표 사이의 유클리드 거리 사용
- `prediction_data=True`: 새 문서의 토픽 예측에 필요한 정보 저장

### CountVectorizer 설정

```python
vectorizer_model = CountVectorizer(
    tokenizer=korean_tokenizer,
    max_df=0.85
)
```

- `tokenizer=korean_tokenizer`: Kiwi 기반 한국어 명사 추출 함수 사용
- `max_df=0.85`: 전체 문서의 85%를 초과해 등장하는 흔한 단어 제외

### BERTopic 모델 생성

```python
topic_model = BERTopic(
    embedding_model=emb_model,
    umap_model=umap_model,
    hdbscan_model=hdbscan_model,
    vectorizer_model=vectorizer_model,
    verbose=False
)
```

### 토픽 학습

```python
topics, probs = topic_model.fit_transform(
    docs,
    embeddings=emb
)
```

- `topics`: 각 리뷰에 부여된 토픽 번호
- `probs`: 각 리뷰가 해당 토픽에 속하는 확률 또는 신뢰도

## 8. 토픽 결과 확인

토픽 정보 표 생성:

```python
topic_info = topic_model.get_topic_info()

display(topic_info)
```

주요 열:

| 열 | 의미 |
|---|---|
| `Topic` | 토픽 번호 |
| `Count` | 해당 토픽에 포함된 리뷰 수 |
| `Name` | 대표 단어로 만든 기본 토픽 이름 |
| `Representation` | 대표 키워드 목록 |
| `Representative_Docs` | 대표 문서 목록 |

`Topic=-1`은 어느 토픽에도 충분히 속하지 않은 노이즈 문서.

## 9. 토픽의 대표 키워드 확인

0번 토픽의 대표 키워드 목록:

```python
keywords = topic_model.get_topic(0)

print(keywords[0])
```

출력 예시:

```text
('마무리', 0.08800627179644041)
```

`get_topic()`은 다음 형태의 튜플 목록 반환:

```text
(단어, c-TF-IDF 점수)
```

점수가 높을수록 해당 토픽을 더 잘 대표하는 단어.

## 10. 토픽의 대표 문서 확인

키워드만으로 토픽의 의미를 판단하기 어려울 때 대표 리뷰 확인.

```python
rep_docs = topic_model.get_representative_docs(0)

print("대표 문서 존재:", len(rep_docs) >= 1)
print(rep_docs[0])
```

- `get_representative_docs(0)`: 0번 토픽을 가장 잘 대표하는 실제 문서 반환
- 키워드와 대표 문서를 함께 봐야 토픽 의미를 더 정확히 해석 가능

## 11. 노이즈 문서 수 확인

BERTopic 내부의 HDBSCAN이 어느 토픽에도 충분히 가깝지 않다고 판단한 문서는 `-1`로 처리.

```python
n_noise = topics.count(-1)

print(
    f"전체 {len(topics)}개 중, "
    f"노이즈 {n_noise}개"
)
```

출력 예시:

```text
전체 545개 중, 노이즈 203개
```

## 12. 토픽별 문서 수 시각화

노이즈 토픽을 제외한 뒤 각 토픽의 문서 수를 막대그래프로 확인.

```python
topic_info_no_noise = topic_info[
    topic_info["Topic"] != -1
]

plt.figure(figsize=(8, 5))

plt.bar(
    topic_info_no_noise["Topic"],
    topic_info_no_noise["Count"]
)

plt.xlabel("토픽 번호")
plt.ylabel("문서 수")
plt.title("토픽별 문서 수")

```

그래프를 통해 어떤 토픽에 리뷰가 많이 모였는지 확인 가능.
