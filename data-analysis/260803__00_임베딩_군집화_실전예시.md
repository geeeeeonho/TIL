# 임베딩 · 코사인 유사도 · 차원 축소 · 군집화 실습

> 문장의 임베딩 생성 → 코사인 유사도 비교 → 의미 검색 → UMAP 차원 축소 → KMeans 군집화 → 벡터 연산과 L2 정규화 순서로 확인.

## 1. 임베딩 만들기

### 1-1. 헤드라인 한 개를 벡터로 변환

문장 하나를 임베딩 모델의 `encode()`에 넣어 벡터로 변환.

```python
# 문자열 하나를 임베딩 모델에 넣어 벡터 얻기
vec = model.encode(df.loc[0, 'headline'])

# 벡터 모양 확인
# 현재 모델에서는 768차원 벡터가 생성됨
display(vec.shape)
```

**결과**

```text
(768,)
```

### 1-2. 헤드라인 20건을 한꺼번에 임베딩

임베딩은 여러 문장을 한 번에 처리할 수 있음.

```python
# 모든 헤드라인을 리스트로 변환
headlines = df['headline'].tolist()

# 모든 헤드라인을 한꺼번에 임베딩
embeddings = model.encode(headlines)

# 임베딩 결과 모양 확인
display(embeddings.shape)
print(f'헤드라인 {embeddings.shape[0]}건 x 각 {embeddings.shape[1]}차원')
```

**결과**

```text
(20, 768)
헤드라인 20건 x 각 768차원
```

`embeddings`의 형태는 `(문장 개수, 임베딩 차원 수)`.

## 2. 코사인 유사도

두 문장의 임베딩 벡터가 얼마나 비슷한 방향을 가지는지 비교.

### 2-1. 같은 분야의 헤드라인 비교

10번과 11번 헤드라인은 같은 스포츠 분야.

```python
# 인덱스 10번(11번째) 헤드라인 벡터
embed10 = embeddings[10:11]

# 인덱스 11번(12번째) 헤드라인 벡터
embed11 = embeddings[11:12]

# 두 벡터의 코사인 유사도 계산
# 결과는 2차원 배열이므로 [0][0]으로 첫 번째 유사도 값을 선택
sim_same = cosine_similarity(embed10, embed11)[0][0]

# 소수 둘째 자리까지 확인
print(round(sim_same, 2))
```

**결과**

```text
0.31
```

### 2-2. 서로 다른 분야의 헤드라인 비교

10번과 15번처럼 서로 다른 분야의 헤드라인을 비교.

```python
# 인덱스 10번(11번째) 헤드라인 벡터
embed10 = embeddings[10:11]

# 인덱스 15번(16번째) 헤드라인 벡터
embed15 = embeddings[15:16]

# 두 벡터의 코사인 유사도 계산
sim_diff = cosine_similarity(embed10, embed15)[0][0]

# 소수 둘째 자리까지 확인
print(round(sim_diff, 2))
```

**결과**

```text
0.13
```

이 예시에서는 같은 분야의 헤드라인 `0.31`이 다른 분야의 헤드라인 `0.13`보다 높은 유사도를 보임.

## 3. 의미 검색

질문도 임베딩한 뒤, 기존 헤드라인 임베딩들과 코사인 유사도를 계산해서 가장 가까운 문장을 찾음.

### 3-1. 질문과 가장 가까운 헤드라인 1건 찾기

```python
query = '프로 스포츠 경기에서 우승'

# 질문 문장을 1개의 벡터로 변환
query_vec = model.encode([query])

# 질문 1개와 기존 헤드라인 전체의 코사인 유사도 계산
# 결과 형태는 (1, 헤드라인 개수)이므로 [0]으로 첫 번째 행을 꺼냄
scores = cosine_similarity(query_vec, embeddings)[0]

print(len(scores))

# 가장 큰 유사도 값을 가진 헤드라인의 인덱스
# np.argmax(): 최댓값의 위치 반환
top1 = np.argmax(scores)
print(top1)
```

**결과**

```text
20
11
```

- `scores`에는 헤드라인 20건 각각의 유사도 점수가 들어감.
- 가장 유사한 헤드라인의 인덱스는 `11`.

### 3-2. 질문과 가장 가까운 헤드라인 3건 찾기

실제 검색에서는 1건보다 상위 `k`개 결과를 가져오는 방식이 더 일반적인 형태.

```python
query2 = '인공지능 기술과 반도체 신제품'

# 질문 문장을 1개의 벡터로 변환
query2_vec = model.encode([query2])

# 질문과 기존 헤드라인 전체의 코사인 유사도 계산
scores2 = cosine_similarity(query2_vec, embeddings)[0]
print(len(scores2))

# 유사도 점수가 큰 순서대로 상위 3개의 인덱스 선택
# -scores2를 사용하면 높은 점수부터 정렬 가능
top3 = np.argsort(-scores2)[:3]

print(len(top3))
print(top3[0])  # 가장 가까운 헤드라인의 인덱스
```

**결과**

```text
20
3
15
```

`top3`에는 질문과 가장 유사한 헤드라인 3개의 인덱스가 들어감.

## 4. 차원 축소: UMAP

고차원 임베딩을 사람이 보기 쉬운 저차원 좌표로 축소.

여기서는 **768차원 → 2차원**으로 변환.

UMAP은 각 데이터의 이웃 관계를 최대한 유지하면서 차원을 줄이는 방식.

### 4-1. 768차원 임베딩을 2차원으로 축소

```python
# UMAP 결과의 차원을 2차원으로 설정
umap_model = UMAP(
    n_components=2,   # 임베딩을 x, y 두 좌표로 축소
    n_neighbors=5,    # 각 데이터 주변의 가까운 이웃 5개를 참고
    min_dist=0.05,    # 축소된 공간에서 가까운 데이터의 밀집 정도 설정
    random_state=0    # 실행 결과 재현을 위한 난수 고정
)

# 임베딩 구조를 학습하고 2차원 좌표로 변환
coords = umap_model.fit_transform(embeddings)

# 결과 형태: (데이터 개수, 2)
print(coords.shape)
```

**결과**

```text
(20, 2)
```

### 4-2. 축소된 좌표 한 건 확인

```python
# coords의 각 행에는 헤드라인 하나의 [x, y] 좌표가 저장됨
first_coord = coords[0]

print(first_coord)       # 첫 번째 헤드라인의 [x, y] 좌표
print(len(first_coord))  # 좌표 개수 → 2
```

**결과**

```text
[10.048118 14.623518]
2
```

## 5. KMeans 군집화

UMAP으로 축소한 좌표를 이용해 비슷한 헤드라인끼리 그룹으로 묶음.

### 5-1. 헤드라인을 3개 군집으로 분류

```python
# KMeans 군집화 모델 설정
kmeans_model = KMeans(
    n_clusters=3,    # 데이터를 3개 군집으로 나눔
    random_state=0,  # 결과 재현을 위한 난수 고정
    n_init=10        # 초기 중심점을 10번 다르게 시도
)

# 2차원 좌표를 군집화하고 각 데이터의 군집 번호 반환
labels = kmeans_model.fit_predict(coords)

print(len(labels))       # 군집 번호 개수 = 헤드라인 개수
print(len(set(labels)))  # 서로 다른 군집 번호 개수
```

**결과**

```text
20
3
```

### 5-2. 같은 분야가 같은 군집에 묶였는지 확인

```python
# 10번과 11번 헤드라인의 군집 번호 비교
same_cluster = labels[10] == labels[11]

print(labels[10])
print(labels[11])
print(same_cluster)
```

**결과**

```text
0
0
True
```

두 헤드라인 모두 군집 `0`에 포함되어 같은 군집으로 분류됨.

### 5-3. 실루엣 점수로 군집화 평가

실루엣 점수는 같은 군집 내부의 데이터는 가깝고, 다른 군집과는 멀리 떨어져 있는지를 평가하는 값.

값이 `1`에 가까울수록 군집이 잘 분리된 상태.

```python
# UMAP 2차원 좌표와 KMeans 군집 라벨을 이용해 실루엣 점수 계산
# coords : 각 헤드라인의 2차원 좌표
# labels : 각 헤드라인의 군집 번호
sil = silhouette_score(coords, labels)

print(sil)
```

**결과**

```text
0.5032878518104553
```

### 5-4. 적절한 군집 개수 k 비교

`k=3`과 `k=6`을 각각 군집화한 뒤 실루엣 점수로 비교.

```python
k3_means_model = KMeans(
    n_clusters=3,
    random_state=0,
    n_init=10
)

k6_means_model = KMeans(
    n_clusters=6,
    random_state=0,
    n_init=10
)

# k=3 군집화
k3_means = k3_means_model.fit_predict(coords)
sil3 = silhouette_score(coords, k3_means)

# k=6 군집화
k6_means = k6_means_model.fit_predict(coords)
sil6 = silhouette_score(coords, k6_means)

# 실루엣 점수가 더 높은 쪽이 더 잘 분리된 군집화 결과
k3_better = sil3 > sil6
print(k3_better)
```

**결과**

```text
True
```

이 결과에서는 `k=3`의 실루엣 점수가 `k=6`보다 높음.

## 6. 벡터 연산으로 코사인 유사도 직접 계산

코사인 유사도 공식:

```text
코사인 유사도 = 내적 / (벡터 A의 길이 × 벡터 B의 길이)
```

### 6-1. 2차원 벡터로 직접 계산

```python
# 벡터 리스트 두 개 만들기
a_vec = [3, 4]
b_vec = [4, 3]

# 내적: 같은 위치의 값을 곱한 뒤 모두 더함
dot_ab = sum(
    a_vec[i] * b_vec[i]
    for i in range(len(a_vec))
)

# 벡터의 길이: 각 값을 제곱해 더한 뒤 제곱근
norm_a = sum(
    a_vec[i] ** 2
    for i in range(len(a_vec))
) ** 0.5

norm_b = sum(
    b_vec[i] ** 2
    for i in range(len(b_vec))
) ** 0.5

# 코사인 유사도 계산
cos_ab = dot_ab / (norm_a * norm_b)
print(cos_ab)

# 함수화
def my_cos(u, v):
    # 내적
    dot_ab = sum(u[i] * v[i] for i in range(len(u)))

    # 두 벡터의 길이
    norm_a = sum(u[i] ** 2 for i in range(len(u))) ** 0.5
    norm_b = sum(v[i] ** 2 for i in range(len(v))) ** 0.5

    # 코사인 유사도
    cos_ab = dot_ab / (norm_a * norm_b)
    return cos_ab
```

**결과**

```text
0.96
```

## 7. 768차원 임베딩의 코사인 유사도 직접 계산

`cosine_similarity()`를 사용하지 않고, 실제 임베딩 벡터의 내적과 길이로 직접 계산.

```python
# embeddings에서 10번과 11번의 768차원 벡터 선택
embed10 = embeddings[10]  # 1차원 배열
embed11 = embeddings[11]  # 1차원 배열

# 내적 계산
# 같은 위치의 768개 값을 각각 곱한 뒤 모두 더함
dot_10_11 = embed10 @ embed11

# 각 벡터의 길이 계산
norm_10 = np.linalg.norm(embed10)
norm_11 = np.linalg.norm(embed11)

# 코사인 유사도 = 내적 / 두 벡터 길이의 곱
cos_manual = dot_10_11 / (norm_10 * norm_11)

print(cos_manual)
```

**결과**

```text
0.3130134
```

앞에서 `cosine_similarity()`로 계산한 같은 두 헤드라인의 유사도 약 `0.31`과 일치.

## 8. L2 정규화

벡터를 자기 자신의 길이로 나누어 **길이가 1인 단위 벡터**로 변환.

```text
정규화 벡터 = 원래 벡터 / 벡터의 길이
```

방향은 유지되고 길이만 `1`로 바뀜.

두 벡터가 모두 L2 정규화되어 길이가 `1`이면:

```text
코사인 유사도 = 내적 / (1 × 1) = 내적
```

따라서 **정규화된 두 벡터의 내적 = 코사인 유사도**.

```python
# 각 벡터를 자신의 L2 길이로 나누어 단위 벡터로 변환
unit_10 = embed10 / norm_10
unit_11 = embed11 / norm_11

# 단위 벡터끼리의 내적 = 코사인 유사도
dot_unit = unit_10 @ unit_11

print(dot_unit)    # 정규화 벡터의 내적
print(cos_manual)  # 직접 계산한 코사인 유사도
```

**결과**

```text
0.31301337
0.3130134
```

두 값이 거의 같음.

## 핵심 흐름

```text
문장
 ↓
임베딩 모델 encode()
 ↓
768차원 벡터
 ↓
코사인 유사도
 ├─ 문장 간 유사도 비교
 └─ 질문과 가까운 문장 검색
 ↓
UMAP
768차원 → 2차원
 ↓
KMeans
비슷한 데이터끼리 군집화
 ↓
실루엣 점수
군집화 품질 비교
```

### 핵심 함수

| 목적 | 함수 / 연산 | 의미 |
|---|---|---|
| 문장 임베딩 | `model.encode()` | 문장을 벡터로 변환 |
| 코사인 유사도 | `cosine_similarity()` | 두 벡터의 방향 유사도 계산 |
| 최댓값 위치 | `np.argmax()` | 가장 높은 유사도 인덱스 찾기 |
| 상위 k개 | `np.argsort(-scores)[:k]` | 유사도 높은 순서의 인덱스 추출 |
| 차원 축소 | `UMAP().fit_transform()` | 고차원 벡터를 저차원 좌표로 변환 |
| 군집화 | `KMeans().fit_predict()` | 비슷한 데이터를 그룹으로 분류 |
| 군집 평가 | `silhouette_score()` | 군집이 얼마나 잘 분리됐는지 평가 |
| 내적 | `a @ b` | 같은 위치 값의 곱을 모두 더함 |
| 벡터 길이 | `np.linalg.norm()` | L2 길이 계산 |
| L2 정규화 | `v / np.linalg.norm(v)` | 벡터 길이를 1로 맞춤 |
