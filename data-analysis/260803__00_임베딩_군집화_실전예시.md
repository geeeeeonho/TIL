벡터 연산 : 수식 직접 계산  
코사인 유사도의 공식인 { 내적 ÷ (길이 × 길이) } 써보기  
*\#벡터 리스트 두개 만들기*  
a\_vec \= \[3, 4\]  
b\_vec \= \[4, 3\]

*\#내적 \= 같은 칸끼리 곱해서 모두 더한 값*  
dot\_ab \= **sum**(  
    a\_vec\[i\] \* b\_vec\[i\] *\#각 자리의 곱*  
    for i in **range**(**len**(a\_vec))  *\#자릿수만큼 반복*  
)

*\#벡터의 길이: 각 값을 제곱해 더한 뒤 제곱근*  
norm\_a \= **sum**(  
        a\_vec\[i\] \*\* 2  
        for i in **range**(**len**(a\_vec))  
    ) \*\* 0.5

norm\_b \= **sum**(  
        b\_vec\[i\] \*\* 2  
        for i in **range**(**len**(b\_vec))  
    ) \*\* 0.5

*\#코사인 유사도 \= 내적 / 두 길이의 곱*  
cos\_ab \= dot\_ab / (norm\_a\*norm\_b)

**print**(cos\_ab)

*\#함수화*  
def **my\_cos**(u, v):  
    *\#내적 \= 같은 칸끼리 곱해서 모두 더한 값*  
    dot\_ab \= **sum**( u\[i\]\*v\[i\] for i in **range**(**len**(u)) )

    *\#벡터의 길이: 각 값을 제곱해 더한 뒤 제곱근*  
    norm\_a \= **sum**( u\[i\]\*\*2 for i in **range**(**len**(u)) ) \*\* 0.5  
    norm\_b \= **sum**(v\[i\]\*\*2 for i in **range**(**len**(v)) ) \*\* 0.5  
     
    *\#코사인 유사도 \= 내적 / 두 길이의 곱*  
    cos\_ab \= dot\_ab / (norm\_a\*norm\_b)

    return cos\_ab  
\>\>\>  
0.96 

**고차원 임베딩 계산**  
786차원 임베딩하기  
*\# embeddings에서 10번과 11번의 768차원 벡터 선택*  
embed10 \= embeddings\[10\]  *\# 10번 벡터: 1차원*  
embed11 \= embeddings\[11\]  *\# 11번 벡터: 1차원*

*\# 내적 구하기 : @연산자 이용*  
*\# 같은 위치의 768개 값을 각각 곱한 뒤 모두 더하여 내적 계*  
dot\_10\_11 \= embed10**@**embed11

*\#각 벡터 길이 구하기 : np.linalg.norm 이용*  
norm\_10 \= **np**.**linalg**.**norm**(embed10)  
norm\_11 \= **np**.**linalg**.**norm**(embed11)

*\#코사인 유사도 계산 : 내적 / 두 길이의 곱*  
cos\_manual \= dot\_10\_11 **/** (norm\_10**\***norm\_11)

**print**(cos\_manual)  
\>\>\>  
0.3130134 

**L2 정규화 : 벡터 길이를 1로 맞추기**  
벡터를 자기 길이로 나누기 \-\> 방향동일 길이 1벡터(L2 정규화)  
\-\> 분모가 1이므로, 내적계산값 \= 코사인값  
*\# 각 벡터를 자신의 L2 길이로 나누어 길이가 1인 단위 벡터로 변환(L2 정규화)*  
*\# 벡터의 방향은 유지되고 크기만 1로 바뀜*  
unit\_10 \= embed10 **/** norm\_10  
unit\_11 \= embed11 **/** norm\_11

*\# 길이가 1인 두 단위 벡터의 내적 계산 \-\> 단위 벡터끼리의 내적 \= 코사인 유사도*  
dot\_unit \= unit\_10@unit\_11

**print**(dot\_unit)     *\# 정규화한 벡터의 내적으로 계산한 코사인 유사도*  
**print**(cos\_manual)   *\# 내적 / 두 벡터 길이의 곱으로 직접 계산한 코사인 유사도*  
\>\>\>  
0.31301337
