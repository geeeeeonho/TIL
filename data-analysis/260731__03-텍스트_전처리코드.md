## 2. 정규표현식 기본 문법

정규표현식은 **문자 패턴을 찾아 검사·추출·변경하는 문법**.

### 문자 패턴

| 패턴 | 뜻 | 예 |
|---|---|---|
| `abc` | 글자 그대로 찾기 | `영화` → 정확히 `영화` |
| `[...]` | 대괄호 안 문자 중 하나 | `[가-힣]` → 완성형 한글 한 글자 |
| `[^...]` | 대괄호 안 문자가 아닌 것 | `[^가-힣]` → 완성형 한글이 아닌 글자 |
| `\d` | 숫자 한 글자 | `\d+` → 이어진 숫자 |
| `\s` | 공백 문자 | 스페이스·탭·줄바꿈 |
| `\S` | 공백이 아닌 문자 | `\S+` → 공백 전까지 |
| `.` | 줄바꿈을 제외한 아무 글자 하나 | `가.` → `가` 뒤의 글자 하나 |

### 반복·범위·그룹

| 패턴 | 뜻 | 예 |
|---|---|---|
| `*` | 앞 패턴이 0회 이상 | `a*` |
| `+` | 앞 패턴이 1회 이상 | `\d+` |
| `?` | 앞 패턴이 0회 또는 1회 | `https?` → `http`, `https` |
| `{m,n}` | 앞 패턴이 m~n회 | `\d{2,3}` |
| `^` | 문자열 시작 | `^공지` |
| `$` | 문자열 끝 | `완료$` |
| `(...)` | 여러 패턴을 그룹으로 묶고 기억 | `(좋아)+` |
| `A&#124;B` | A 또는 B | `긍정&#124;부정` |
| `\1` | 첫 번째 그룹에서 기억한 값 재사용 | `(.)\1` |

### 역참조

```python
pattern = r"(.)\1{2,}"
```

구성:

```text
(.)       아무 글자 하나를 첫 번째 그룹으로 기억
\1        첫 번째 그룹에서 기억한 글자와 같은 글자
{2,}      같은 글자가 2번 이상 더 등장
```

따라서 **같은 글자가 총 3번 이상 반복되는 부분**과 일치.

```text
ㅋㅋ   → 불일치
ㅋㅋㅋ → 일치
ㅋㅋㅋㅋ → 일치
```

> `(.)\1`은 같은 글자가 두 번 반복된 패턴이다.  
> 세 글자 회문은 `(.).\1`처럼 첫 글자를 기억하고 가운데 글자 뒤에 같은 글자가 다시 오는 패턴으로 찾는다.

### Raw string

정규표현식 앞에는 보통 `r`을 붙임.

```python
r"\s+"
r"\d{3}-\d{4}-\d{4}"
```

`r`은 `\`를 파이썬이 먼저 해석하지 않고 정규표현식에 그대로 전달하는 표시.

## 3. 문자열 찾기와 정규표현식 함수

| 목적 | 함수 | 결과 |
|---|---|---|
| 정확한 글자의 위치 찾기 | `문장.find("글자")` | 시작 인덱스, 없으면 `-1` |
| 패턴의 첫 일치 찾기 | `re.search(패턴, 문장)` | `Match` 또는 `None` |
| 모든 일치값 찾기 | `re.findall(패턴, 문장)` | 문자열 리스트 |
| 일치 부분 바꾸기 | `re.sub(패턴, 바꿀값, 문장)` | 변경된 새 문자열 |

### `find()`와 `search()` 비교

```python
message = "문의번호 CS-102, 주문번호 OD-305, 연락처 010-1234-5678"

# 정확한 문자열 '주문번호'가 시작되는 위치를 반환
literal_index = message.find("주문번호")
print("find 결과:", literal_index)

# 대문자 2개-숫자 3개 형식과 처음 일치하는 부분 검색
first_code = re.search(r"[A-Z]{2}-\d{3}", message)

# re.search()는 일치하지 않으면 None을 반환하므로 먼저 확인
if first_code is not None:
    print("search 값:", first_code.group())
```

```text
find 결과: 13
search 값: CS-102
```

패턴 설명:

```text
[A-Z]       A~Z 사이의 대문자 한 글자
[A-Z]{2}    대문자 두 글자
-           하이픈 문자 그대로
\d{3}       숫자 세 글자
```

### 모든 코드 찾기

```python
code_pattern = r"[A-Z]{2}-\d{3}"

# 패턴과 일치하는 모든 문자열을 리스트로 반환
all_codes = re.findall(code_pattern, message)

print("findall 결과:", all_codes)
# ['CS-102', 'OD-305']
```

## 4. 텍스트 정제와 정규화

### 정제 3단계

```text
1. 특수문자 제거
2. 반복문자 축약
3. 공백 정규화
```

```python
sample = "TV시리즈가 너무재밌어서 영화는 기대안하고 봤는데 역시....최고네요ㅋㅋㅋㅋ!!!"

print("원문:", sample)

# 1) 한글·자음·모음·영문·숫자·공백이 아닌 문자를 공백으로 변경
step1 = re.sub(
    r"[^가-힣ㄱ-ㅎㅏ-ㅣa-zA-Z0-9\s]",
    " ",
    sample
)
print("1단계:", step1)

# 2) 같은 글자가 3번 이상 반복되면 2번으로 축약
# 예: ㅋㅋㅋㅋ → ㅋㅋ
step2 = re.sub(
    r"(.)\1{2,}",
    r"\1\1",
    step1
)
print("2단계:", step2)

# 3) 여러 공백을 한 칸으로 줄이고 양끝 공백 제거
step3 = re.sub(r"\s+", " ", step2).strip()
print("3단계:", step3)
```

```text
원문: TV시리즈가 너무재밌어서 영화는 기대안하고 봤는데 역시....최고네요ㅋㅋㅋㅋ!!!
1단계: TV시리즈가 너무재밌어서 영화는 기대안하고 봤는데 역시    최고네요ㅋㅋㅋㅋ
2단계: TV시리즈가 너무재밌어서 영화는 기대안하고 봤는데 역시    최고네요ㅋㅋ
3단계: TV시리즈가 너무재밌어서 영화는 기대안하고 봤는데 역시 최고네요ㅋㅋ
```

### 통합 정제 함수

```python
def clean_text(text):
    """특수문자·반복문자·공백을 정제해 문자열로 반환."""

    # 결측치나 숫자 등이 들어와도 처리할 수 있도록 문자열로 변환
    text = str(text)

    # 한글·자모·영문·숫자·공백이 아닌 문자 제거
    text = re.sub(
        r"[^가-힣ㄱ-ㅎㅏ-ㅣa-zA-Z0-9\s]",
        " ",
        text
    )

    # 같은 글자가 3번 이상 반복되면 2번만 남김
    text = re.sub(
        r"(.)\1{2,}",
        r"\1\1",
        text
    )

    # 연속된 공백을 한 칸으로 줄이고 양끝 공백 제거
    text = re.sub(r"\s+", " ", text).strip()

    return text
```

## 5. 실무에서 자주 쓰는 정제 패턴

| 제거 대상 | 패턴 | 설명 |
|---|---|---|
| HTML 태그 | `<[^>]+>` | `<`부터 다음 `>`까지 제거 |
| URL | `https?://\S+` | `http` 또는 `https`로 시작하는 주소 |
| 이메일 | `[\w.+-]+@[\w-]+\.[\w.-]+` | 일반적인 이메일 형식 |
| 숫자 | `\d+` | 숫자 한 개 이상 |
| 연속 공백 | `\s+` | 여러 공백·탭·줄바꿈 |

전화번호·가격·날짜가 분석에 필요하면 숫자를 무조건 지우지 않음.

### HTML·URL·이메일·숫자 제거

```python
raw = (
    "<p>배송 문의는 <b>help@shop.co.kr</b> 로!</p> "
    "자세한 내용 https://shop.co.kr/faq 참고. "
    "전화 01012345678"
)

print("원문:", raw)

# HTML 태그 제거
text = re.sub(r"<[^>]+>", " ", raw)
print("태그 제거:", text.strip())

# URL 제거
text = re.sub(r"https?://\S+", " ", text)
print("링크 제거:", text.strip())

# 이메일 제거
text = re.sub(
    r"[\w.+-]+@[\w-]+\.[\w.-]+",
    " ",
    text
)
print("메일 제거:", text.strip())

# 숫자 제거
text = re.sub(r"\d+", " ", text)

# 남은 여러 공백 정리
text = re.sub(r"\s+", " ", text).strip()

print("최종:", text)
```

## 6. 정규표현식 종합 예제

```python
log = "ERROR 코드 ER-104 발생, 재시도 코드 RT-208 기록"

# 대문자 2개-숫자 3개 형식
code_pattern = r"[A-Z]{2}-\d{3}"

# 정확한 글자 '재시도'의 시작 위치
# 찾지 못하면 -1 반환
retry_index = log.find("재시도")

# 패턴과 처음 일치하는 Match 객체
first_match = re.search(code_pattern, log)

# 일치한 경우 문자열을 꺼내고, 없으면 None 저장
first_code = first_match.group() if first_match else None

# 패턴과 일치하는 모든 문자열
all_codes = re.findall(code_pattern, log)

print("재시도의 인덱스:", retry_index)
print("패턴에 맞는 최초의 코드:", first_code)
print("패턴에 맞는 모든 코드:", all_codes)
```

```text
재시도의 인덱스: 20
패턴에 맞는 최초의 코드: ER-104
패턴에 맞는 모든 코드: ['ER-104', 'RT-208']
```

> `re.search()`가 실패했을 때 `re.findall()` 결과를 대신 넣으면 `first_code`의 자료형이 문자열과 리스트로 섞인다.  
> 첫 코드가 없을 때는 `None`으로 통일하는 편이 안전하다.

## 7. 공백 기준 토큰화의 한계

### `split()`으로 단어 세기

```python
support_messages = [
    "배송이 너무 늦어요",
    "배송은 언제 시작되나요",
    "배송을 기다리고 있어요",
    "배송 지연 문의입니다",
    "배송이 아직 안 왔어요",
]

# 빈 Counter 생성
support_counter = Counter()

for message in support_messages:
    # 공백으로 나눈 단어들을 빈도에 누적
    support_counter.update(message.split())

print(support_counter)
```

결과에는 다음 표현이 서로 다른 단어로 저장됨.

```text
배송
배송이
배송은
배송을
```

한국어는 명사 뒤에 조사와 어미가 붙기 때문에 `split()`만으로 정확한 단어 빈도를 구하기 어려움.

### `배송`으로 시작하는 단어만 추출

```python
delivery_forms = [
    (word, count)
    for word, count in support_counter.items()
    if word.startswith("배송")
]

# 빈도 기준 내림차순 정렬
delivery_forms.sort(
    key=lambda item: item[1],
    reverse=True
)

print("서로 다른 배송 표현 수:", len(delivery_forms))
print(delivery_forms)
```

```text
[('배송이', 2), ('배송은', 1), ('배송을', 1), ('배송', 1)]
```

## 8. 한국어 형태소 분석

`Kiwi`는 문장을 형태소로 나누고 각 형태소에 품사 태그를 붙임.

```python
kiwi.tokenize("배송이 늦어요")
```

토큰에서 주로 사용하는 속성:

```text
token.form    형태소의 실제 글자
token.tag     형태소의 품사 태그
```

### 주요 품사 태그

| 태그 | 품사 | 예 |
|---|---|---|
| `NNG` | 일반 명사 | 영화, 배송, 상담원 |
| `NNP` | 고유 명사 | 사람·장소·브랜드 이름 |
| `VA` | 형용사 | 느리, 좋, 아름답 |
| `VV` | 동사 | 보, 만들, 웃 |
| `MAG` | 일반 부사 | 너무, 매우 |
| `JKS`, `JX` | 조사 | 이, 가, 는 |
| `EP`, `EF` | 어미 | 었, 어요 |
| `XR` | 어근 | 답답 |
| `XSA` | 형용사 파생 접미사 | 하 |

### 정제 후 형태소 분석

```python
raw = "배송이 너무느리고 상담원이 답답했어요!!!"

# 정제 함수 적용
cleaned = clean_text(raw)

print("정제 후:", cleaned)

# 형태소 분석 결과 전체 확인
kiwi_tokens = kiwi.tokenize(cleaned)

for token in kiwi_tokens:
    print(token.form, token.tag)

# 명사·형용사·동사이며 두 글자 이상인 형태소만 추출
tokens = [
    token.form
    for token in kiwi_tokens
    if token.tag.startswith(("NN", "VA", "VV"))
    and len(token.form) > 1
]

print("선택한 토큰:", tokens)
```

```text
선택한 토큰: ['배송', '느리', '상담원']
```

`답답했어요`는 Kiwi에서 다음처럼 분석될 수 있음.

```text
답답/XR + 하/XSA + 었/EP + 어요/EF
```

현재 필터는 `NN`, `VA`, `VV`만 선택하므로 `답답`은 제외됨.

분석 목적에 따라 `XR`을 추가할 수 있음.

```python
token.tag.startswith(("NN", "VA", "VV", "XR"))
```

## 9. 불용어 제거

**불용어**: 자주 나오지만 분석 목적에는 중요하지 않은 단어.

종류:

```text
일반 불용어
- 여러 분야에서 공통으로 의미가 적은 단어

도메인 불용어
- 특정 데이터에서 너무 흔해 구분력이 낮은 단어
- 영화 리뷰의 '영화', '평점'
- 고객 문의의 '문의', '상담'
```

### JSON 불용어 파일 읽기

```python
with open(
    "data/stopwords_ko.json",
    encoding="utf-8"
) as file:
    # JSON 배열을 파이썬 리스트로 읽은 뒤 set으로 변환
    stopwords_general = set(json.load(file))

print("일반 불용어 개수:", len(stopwords_general))
print("예시:", sorted(stopwords_general)[:15])
```

`set`을 사용하는 이유:

- 중복 자동 제거
- `word in stopwords` 검사가 빠름
- `A | B`로 두 불용어 집합을 쉽게 합칠 수 있음

```python
domain_stopwords = {"영화", "평점"}

# 일반 불용어와 도메인 불용어 합치기
all_stopwords = stopwords_general | domain_stopwords
```

## 10. 정제·형태소 분석·불용어 제거 함수

```python
def tokenize(text, stopwords):
    """
    텍스트를 정제하고 형태소 분석한 뒤
    필요한 품사만 골라 불용어를 제거한다.
    """

    # 1. 특수문자·반복문자·공백 정제
    cleaned = clean_text(text)

    # 2. 정제된 문장을 형태소 단위로 분석
    kiwi_tokens = kiwi.tokenize(cleaned)

    # 3. 조건을 만족하는 형태소의 실제 글자만 반환
    return [
        token.form
        for token in kiwi_tokens

        # NN: 명사, VA: 형용사, VV: 동사
        if token.tag.startswith(("NN", "VA", "VV"))

        # 한 글자 형태소 제외
        and len(token.form) > 1

        # 불용어 목록에 포함된 형태소 제외
        and token.form not in stopwords
    ]
```

### 리스트 컴프리헨션 해석

```python
return [
    token.form
    for token in kiwi_tokens
    if 조건1
    and 조건2
    and 조건3
]
```

실행 순서:

```text
kiwi_tokens에서 token을 하나씩 꺼냄
→ 품사 조건 확인
→ 길이 조건 확인
→ 불용어 조건 확인
→ 모든 조건을 통과한 token.form만 리스트에 저장
```

## 11. 전체 리뷰의 단어 빈도 분석

다음 예제는 `reviews`가 `text` 열을 가진 데이터프레임이라고 가정.

```python
counter_general = Counter()

for text in reviews["text"]:
    # 리뷰 하나를 토큰화한 뒤 빈도 누적
    review_tokens = tokenize(
        text,
        stopwords_general
    )

    counter_general.update(review_tokens)

print("[일반 불용어 적용 빈도 TOP 15]")

for word, count in counter_general.most_common(15):
    print(f"{word:8s} {count}")
```

도메인 불용어는 먼저 빈도 상위를 확인한 뒤 사람이 결정.

```python
movie_stopwords = {
    "영화",
    "평점"
}

movie_all_stopwords = (
    stopwords_general
    | movie_stopwords
)
```

## 12. 고객 문의 종합 예제

```python
support_samples = [
    "배송이 너무 늦어서 확인 부탁해요!!!",
    "결제가 두 번 됐는데 취소할 수 있나요?",
    "교환 신청했는데 수거 일정이 궁금합니다.",
]

# 고객 문의 데이터에서 제외할 도메인 불용어
support_stopwords = {
    "문의",
    "상담"
}

# 모든 문의의 토큰을 모을 리스트
all_tokens = []

for index, raw in enumerate(support_samples):
    # 같은 문장을 두 번 분석하지 않고 결과를 변수에 저장
    sample_tokens = tokenize(
        raw,
        support_stopwords
    )

    print(f"[{index}] 원문: {raw}")
    print(f"    토큰: {sample_tokens}")

    # 현재 문의의 토큰을 전체 리스트에 추가
    all_tokens.extend(sample_tokens)

# 전체 토큰 빈도 계산
counter = Counter(all_tokens)

print("전체 빈도:", counter)
```

```text
[0] 토큰: ['배송', '확인', '부탁']
[1] 토큰: ['결제', '취소']
[2] 토큰: ['교환', '신청', '수거', '일정', '궁금하']
```

`extend()`와 `append()` 차이:

```python
all_tokens.extend(["배송", "확인"])
# ['배송', '확인']

all_tokens.append(["배송", "확인"])
# [['배송', '확인']]
```

토큰을 하나의 평평한 리스트로 합칠 때는 `extend()` 사용.

## 13. 수정·보완한 코드

### 1. `배송` 필터 누락

기존 형태:

```python
delivery_forms = [
    (word, count)
    for word, count in support_counter.items()
]
```

이 코드는 모든 단어를 가져오므로 `배송`으로 시작하는 단어만 고른다는 설명과 불일치.

수정:

```python
delivery_forms = [
    (word, count)
    for word, count in support_counter.items()
    if word.startswith("배송")
]
```

### 2. 첫 검색 실패 시 자료형 불일치

피해야 할 형태:

```python
if first_match:
    first_code = first_match.group()
else:
    first_code = re.findall(code_pattern, log)
```

검색 성공 시 문자열, 실패 시 리스트가 저장됨.

수정:

```python
first_code = (
    first_match.group()
    if first_match
    else None
)
```

### 3. 동일 문장 중복 토큰화

피해야 할 형태:

```python
print(tokenize(raw, stopwords))
tokens += tokenize(raw, stopwords)
```

같은 문장을 두 번 형태소 분석.

수정:

```python
sample_tokens = tokenize(raw, stopwords)

print(sample_tokens)
tokens.extend(sample_tokens)
```

## 14. 최종 통합 코드

```python
import json
import re
from collections import Counter

from kiwipiepy import Kiwi


# 형태소 분석기 생성
kiwi = Kiwi()


def clean_text(text):
    """특수문자·반복문자·공백을 정제한다."""

    # 입력값을 안전하게 문자열로 변환
    text = str(text)

    # 한글·자모·영문·숫자·공백 외 문자 제거
    text = re.sub(
        r"[^가-힣ㄱ-ㅎㅏ-ㅣa-zA-Z0-9\s]",
        " ",
        text
    )

    # 같은 글자가 3번 이상 반복되면 2번으로 축약
    text = re.sub(
        r"(.)\1{2,}",
        r"\1\1",
        text
    )

    # 연속 공백을 한 칸으로 통일
    text = re.sub(r"\s+", " ", text).strip()

    return text


def tokenize(text, stopwords):
    """정제 → 형태소 분석 → 품사 필터 → 불용어 제거."""

    # 원문 정제
    cleaned = clean_text(text)

    # 정제된 문장 형태소 분석
    kiwi_tokens = kiwi.tokenize(cleaned)

    # 분석 목적에 필요한 토큰만 선택
    return [
        token.form
        for token in kiwi_tokens
        if token.tag.startswith(("NN", "VA", "VV"))
        and len(token.form) > 1
        and token.form not in stopwords
    ]


# 일반 불용어 파일 읽기
with open(
    "data/stopwords_ko.json",
    encoding="utf-8"
) as file:
    stopwords_general = set(json.load(file))


# 분석 분야에 맞는 도메인 불용어 추가
support_domain_stopwords = {
    "문의",
    "상담"
}

support_stopwords = (
    stopwords_general
    | support_domain_stopwords
)


# 분석할 문장
support_samples = [
    "배송이 너무 늦어서 확인 부탁해요!!!",
    "결제가 두 번 됐는데 취소할 수 있나요?",
    "교환 신청했는데 수거 일정이 궁금합니다.",
]


# 전체 토큰 누적
all_tokens = []

for index, raw in enumerate(support_samples):
    sample_tokens = tokenize(
        raw,
        support_stopwords
    )

    print(f"[{index}] 원문: {raw}")
    print(f"    토큰: {sample_tokens}")

    all_tokens.extend(sample_tokens)


# 단어별 빈도 계산
counter = Counter(all_tokens)

print("\n[단어 빈도]")
for word, count in counter.most_common():
    print(f"{word:8s} {count}")
```

## 총정리

| 단계 | 하는 일 | 주요 코드 |
|---|---|---|
| 정확한 글자 찾기 | 특정 문자열의 위치 확인 | `str.find()` |
| 패턴 첫 검색 | 첫 번째 일치 확인 | `re.search()` |
| 패턴 전체 검색 | 모든 일치값 추출 | `re.findall()` |
| 텍스트 정제 | 특수문자·URL·이메일 제거 | `re.sub()` |
| 반복문자 정규화 | `ㅋㅋㅋㅋ` → `ㅋㅋ` | `(.)\1{2,}` |
| 공백 정규화 | 여러 공백을 한 칸으로 변경 | `re.sub(r"\s+", " ", text)` |
| 단순 토큰화 | 공백 기준 분리 | `split()` |
| 형태소 분석 | 조사·어미 분리, 품사 확인 | `kiwi.tokenize()` |
| 품사 필터 | 명사·형용사·동사 선택 | `tag.startswith(("NN", "VA", "VV"))` |
| 불용어 제거 | 의미 없는 일반·도메인 단어 제거 | `token.form not in stopwords` |
| 빈도 분석 | 단어별 등장 횟수 계산 | `Counter.update()` |

```text
한국어 텍스트 분석의 핵심

정제만으로는 부족
→ 한국어는 조사·어미가 붙음
→ 형태소 분석 필요
→ 필요한 품사만 선택
→ 일반 불용어와 도메인 불용어 제거
→ Counter로 단어 빈도 확인
```
