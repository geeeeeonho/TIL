# Pandas 실사용 중심 정리

> 기준: 실제 작업에서 **무엇을 하려는지 → 어떤 함수·문법을 쓰는지** 순서로 정리  
> 전체 흐름: **불러오기 → 구조 확인 → 필요한 데이터 선택 → 정제 → 결측·이상치 처리 → 파생 변수 → 검증 → 저장**

## 0. 기본 준비

```python
import pandas as pd
import numpy as np
```

- `pd`: pandas 별칭
- `np`: numpy 별칭
- `DataFrame`: 행·열로 구성된 2차원 표
- `Series`: 열 하나 형태의 1차원 데이터
- `NaN`: 일반적인 결측값
- `NaT`: 날짜형 결측값

# 5. 특정 행·열 위치를 정확히 고를 때


→ 라벨 `0, 1, 2` 모두 포함

특징:


# 6. 조건에 맞는 행만 찾을 때

기본 구조:

```python
df[조건]
```

예:

```python
df[df["가격"] >= 5000]
```

조건식은 각 행에 대해 `True / False`를 만들고, `True`인 행만 남김.

---

## 6-1. 하나의 조건

```python
df[df["카테고리"] == "커피"]
```

---

## 6-2. 여러 조건

### AND

```python
df[
    (df["카테고리"] == "커피")
    & (df["가격"] >= 4000)
]
```

### OR

```python
df[(조건A) | (조건B)]
```

### NOT

```python
df[~(조건A)]
```

Pandas에서는:

```text
and → &
or  → |
not → ~
```

여러 조건은 각각 괄호로 묶음.

---

## 6-3. 여러 후보 중 하나 찾기 → `isin()`

```python
df[df["음료"].isin(["커피", "차"])]
```

구조:

```python
Series.isin([값1, 값2, ...])
```

---

## 6-4. 일정 범위 찾기 → `between()`

```python
df[df["수량"].between(2, 4)]
```

→ `2 이상 4 이하`

# 7. 필요 없는 열을 지우거나 순서를 정리할 때

## 7-1. 열 삭제 → `drop()`

```python
df = df.drop(columns=["회원여부"])
```

- `columns=[...]` → 삭제할 열
- 기본적으로 새 DataFrame 반환
- 실제 반영하려면 다시 저장

---

## 7-2. 값 기준 정렬 → `sort_values()`

오름차순:

```python
df.sort_values("수량")
```

내림차순:

```python
df.sort_values(
    "수량",
    ascending=False
)
```

여러 기준:

```python
df.sort_values(
    ["카테고리", "수량"],
    ascending=[True, False]
)
```

→ 카테고리는 오름차순  
→ 같은 카테고리 안에서는 수량 내림차순

---

## 7-3. 정렬 후 인덱스 다시 정리 → `reset_index()`

```python
top = (
    df.sort_values("수량", ascending=False)
      .head(5)
      .reset_index(drop=True)
)
```

- `drop=True` → 기존 인덱스를 별도 열로 남기지 않음

---

## 7-4. 특정 열을 인덱스로 사용 → `set_index()`

```python
by_drink = df.set_index("음료")
```

원래 열도 유지:

```python
by_drink = df.set_index(

```

# 9. 문자열이 지저분할 때

문자열 열은 주로 `.str` 사용.

## 9-1. 앞뒤 공백 제거 → `str.strip()`

```python
df["음료"] = df["음료"].str.strip()
```

---

## 9-2. 특정 문자 바꾸기 → `str.replace()`

```python
df["가격"] = (
    df["가격"]
      .astype("string")
      .str.replace(",", "", regex=False)
)
```

- `regex=False` → 정규식이 아닌 일반 문자열 치환

---

## 9-3. 특정 문자가 들어 있는지 확인 → `str.contains()`

```python
df["음료"].str.contains(
    "라떼",
    na=False
)
```

- `na=False` → 결측값은 `False` 처리

---

## 9-4. 기타 문자열 처리

```python
df["음료"].str.lower()
df["음료"].str.upper()
df["음료"].str.len()
df["음료"].str.split(",")
```

| 문법 | 의미 |
|---|---|
| `.str.lower()` | 소문자 변환 |
| `.str.upper()` | 대문자 변환 |
| `.str.len()` | 문자열 길이 |
| `.str.split(",")` | 문자열 분리 |

---

# 10. 숫자처럼 보이지만 실제로 문자열일 때

## 10-1. 단순 자료형 변환 → `astype()`

```python
df["수량"] = df["수량"].astype(int)
```

문자열 변환:

```python
df["가격"].astype("string")
```

주의:

- 잘못된 값이 섞여 있으면 숫자 변환에서 오류 발생 가능

---

## 10-2. 안전하게 숫자로 변환 → `pd.to_numeric()`

```python
df["가격"] = pd.to_numeric(
    df["가격"],
    errors="coerce"
)
```

- `errors="coerce"` → 변환 실패 값을 `NaN`으로 변경

콤마가 들어 있는 가격:

```python
df["가격"] = pd.to_numeric(
    df["가격"]
      .astype("string")
      .str.replace(",", "", regex=False),
    errors="coerce"
)
```

처리 흐름:

```text
문자열로 통일
→ 콤마 제거
→ 숫자 변환
→ 실패한 값은 NaN
```

# 11. 날짜가 문자열로 들어왔을 때

## `pd.to_datetime()`

```python
df["주문일"] = pd.to_datetime(
    df["주문일"],
    errors="coerce"
)
```

- 잘못된 날짜 → `NaT`

## 날짜에서 연·월·일 추출 → `.dt`

```python
df["주문일"].dt.year
df["주문일"].dt.month
df["주문일"].dt.day
df["주문일"].dt.dayofweek
```

`dayofweek`:

```text
월요일 0
화요일 1
...
일요일 6
```

요일 열 생성:

```python
week_map = {
    0: "월",
    1: "화",
    2: "수",
    3: "목",
    4: "금",
    5: "토",
    6: "일",
}

df["요일"] = (
    df["주문일"]
      .dt.dayofweek
      .map(week_map)
)
```

# 12. 결측값이 있을 때

## 12-1. 결측 여부 확인 → `isna()`

```python
df["가격"].isna()
```

한 열의 결측 개수:

```python
df["가격"].isna().sum()
```

열별 결측 개수:

```python
df.isna().sum()
```

전체 결측 개수:

```python
df.isna().sum().sum()
```

---

## 12-2. 결측이 아닌 값 확인 → `notna()`

```python
df["가격"].notna()
```

---

## 12-3. 결측 행 제거 → `dropna()`

```python
df = df.dropna(
    subset=["가격"]
)
```

- `subset=[...]` → 결측 여부를 확인할 열

---

## 12-4. 결측값 채우기 → `fillna()`

주의:


이렇게만 실행하면 원본 열에 반영되지 않음.

# 13. 이상한 값이 있을 때

이상치는 자동으로 제거하기보다 실제 데이터 의미를 먼저 확인.

## 13-1. 특정 이상값을 가진 행 제거

```python
df = df[df["수량"] != 999]
```

---

## 13-2. 이상값을 결측값으로 변경 → `loc`

```python
df.loc[
    df["수량"] == 999,
    "수량"
] = np.nan
```

구조:

```python
df.loc[행 조건, 수정할 열] = 새 값
```

---

## 13-3. 최솟값·최댓값 제한 → `clip()`

```python
df["수량"] = df["수량"].clip(

    upper=10
)
```

- 1보다 작음 → 1
- 10보다 큼 → 10

---

## 13-4. 분위수 기준 확인 → `quantile()`

```python
limit = df["수량"].quantile(0.95)
```

→ 상위 약 5%가 시작되는 경계값 확인

# 14. 새로운 분석용 열을 만들 때

## 14-1. 기존 열끼리 계산

```python
df["총액"] = (
    df["가격"]
    * df["수량"]
)
```

---

## 14-2. 정해진 대응표로 바꾸기 → `map()`

```python
member_map = {
    "Y": "회원",
    "N": "비회원",
}

df["회원구분"] = (
    df["회원여부"]
      .map(member_map)
      .fillna("미확인")
)
```

- 대응표에 없는 값 → `NaN`
- 필요하면 `fillna()`로 처리

사용 기준:

```text
정해진 값 A → B 형태의 1:1 치환
```

---

## 14-3. 조건에 따라 둘 중 하나로 나누기 → `np.where()`

```python
df["주문규모"] = np.where(
    df["수량"] >= 4,
    "대량",
    "일반"
)
```

구조:

```python
np.where(
    조건,
    참일 때 값,
    거짓일 때 값
)
```

---

## 14-4. 직접 만든 규칙 적용 → `apply()`

```python
df["가격등급"] = df["가격"].apply(
    lambda x: "고가"
    if x >= 5000
    else "보통"
)
```

- `x` → 현재 처리 중인 값 하나

선택 기준:

```text
고정된 1:1 치환 → map()
두 가지 조건 분기 → np.where()
직접 만든 규칙 → apply()
```

# 17. 실제 정제 작업 전체 예시

```python
import os
import pandas as pd
import numpy as np

# 1. 데이터 읽기
df = pd.read_csv("주문내역.csv")

# 2. 데이터 상태 확인
print(df.shape)
print(df.head())
df.info()

# 3. 원본 보호
tidy = df.copy()

# 4. 문자열 정리
tidy["음료"] = (
    tidy["음료"]
      .astype("string")
      .str.strip()
)

# 5. 가격 숫자 변환
tidy["가격"] = pd.to_numeric(
    tidy["가격"]
      .astype("string")
      .str.replace(",", "", regex=False),
    errors="coerce"
)

# 6. 수량 숫자 변환
tidy["수량"] = pd.to_numeric(
    tidy["수량"],
    errors="coerce"
)

# 7. 이상치 처리
tidy.loc[
    tidy["수량"] == 999,
    "수량"
] = np.nan

# 8. 결측값 처리
tidy["가격"] = (
    tidy["가격"]
      .fillna(tidy["가격"].median())
      .round()
      .astype(int)
)

tidy["수량"] = (
    tidy["수량"]
      .fillna(tidy["수량"].median())
      .round()
      .astype(int)
)

# 9. 날짜 변환
tidy["주문일"] = pd.to_datetime(
    tidy["주문일"],
    errors="coerce"
)

# 10. 요일 생성
week_map = {
    0: "월", 1: "화", 2: "수",
    3: "목", 4: "금", 5: "토", 6: "일"
}

tidy["요일"] = (
    tidy["주문일"]
      .dt.dayofweek
      .map(week_map)
)

# 11. 파생 변수 생성
tidy["총액"] = (
    tidy["가격"]
    * tidy["수량"]
)

# 12. 결과 검증
print(tidy.head())
print(tidy.isna().sum())
print("총 매출:", tidy["총액"].sum())

# 13. 저장
os.makedirs(
    "output",
    exist_ok=True
)

tidy.to_csv(
    "output/정제결과.csv",
    index=False,
    encoding="utf-8-sig"
)
```

# 핵심 정리

함수 이름부터 외우기보다 **현재 데이터에서 무엇을 해야 하는지**를 먼저 판단.

```text
"데이터가 어떻게 생겼지?"
→ head(), info(), describe()

"필요한 행만 뽑고 싶은데?"
→ 조건 필터, loc, isin(), between()

"문자열과 숫자가 뒤섞였는데?"
→ .str, pd.to_numeric()

"빈 값이 있는데?"
→ isna(), fillna(), dropna()

"999 같은 이상한 값이 있는데?"
→ loc, clip(), quantile()

"분석에 쓸 새 열이 필요한데?"
→ 열 연산, map(), np.where(), apply()

"작업이 끝났는데?"
→ 검증 후 to_csv()
```

> 이 자료 범위에서는 데이터 불러오기·정제·변환 중심까지 다룸.  
> `groupby()`, `agg()`, `pivot_table()` 같은 그룹 집계 함수는 현재 교안 범위에 포함되어 있지 않아 추가하지 않음.
