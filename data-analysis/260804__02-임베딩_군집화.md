# 임베딩 기반 문서 군집화

## 1. 개념과 전체 흐름

임베딩 기반 군집화는 문장을 의미 벡터로 바꾼 뒤, 의미가 비슷한 문서끼리 자동으로 묶는 방법.

```text
문서
→ 임베딩
→ UMAP 차원 축소
→ HDBSCAN 군집화
→ 군집 검증
→ 새 문서 배정
```

| 단계 | 목적 | 핵심 도구 |
|---|---|---|
| 임베딩 | 문장의 의미를 숫자 벡터로 변환 | Sentence Transformer |
| 차원 축소 | 고차원 벡터를 낮은 차원으로 압축 | UMAP |
| 군집화 | 밀집된 문서끼리 자동 분류 | HDBSCAN |
| 검증 | 군집이 실제로 비슷한 문서를 묶었는지 확인 | 산점도·교차표·제목 확인 |
| 새 문서 배정 | 새 문서와 가장 가까운 군집 탐색 | 군집 대표 벡터·코사인 유사도 |

> 군집 번호는 단순 식별자.  
> `군집 2` 자체에 의미가 있는 것이 아니라, 내부 문서를 확인한 뒤 사람이 의미를 해석해야 함.

## 2. 임베딩 생성과 품질 확인

### 임베딩 저장이 필요한 이유

문서 임베딩은 계산 시간이 걸릴 수 있음.  
한 번 계산한 결과를 `.npy` 파일로 저장하면 다음 실행부터 바로 불러올 수 있음.

```python
import os
import numpy as np

emb_path = "data/news_embeddings.npy"

if os.path.exists(emb_path):
    # 기존 임베딩 재사용
    embeddings = np.load(emb_path)

else:
    # 기사 제목을 의미 벡터로 변환
    embeddings = emb_model.encode(
        news["title"].tolist(),
        show_progress_bar=False
    )

    # 다음 실행을 위해 저장
    np.save(emb_path, embeddings)

print(embeddings.shape)
```

예시 형태:

```text
(1800, 768)
```

- `1800`: 문서 수
- `768`: 문서 하나를 표현하는 벡터 차원 수
- `embeddings[i]`: `i`번째 문서의 임베딩

### 비슷한 문서 찾기로 임베딩 점검

기준 문서와 모든 문서의 코사인 유사도를 계산해 가까운 문서를 확인.

```python
from sklearn.metrics.pairwise import cosine_similarity

# 0번 문서와 전체 문서의 유사도
sims = cosine_similarity(
    embeddings[0:1],
    embeddings
)[0]

# 유사도 내림차순 정렬
# 첫 번째는 자기 자신이므로 제외
top3 = np.argsort(-sims)[1:4]

for i in top3:
    print(
        f"{sims[i]:.3f}",
        news.iloc[i]["title"]
    )
```

```python
embeddings[0:1]
```

- 2차원 형태 `(1, 768)` 유지
- `cosine_similarity()` 입력 형식에 맞추기 위한 슬라이싱

```python
np.argsort(-sims)
```

- `argsort()`는 값의 순서가 아니라 인덱스를 반환
- `-sims`를 사용해 큰 유사도부터 정렬

비슷한 문서들이 같은 분야나 비슷한 내용을 가진다면 임베딩이 의미를 비교적 잘 담고 있다는 신호.

## 3. UMAP 차원 축소

임베딩은 768차원이라 그대로는 눈으로 확인하기 어려움.  
UMAP을 사용해 가까운 문서 관계를 최대한 유지하면서 차원을 줄임.

이 예제에서는 산점도와 군집화에 사용할 **2차원 좌표**를 생성.

```python
from umap import UMAP

umap_model = UMAP(
    n_components=2,
    n_neighbors=15,
    min_dist=0.1,
    metric="cosine",
    random_state=42
)

umap2d = umap_model.fit_transform(embeddings)

print(umap2d.shape)
```

예시 형태:

```text
(1800, 2)
```

각 문서가 다음 좌표를 하나씩 가짐.

```text
[UMAP 1 좌표, UMAP 2 좌표]
```

### 주요 파라미터

| 파라미터 | 의미 | 값 변화 |
|---|---|---|
| `n_components` | 줄일 목표 차원 수 | `2`이면 평면 시각화 가능 |
| `n_neighbors` | 주변 이웃을 몇 개까지 참고할지 | 작으면 국소 구조, 크면 전체 구조를 더 반영 |
| `min_dist` | 축소된 점을 얼마나 가깝게 모을지 | 작을수록 점이 더 빽빽하게 모임 |
| `metric` | 원래 임베딩의 거리 계산 방식 | 문장 임베딩에는 주로 `"cosine"` |
| `random_state` | 난수 결과 고정 | 같은 조건에서 결과 재현 |

### UMAP 좌표 저장

UMAP도 계산 결과를 저장해 재사용 가능.

```python
umap_path = "data/news_umap2d.npy"

if os.path.exists(umap_path):
    umap2d = np.load(umap_path)

else:
    umap2d = umap_model.fit_transform(embeddings)
    np.save(umap_path, umap2d)
```

> 같은 좌표를 계속 사용하려면 임베딩 파일과 UMAP 좌표 파일을 함께 관리해야 함.

### 실제 분야별 분포 확인

```python
import matplotlib.pyplot as plt

plt.figure(figsize=(8, 6))

for category in news["category"].unique():
    mask = news["category"].values == category

    plt.scatter(
        umap2d[mask, 0],
        umap2d[mask, 1],
        s=8,
        alpha=0.6,
        label=category
    )

plt.title("뉴스 임베딩의 2차원 분포")
plt.xlabel("UMAP 1")
plt.ylabel("UMAP 2")
plt.legend()
plt.show()
```

같은 분야의 문서가 가까이 모이면 임베딩과 차원 축소가 분야 차이를 어느 정도 유지한 것.

단, UMAP 축의 숫자 자체에는 특별한 의미가 없음.  
점 사이의 상대적인 위치와 덩어리 구조를 확인하는 용도.

## 4. HDBSCAN 군집화

HDBSCAN은 문서가 밀집된 영역을 찾아 자동으로 군집을 만듦.

KMeans와 달리 군집 개수를 미리 지정하지 않으며, 어느 군집에도 안정적으로 포함되지 않는 문서는 `-1`로 분류.

```python
from hdbscan import HDBSCAN

hdb = HDBSCAN(
    min_cluster_size=15,
    metric="euclidean",
    cluster_selection_method="eom"
)

hdb_labels = hdb.fit_predict(umap2d)
```

### 결과 구조

```python
hdb_labels
```

각 문서의 군집 번호가 들어 있는 1차원 배열.

```text
[3, 3, -1, 0, 2, ...]
```

- `0`, `1`, `2` 등: 군집 번호
- `-1`: 특정 군집에 속하지 못한 노이즈 문서

### 주요 파라미터

| 파라미터 | 의미 |
|---|---|
| `min_cluster_size` | 하나의 군집으로 인정할 최소 문서 수 |
| `metric` | 입력 좌표 사이의 거리 계산 방식 |
| `cluster_selection_method="eom"` | 비교적 안정적인 밀집 영역을 군집으로 선택 |

`min_cluster_size` 변화:

```text
작게 설정 → 작은 군집까지 생성 → 군집이 잘게 나뉠 수 있음
크게 설정 → 작은 군집이 사라짐 → 군집 수가 줄어들 수 있음
```

### 군집 수와 노이즈 수 확인

```python
# -1을 제외한 군집 번호
group_ids = sorted(set(hdb_labels) - {-1})

n_groups = len(group_ids)
n_noise = int((hdb_labels == -1).sum())

print("군집 수:", n_groups)
print("노이즈 수:", n_noise)
```

군집별 문서 수:

```python
import pandas as pd

cluster_sizes = (
    pd.Series(hdb_labels)
      .value_counts()
      .sort_index()
      .rename_axis("군집 번호")
      .to_frame("문서 수")
)

display(cluster_sizes)
```

노이즈가 많다고 무조건 실패한 것은 아님.  
HDBSCAN이 밀도가 불충분하거나 애매한 문서를 억지로 군집에 넣지 않은 결과일 수 있음.

## 5. 군집 검증과 해석

군집 번호만 보고는 군집의 의미를 알 수 없음.  
다음 세 방법을 함께 사용해 확인.

### ① 군집 분포 시각화

```python
is_noise = hdb_labels == -1

plt.figure(figsize=(8, 6))

# 노이즈
plt.scatter(
    umap2d[is_noise, 0],
    umap2d[is_noise, 1],
    s=8,
    label="노이즈(-1)"
)

# 군집 문서
plt.scatter(
    umap2d[~is_noise, 0],
    umap2d[~is_noise, 1],
    c=hdb_labels[~is_noise],
    s=8,
    alpha=0.8
)

plt.title("HDBSCAN 군집 결과")
plt.xlabel("UMAP 1")
plt.ylabel("UMAP 2")
plt.legend()
plt.show()
```

확인할 내용:

- 서로 다른 군집이 공간상 구분되는지
- 특정 군집이 지나치게 크거나 작은지
- 노이즈가 어느 영역에 많이 존재하는지

### ② 실제 분야와 교차표 비교

실제 카테고리가 있다면 군집별 구성 확인에 사용 가능.

```python
tab = pd.crosstab(
    pd.Series(hdb_labels, name="군집 번호"),
    news["category"]
)

display(tab)
```

교차표 해석:

- 행: HDBSCAN이 만든 군집
- 열: 실제 기사 분야
- 값: 해당 조합의 문서 수

한 군집에 특정 분야가 많이 모였다면 군집이 의미 있는 구분을 만들었다고 볼 수 있음.

하지만 군집과 실제 분야가 반드시 일치할 필요는 없음.

```text
실제 분야: 스포츠
군집 결과: 야구 / 축구 / 감독·이적 / 국제대회 등
```

군집화는 기존 분야보다 더 좁은 주제 단위로 나눌 수 있음.

### ③ 군집 내부 문서 직접 확인

가장 중요한 검증 방법.  
같은 군집의 제목을 여러 개 읽고 공통 의미를 확인.

```python
sizes = pd.Series(hdb_labels).value_counts()

# 노이즈를 제외한 큰 군집 5개
top5 = [g for g in sizes.index if g != -1][:5]

for g in top5:
    in_group = hdb_labels == g

    main_category = (
        news.loc[in_group, "category"]
            .mode()[0]
    )

    print(
        f"[군집 {g}]",
        f"{int(in_group.sum())}건",
        f"주요 분야: {main_category}"
    )

    for title in news.loc[in_group, "title"].head(5):
        print(" -", title)

    print()
```

군집 이름은 다음 순서로 붙이는 것이 안전.

```text
군집 크기 확인
→ 주요 분야 확인
→ 대표 제목 여러 개 확인
→ 공통 주제를 사람이 요약
```

## 6. 새 문서를 기존 군집에 배정

각 군집에 속한 문서 임베딩의 평균을 구해 **군집 대표 벡터**를 만듦.

```python
group_ids = sorted(set(hdb_labels) - {-1})

centers = np.vstack([
    embeddings[hdb_labels == group_id].mean(axis=0)
    for group_id in group_ids
])

print(centers.shape)
```

형태:

```text
(군집 수, 768)
```

- 행 하나: 군집 하나의 대표 벡터
- 열 768개: 임베딩 차원

새 문서를 임베딩한 뒤 군집 대표 벡터와 코사인 유사도 계산.

```python
new_titles = [
    "프로야구 개막전 매진 행렬",
    "새 스마트폰 카메라 성능 공개"
]

new_vectors = emb_model.encode(new_titles)

sims = cosine_similarity(
    new_vectors,
    centers
)

nearest = [
    group_ids[i]
    for i in sims.argmax(axis=1)
]

result = pd.DataFrame({
    "새 문서": new_titles,
    "배정 군집": nearest,
    "최대 유사도": sims.max(axis=1).round(3)
})

display(result)
```

### 코드 해석

```python
sims.shape
```

```text
(새 문서 수, 군집 수)
```

각 새 문서와 모든 군집 대표 벡터의 유사도.

```python
sims.argmax(axis=1)
```

각 행에서 가장 높은 유사도의 열 위치를 선택.

```python
sims.max(axis=1)
```

선택된 군집과의 최대 유사도.

> `argmax()`는 가장 큰 값을 무조건 하나 선택함.  
> 최대 유사도가 낮더라도 군집 번호가 반환되므로, 결과와 기존 군집 문서를 함께 확인해야 함.

기존 문서 확인:

```python
for title, group_id in zip(new_titles, nearest):
    print(f"\n[{title}] → 군집 {group_id}")

    for old_title in news.loc[
        hdb_labels == group_id,
        "title"
    ].head(3):
        print(" -", old_title)
```

## 핵심 코드 흐름

```python
# 1. 문서 임베딩
embeddings = emb_model.encode(
    news["title"].tolist(),
    show_progress_bar=False
)

# 2. UMAP 차원 축소
umap_model = UMAP(
    n_components=2,
    n_neighbors=15,
    min_dist=0.1,
    metric="cosine",
    random_state=42
)

umap2d = umap_model.fit_transform(embeddings)

# 3. HDBSCAN 군집화
hdb = HDBSCAN(
    min_cluster_size=15,
    metric="euclidean",
    cluster_selection_method="eom"
)

hdb_labels = hdb.fit_predict(umap2d)

# 4. 군집별 크기 확인
cluster_sizes = pd.Series(hdb_labels).value_counts()

# 5. 군집 내부 문서 확인
for group_id in cluster_sizes.index:
    if group_id == -1:
        continue

    titles = news.loc[
        hdb_labels == group_id,
        "title"
    ].head(3)

    print(f"\n[군집 {group_id}]")
    print(titles.to_list())
```

## 핵심 치트시트

| 목적 | 코드·도구 |
|---|---|
| 문서를 의미 벡터로 변환 | `emb_model.encode(docs)` |
| 배열 저장 | `np.save(path, array)` |
| 배열 불러오기 | `np.load(path)` |
| 문서 유사도 계산 | `cosine_similarity()` |
| 낮은 차원으로 축소 | `UMAP().fit_transform()` |
| 밀도 기반 군집 생성 | `HDBSCAN().fit_predict()` |
| 군집 수 계산 | `len(set(labels) - {-1})` |
| 노이즈 수 계산 | `(labels == -1).sum()` |
| 군집별 크기 | `pd.Series(labels).value_counts()` |
| 실제 분야와 비교 | `pd.crosstab()` |
| 군집 대표 벡터 | 군집별 임베딩의 `mean(axis=0)` |
| 가장 가까운 군집 | `similarities.argmax(axis=1)` |

## 한 줄 정리

```text
임베딩 기반 군집화 =
문서를 의미 벡터로 변환
→ UMAP으로 관계를 유지하며 차원 축소
→ HDBSCAN으로 밀집된 문서 묶기
→ 교차표와 실제 제목으로 군집 의미 검증
→ 대표 벡터로 새 문서의 가까운 군집 탐색
```

> BERTopic은 이 임베딩·UMAP·HDBSCAN 흐름에 토큰화와 c-TF-IDF 대표 키워드 추출을 추가한 토픽 모델링 방식.
