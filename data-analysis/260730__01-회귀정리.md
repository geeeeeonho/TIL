# 선형회귀 정리

> **상관계수 `r` → 결정계수 `R²` → 회귀식 → 예측 → 회귀진단**

---

## 1. 데이터 준비

```python
import pandas as pd

raw = pd.read_csv("data/mpg.csv")

print(raw.shape)        # 행·열 개수
display(raw.head())     # 앞부분 확인
raw.info()              # 자료형·결측치 확인
display(raw.describe()) # 수치형 요약

print(raw["horsepower"].isna().sum())
```

회귀에 사용할 열 중 하나라도 결측이면 해당 행 제거.

```python
df = raw.dropna(
    subset=["mpg", "weight", "horsepower", "displacement"]

print(df.shape)  # 392행
```

```python
df["mpg"].dropna()
```

위 코드는 결과를 저장하지 않으므로 원본 `df`를 바꾸지 않는다.

## 2. 상관에서 회귀로

| 개념 | 의미 | 범위 |
|---|---|---:|
| 상관계수 `r` | 두 변수가 움직이는 방향과 강도 | `-1 ~ 1` |
| 결정계수 `R²` | 종속변수 변동을 모형이 설명하는 비율 | `0 ~ 1` |
| 회귀식 | 관계를 식으로 나타내 설명·예측 | `y = a + bx` |

단순 선형회귀에서 절편을 포함하면 다음이 성립한다.

```text
R² = r²
```

예:

```text
r = -0.832
R² ≈ 0.692
```

- 무게와 연비는 강한 음의 관계
- 무게 하나로 연비 변동의 약 69.2% 설명
- `R² = r²`는 독립변수가 하나인 단순회귀에서 성립
- 다중회귀에서는 하나의 상관계수를 제곱한 값과 같지 않음

## 3. 단순 선형회귀

### 무게로 연비 설명

```python
import statsmodels.formula.api as smf

model_weight = smf.ols(
    "mpg ~ weight",
    data=df
).fit()

print(model_weight.summary())
```

회귀식:

```text
예측 연비 = 46.2165 - 0.0076 × 무게
```

| 결과 | 값 | 해석 |
|---|---:|---|
| 절편 | `46.2165` | 무게가 0일 때 계산되는 기준값 |
| 무게 계수 | `-0.0076` | 무게 1파운드 증가 시 연비 약 0.0076 감소 |
| 무게 100파운드 | 약 `-0.76 mpg` | 무게 100파운드 증가 시 연비 약 0.76 감소 |
| `R²` | `0.693` | 연비 변동의 약 69.3% 설명 |
| 계수 p-value | `< 0.001` | 무게 효과가 통계적으로 유의 |
| 표본 수 | `392` | 회귀에 사용된 차량 수 |

### 회귀 결과에서 볼 값

| 항목 | 의미 |
|---|---|
| `R-squared` | 모형의 설명력 |
| `Adj. R-squared` | 변수 개수를 고려해 보정한 설명력 |
| `Prob (F-statistic)` | 모형 전체가 유의한지 확인 |
| `coef` | 독립변수 1 증가 시 종속변수의 평균 변화량 |
| `P>|t|` | 각 회귀계수가 유의한지 확인 |
| `[0.025, 0.975]` | 계수의 95% 신뢰구간 |
| `No. Observations` | 실제 사용된 행 수 |
| `Durbin-Watson` | 잔차의 자기상관 점검 |

출력에서 `P>|t| = 0.000`은 실제 값이 0이라는 뜻이 아니다.

```text
p < 0.001
```

처럼 해석한다.

---

### 대기시간으로 만족도 설명

```python
cc["wait"] = cc["대기시간_초"]
cc["sat"] = cc["만족도"]

model_wait = smf.ols(
    "sat ~ wait",
    data=cc
).fit()

print(model_wait.summary())
```

회귀식:

```text
예측 만족도 = 4.2537 - 0.00644 × 대기시간
```

| 결과 | 해석 |
|---|---|
| 대기시간 계수 `-0.00644` | 대기시간 1초 증가 시 만족도 약 0.00644점 감소 |
| 100초당 변화 | 만족도 약 0.644점 감소 |
| `R² = 0.4568` | 만족도 변동의 약 45.7% 설명 |
| p-value `< 0.001` | 대기시간 효과가 유의 |

```python
print("절편:", model_wait.params["Intercept"])
print("대기시간 계수:", model_wait.params["wait"])
print("계수 p-value:", model_wait.pvalues["wait"])
print("R²:", model_wait.rsquared)
```

새로운 값 예측:

```python
new_data = pd.DataFrame({
    "wait": [100, 200, 300]
})

display(model_wait.predict(new_data))
```

```text
100초 → 약 3.61점
200초 → 약 2.97점
300초 → 약 2.32점
```

## 4. 다중 선형회귀

여러 독립변수를 함께 넣어 종속변수를 설명한다.

```text
연비 = a + b₁(무게) + b₂(마력) + b₃(배기량)
```

```python
model_multi = smf.ols(
    "mpg ~ weight + horsepower + displacement",
    data=df
).fit()

print(model_multi.summary())
```

다중회귀의 계수는 **다른 변수를 고정한 상태**에서 해석한다.

```text
weight 계수
= horsepower와 displacement가 같다고 볼 때
  weight가 1 증가할 때의 평균 연비 변화
```

### 다중공선성

독립변수끼리 지나치게 강하게 연결된 상태.

예:

- 무게가 큰 차는 배기량도 큰 경우가 많음
- 배기량이 큰 차는 마력도 큰 경우가 많음

문제:

- 전체 설명력은 높아도 개별 변수 p-value가 커질 수 있음
- 계수의 부호와 크기가 불안정해질 수 있음

## 5. 범주형 변수 넣기

`statsmodels`에서는 `C()`를 사용하면 더미 변수를 자동 생성한다.

```python
model_origin = smf.ols(
    "mpg ~ weight + C(origin)",
    data=df
).fit()

print(model_origin.summary())
```

`europe`가 기준 범주일 때:

| 계수 | 의미 |
|---|---|
| `C(origin)[T.japan] = 1.3562` | 같은 무게에서 일본차가 유럽차보다 연비 약 1.36 높음 |
| `C(origin)[T.usa] = -0.9709` | 같은 무게에서 미국차가 유럽차보다 연비 약 0.97 낮음 |
| `weight = -0.0070` | 원산지가 같을 때 무게 1파운드당 연비 약 0.007 감소 |

원산지 계수의 p-value:

```text
일본: p = 0.057
미국: p = 0.141
```

둘 다 `0.05`보다 크므로 유의하다고 단정하기 어렵다.

모형 비교에는 `Adj. R²`를 함께 사용한다.

```python
print(
    "무게만:",
    model_weight.rsquared,
    model_weight.rsquared_adj
)

print(
    "무게+원산지:",
    model_origin.rsquared,
    model_origin.rsquared_adj
)
```

### 직접 원-핫 인코딩

```python
pd.get_dummies(cc["채널"])
```

```text
이메일 → 1, 0, 0
전화   → 0, 1, 0

```

절편이 있는 회귀모형에서는 기준 범주 하나를 제거한다.

```python
dummies = pd.get_dummies(
    cc["채널"],
    prefix="ch",
    drop_first=True,
    dtype=int
)

cc_d = pd.concat(
    [cc[["sat", "wait"]], dummies],
    axis=1
)
```

더 간단한 방법:

```python
cc["channel"] = cc["채널"]

model_channel = smf.ols(
    "sat ~ wait + C(channel)",
    data=cc
).fit()
```

> 모든 더미 변수와 절편을 함께 넣으면 완전한 다중공선성이 생긴다.  
> `drop_first=True` 또는 `C()`를 사용한다.

## 6. 회귀진단

잔차:

```text
잔차 = 실제값 - 예측값
```

```python
residuals = model_multi.resid
fitted = model_multi.fittedvalues
```

| 가정 | 의미 | 확인 방법 | 이상 신호 |
|---|---|---|---|
| 선형성 | 관계가 직선에 가까움 | 잔차 vs 적합값 | U자·곡선 무늬 |
| 등분산성 | 잔차 퍼짐이 일정함 | 잔차 vs 적합값 | 깔때기 모양 |
| 정규성 | 잔차가 정규분포에 가까움 | Q-Q Plot | 양 끝이 직선에서 벗어남 |
| 독립성 | 잔차끼리 관련이 없음 | Durbin-Watson | 2에서 크게 벗어남 |

### 잔차와 적합값

```python
import matplotlib.pyplot as plt
import seaborn as sns

fig, ax = plt.subplots(figsize=(10, 4.5))

sns.scatterplot(
    x=fitted,
    y=residuals,
    alpha=0.4,
    ax=ax
)

ax.axhline(0, color="red", linestyle="--")
ax.set_xlabel("적합값")
ax.set_ylabel("잔차")
plt.show()
```

좋은 상태:

```text
잔차가 0 주변에 특별한 무늬 없이 고르게 흩어짐
```

이상 신호:

```text
곡선 모양   → 선형성 위반
깔때기 모양 → 등분산성 위반
```

### Q-Q Plot

```python
import pingouin as pg

fig, ax = plt.subplots(figsize=(10, 4.5))

pg.qqplot(
    residuals,
    dist="norm",
    ax=ax
)

plt.show()
```

점들이 기준 직선을 따르면 정규성에 가깝다.

### 문서의 진단 결과

| 가정 | 관찰 결과 | 판단 |
|---|---|---|
| 선형성 | 구간별 잔차 평균이 U자 형태 | 위반 신호 |
| 등분산성 | 잔차 표준편차가 약 2.4 → 5.3으로 증가 | 위반 신호 |
| 정규성 | Q-Q 양 끝 이탈, p 약 `7e-7` | 위반 신호 |
| 독립성 | Durbin-Watson 약 `0.86` | 양의 자기상관 신호 |

### 가정이 깨졌을 때

| 신호 | 대처 |
|---|---|
| 곡선 관계 | 로그 변환·제곱항 추가 |
| 깔때기 모양 | 로그 변환·이분산 강건 표준오차 |
| Q-Q Plot 이탈 | 이상치 확인·변환 검토 |
| DW가 2에서 멂 | 시간·순서 변수 추가 또는 시계열 모형 검토 |

Durbin-Watson은 행의 순서에 영향을 받는다.  
시간 자료가 아닌 일반 데이터에서는 해석에 주의한다.

## 7. 코드·내용 수정점

### 변수 이름 구분

같은 `model` 이름을 반복 사용하지 않는다.

```python
model_weight
model_wait
model_multi
model_origin
```

### 출력문 수정

```python
print("대기시간의 기울기:", model_wait.params["wait"])
```

기존의 `"weight의 기울기"`는 잘못된 설명이다.

### 잘못 섞인 R²

```text
무게 단순회귀 R² ≈ 0.693
대기시간 단순회귀 R² ≈ 0.457
```

문서의 `무게만 R² = 0.4568`은 대기시간 모형 값이 섞인 결과다.

### 단위 확인

`weight` 단위는 파운드다.

```text
1톤 = 1000파운드
```

으로 바로 해석하면 안 된다.

### 순서형 변수 주의

순서형 값을 정수로 회귀에 넣으면 다음을 가정한다.

- 단계 간 간격이 같음
- 단계가 한 칸 증가할 때 효과가 일정함

이 가정이 맞지 않으면 `C()`로 범주형 처리한다.

## 총정리

| 작업 | 핵심 코드 | 의미 |
|---|---|---|
| 단순회귀 | `smf.ols("y ~ x", data=df).fit()` | 변수 하나로 설명 |
| 다중회귀 | `smf.ols("y ~ x1 + x2", data=df).fit()` | 여러 변수를 함께 통제 |
| 범주형 변수 | `C(category)` | 더미 변수 자동 생성 |
| 설명력 | `model.rsquared` | 종속변수 변동 설명 비율 |
| 보정 설명력 | `model.rsquared_adj` | 변수 개수를 고려한 설명력 |
| 계수 | `model.params` | 독립변수 1단위당 평균 변화 |
| 유의성 | `model.pvalues` | 계수의 통계적 유의성 |
| 예측 | `model.predict(new_data)` | 새로운 값 예측 |
| 잔차 | `model.resid` | 실제값과 예측값의 차이 |
| 적합값 | `model.fittedvalues` | 기존 데이터의 예측값 |
| 독립성 | `durbin_watson(model.resid)` | 잔차 자기상관 점검 |
