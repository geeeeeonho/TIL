## 1. 기술통계와 추론통계

| 구분 | 기술통계 `descriptive statistics` | 추론통계 `inferential statistics` |
|---|---|---|
| 목적 | 현재 가진 데이터를 요약·설명 | 표본으로 모집단의 특성을 추정·검정 |
| 질문 | 이 데이터는 어떻게 생겼나? | 전체도 이와 비슷할까? |
| 주요 도구 | 평균, 중앙값, 표준편차, 상관계수, 그래프 | 신뢰구간, 가설검정 |
| 결과 | 관찰 데이터에 대해서는 계산값이 확정 | 표본오차가 있어 확률적으로 해석 |

- **기술통계**: 중심, 퍼짐, 분포 모양, 변수 관계를 파악
- **추론통계**: 표본에서 계산한 값을 이용해 모집단을 추측

## 2. 데이터 유형과 측정척도

측정척도는 **가능한 계산과 적절한 요약 방법**을 결정한다.

| 유형 | 척도 | 뜻 | 예시 | 주로 가능한 계산 |
|---|---|---|---|---|
| 범주형 | 명목 `nominal` | 이름·분류만 있고 순서 없음 | 제조국, 혈액형, 결제수단 | 빈도, 비율, 최빈값 |
| 범주형 | 순서 `ordinal` | 순서는 있으나 단계 간 간격은 일정하지 않음 | 만족도 상·중·하, 등급 | 빈도, 중앙값, 순위 |
| 수치형 | 등간 `interval` | 간격은 일정하지만 절대적 0이 없음 | 섭씨온도, 연도 | 차이, 평균, 표준편차 |
| 수치형 | 비율 `ratio` | 간격이 일정하고 0이 실제로 ‘없음’을 뜻함 | 무게, 나이, 거리, 매출 | 모든 산술 계산, 배수 비교 |

> 섭씨 20℃가 10℃보다 두 배 따뜻하다고 할 수 없음. 0℃가 온도의 부재를 뜻하지 않기 때문.

## 3. 기술통계

### 3.1 중심을 나타내는 대표값

| 대표값 | 뜻 | Python | 특징 |
|---|---|---|---|
| 산술평균 `mean` | 합계 ÷ 개수 | `x.mean()` | 가장 흔함. 이상치에 민감 |
| 중앙값 `median` | 정렬했을 때 가운데 값 | `x.median()` | 이상치에 비교적 강함 |
| 최빈값 `mode` | 가장 자주 나온 값 | `x.mode()` | 범주형에도 사용. 여러 개일 수 있음 |
| 절사평균 `trimmed mean` | 양쪽 극단값 일부를 제거한 평균 | `stats.trim_mean(x, 0.1)` | 이상치 영향 완화 |
| 가중평균 `weighted mean` | 값마다 중요도·개수를 반영 | `np.average(x, weights=w)` | 비중이 다른 값을 결합할 때 사용 |

`stats.trim_mean(x, 0.1)`은 **하위 10%와 상위 10%를 각각 제거**한 뒤 평균을 계산한다.

```python
x = mpg['mpg'].dropna()

print('평균:', round(x.mean(), 3))
print('중앙값:', round(x.median(), 3))
print('최빈값:', x.mode().tolist())
print('절사평균:', round(stats.trim_mean(x, 0.1), 3))
```

#### 그룹 평균의 가중평균

그룹마다 데이터 수가 다르면 그룹 평균을 단순히 다시 평균 내면 전체 평균과 달라질 수 있다.

```python
group_stats = (
    mpg.groupby('origin')['mpg']
       .agg(mean='mean', count='count')
)

weighted_mean = np.average(
    group_stats['mean'],
    weights=group_stats['count']
)

print('그룹 평균의 단순평균:', group_stats['mean'].mean())
print('그룹 크기를 반영한 가중평균:', weighted_mean)
print('전체 평균:', mpg['mpg'].mean())
```

- `mean`: 그룹별 평균
- `count`: 평균 계산에 실제 사용된 값의 개수
- 그룹 평균에 그룹별 `count`를 가중치로 적용하면 전체 평균과 일치

### 3.2 퍼짐을 나타내는 산포도

| 지표 | 뜻 | Python |
|---|---|---|
| 범위 `range` | 최댓값 − 최솟값 | `x.max() - x.min()` |
| IQR | Q3 − Q1, 가운데 50%의 폭 | `stats.iqr(x)` |
| 표본분산 `variance` | 편차 제곱합 ÷ `(n-1)` | `x.var(ddof=1)` |
| 표본표준편차 `std` | 표본분산의 제곱근 | `x.std(ddof=1)` |
| 변동계수 `CV` | 표준편차 ÷ 평균 × 100 | `x.std() / x.mean() * 100` |

#### 표본과 모집단의 분산

- **모집단 분산**: 편차 제곱합을 `N`으로 나눔 → `ddof=0`
- **표본 분산**: 편차 제곱합을 `n-1`로 나눔 → `ddof=1`
- pandas의 `Series.var()`와 `Series.std()` 기본값은 `ddof=1`

#### 변동계수 사용 조건

CV는 단위를 없앤 **상대적 퍼짐**이다.

\[
CV = \frac{s}{\bar{x}} \times 100
\]

서로 단위나 평균 크기가 다른 자료의 변동성을 비교할 때 사용한다.

> CV는 절대적 0이 있는 **비율척도**에서 사용해야 한다. 평균이 0에 가깝거나 음수인 자료에서는 해석이 불안정하다.

### 3.3 이상치 판별

#### IQR 1.5배 규칙

\[
IQR = Q3-Q1
\]

- 하한: `Q1 - 1.5 × IQR`
- 상한: `Q3 + 1.5 × IQR`
- 하한보다 작거나 상한보다 크면 이상치 후보

```python
q1 = x.quantile(0.25)
q3 = x.quantile(0.75)
iqr = q3 - q1

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

outliers = x[(x < lower) | (x > upper)]
```

#### Z-score 규칙

\[
Z = \frac{x-\mu}{\sigma}
\]

- 평균에서 표준편차 몇 칸 떨어졌는지를 표시
- 보통 `|Z| > 3`을 이상치 후보로 봄
- 표본에서는 `μ`, `σ` 대신 표본평균과 표본표준편차를 사용 가능

```python
z = stats.zscore(x, nan_policy='omit')
outliers = x[np.abs(z) > 3]
```

> 이상치 규칙은 자동 삭제 기준이 아님. 입력 오류인지, 실제로 중요한 극단 사례인지 먼저 확인해야 한다. Z-score는 평균과 표준편차를 사용하므로 이상치 자체의 영향을 받으며, 심하게 치우친 분포에는 IQR 방식이 더 적합할 수 있다.

### 3.4 분포 모양: 왜도와 첨도

#### 왜도 `skewness`

분포가 좌우 어느 방향으로 치우쳤는지 나타낸다.

```python
x.skew()
```

- `왜도 > 0`: 오른쪽 꼬리가 김. 대체로 `평균 > 중앙값`
- `왜도 < 0`: 왼쪽 꼬리가 김. 대체로 `평균 < 중앙값`
- `왜도 ≈ 0`: 좌우 대칭에 가까움

평균과 중앙값의 관계는 흔한 경향일 뿐 항상 성립하는 법칙은 아니다.

#### 첨도 `kurtosis`

극단값과 꼬리의 두꺼움을 나타낸다.

```python
x.kurt()
```

pandas의 `.kurt()`는 **초과첨도**를 반환한다.

- `초과첨도 = 0`: 정규분포와 같은 기준
- `초과첨도 > 0`: 정규분포보다 꼬리가 두꺼워 극단값이 상대적으로 자주 나타남
- `초과첨도 < 0`: 정규분포보다 꼬리가 얇음

> 첨도를 단순히 “봉우리가 얼마나 뾰족한가”로만 해석하면 부정확하다. 핵심은 꼬리와 극단값 발생 가능성이다.

### 3.5 상관분석

상관계수는 두 변수 관계의 **방향과 강도**를 `-1 ~ 1` 범위로 요약한다.

#### 피어슨 상관계수 `Pearson r`

두 수치형 변수의 **선형 관계**를 측정한다.

- `r > 0`: 한 변수가 커질수록 다른 변수도 커지는 경향
- `r < 0`: 한 변수가 커질수록 다른 변수는 작아지는 경향
- `r ≈ 0`: 선형 관계가 약함
- `|r|`가 1에 가까울수록 선형 관계가 강함

| `|r|` | 흔히 사용하는 해석 |
|---:|---|
| 0.3 미만 | 약한 관계 |
| 0.3 ~ 0.7 | 중간 관계 |
| 0.7 초과 | 강한 관계 |

> 위 기준은 절대 규칙이 아님. 분야와 데이터 특성에 따라 해석 기준이 달라진다.

```python
mpg['mpg'].corr(mpg['weight'], method='pearson')
```

#### 스피어만 상관계수 `Spearman ρ`

값을 **순위로 바꾼 뒤 단조 관계**를 측정한다.

- 직선이 아니어도 한쪽 방향으로 계속 증가·감소하면 포착 가능
- 피어슨보다 이상치에 덜 민감
- 순서형 자료에도 사용 가능
- 동점이 많거나 복잡한 비단조 관계에서는 주의

```python
mpg['mpg'].corr(mpg['weight'], method='spearman')
```

#### 상관행렬 히트맵

```python
corr = mpg.corr(numeric_only=True, method='pearson')

sns.heatmap(
    corr,
    annot=True,
    cmap='coolwarm',
    fmt='.2f',
    vmin=-1,
    vmax=1
)
plt.title('수치형 변수 상관행렬')
plt.show()
```

- 대각선은 자기 자신과의 상관이라 항상 `1`
- 색은 방향과 크기를 빠르게 비교하는 용도
- 실제 모양은 산점도로 함께 확인

#### 상관분석의 한계

- 피어슨은 U자형 같은 비선형 관계를 놓칠 수 있음
- 이상치 하나가 상관계수를 크게 바꿀 수 있음
- 같은 상관계수라도 산점도 모양이 전혀 다를 수 있음
- 관찰 범위가 좁으면 상관이 약하게 보일 수 있음
- **상관관계는 인과관계를 증명하지 않음**

인과관계 확인에는 무작위 실험, A/B 테스트, 또는 적절한 인과추론 설계가 필요하다.

## 4. 확률의 기본

### 4.1 기본 법칙

| 법칙 | 뜻 | 식 |
|---|---|---|
| 여사건 | A가 일어나지 않을 확률 | `P(Aᶜ) = 1 - P(A)` |
| 덧셈법칙 | A 또는 B가 일어날 확률 | `P(A∪B) = P(A)+P(B)-P(A∩B)` |
| 조건부확률 | B가 일어난 상황에서 A의 확률 | `P(A|B) = P(A∩B)/P(B)` |
| 곱셈법칙 | A와 B가 모두 일어날 확률 | `P(A∩B) = P(A)P(B|A)` |

추가 관계:

- A와 B가 **서로 배반**이면 `P(A∩B)=0`
- A와 B가 **독립**이면 `P(A|B)=P(A)`이므로 `P(A∩B)=P(A)P(B)`
- 조건부확률 `P(A|B)`는 `P(B)>0`일 때 정의

---

### 4.2 확률변수, 기대값, 분산

- **확률변수 X**: 무작위 시행 결과를 숫자로 나타낸 변수
- **기대값 E[X]**: 각 값에 확률을 가중한 장기 평균
- **분산 Var(X)**: 값들이 기대값에서 얼마나 퍼져 있는지 표시

\[
E[X] = \sum_x xP(X=x)
\]

\[
Var(X) = \sum_x (x-E[X])^2P(X=x)
\]

분산의 다른 표현:

\[
Var(X)=E[X^2]-E[X]^2
\]

## 5. 확률분포

확률분포는 확률변수가 가질 수 있는 값과 그 확률을 나타낸다.

### 5.1 PMF · PDF · CDF · SF · PPF

| 약어 | 이름 | 의미 |
|---|---|---|
| PMF | Probability Mass Function | 이산형에서 각 값의 확률(이산형 특정값의 확률) `P(X=x)` |
| PDF | Probability Density Function | 연속형에서 구간 아래 넓이가 확률 |
| CDF | Cumulative Distribution Function | 연속형 구간의 확률 `F(x)=P(X≤x)` |
| SF | Survival Function | `P(X>x)=1-CDF(x)` |
| PPF | Percent Point Function | CDF의 역함수. 누적확률 → 경곗값 |

#### 확률분포의 두 종류 : 이산형과 연속형

- **이산형**: 값이 셀 수 있게 떨어짐. 예: 불량품 개수, 성공 횟수
    - 베르누이, 이상분포, 포아송
- **연속형**: 구간 안의 모든 실수값을 가질 수 있음. 예: 키, 시간, 무게
    - 균등분포, 지수 분포, 정규분포, t분포

연속형에서 PDF의 높이 자체는 확률이 아니다.

- 구간 확률 = PDF 아래의 **넓이**
- 정확히 한 점일 확률 `P(X=x)=0`
- PDF 값은 경우에 따라 1보다 클 수도 있지만 전체 넓이는 1

---

### 5.2 이산확률분포

#### 베르누이 분포

성공·실패처럼 결과가 두 개인 시행을 한 번 수행한다.

```python
bern = stats.bernoulli(p=0.3)

print('P(X=1):', bern.pmf(1))
print('P(X=0):', bern.pmf(0))
print('기대값:', bern.mean())
print('분산:', bern.var())
```

- 성공확률: `p`
- 기대값: `p`
- 분산: `p(1-p)`

#### 이항분포

독립적인 베르누이 시행을 `n`번 했을 때의 성공 횟수.

조건:

1. 시행 횟수 `n`이 고정
2. 각 시행 결과는 성공·실패 두 가지
3. 각 시행의 성공확률 `p`가 동일
4. 시행들이 서로 독립

```python
binom = stats.binom(n=20, p=0.05)

print('기대 불량 수:', binom.mean())
print('P(불량 0개):', binom.pmf(0))
print('P(불량 2개 이하):', binom.cdf(2))
print('P(불량 3개 이상):', binom.sf(2))
```

- 기대값: `np`
- 분산: `np(1-p)`

#### 포아송 분포

일정한 시간·공간 안에서 사건이 발생한 횟수를 모델링한다.

주요 가정:

- 평균 발생률 `λ`가 일정
- 사건이 서로 독립적으로 발생
- 매우 짧은 구간에서 여러 사건이 동시에 발생할 가능성이 매우 작음

```python
pois = stats.poisson(mu=3)

print('P(정확히 5회):', pois.pmf(5))
print('P(2회 이하):', pois.cdf(2))
print('기대값:', pois.mean())
print('분산:', pois.var())
```

- 기대값: `λ`
- 분산: `λ`

#### 이산형 확률의 경계

| 구하려는 확률 | SciPy |
|---|---|
| `P(X=k)` | `dist.pmf(k)` |
| `P(X≤k)` | `dist.cdf(k)` |
| `P(X<k)` | `dist.cdf(k-1)` |
| `P(X≥k)` | `dist.sf(k-1)` |
| `P(X>k)` | `dist.sf(k)` |

> 이산형에서 `sf(k)`는 `P(X>k)`이다. `P(X≥k)`를 구하려면 `sf(k-1)`을 사용한다.

### 5.3 연속확률분포

#### 균등분포

구간 `[a,b]`의 모든 위치가 동일한 밀도를 가진다.

```python
unif = stats.uniform(loc=0, scale=10)  # [0, 10]

print('평균:', unif.mean())
print('P(X≤3):', unif.cdf(3))
```

- SciPy: `stats.uniform(loc=a, scale=b-a)`
- 기대값: `(a+b)/2`
- 분산: `(b-a)²/12`

#### 지수분포

포아송 과정에서 다음 사건이 발생할 때까지의 대기시간을 모델링한다.

```python
expon = stats.expon(scale=1000)  # 평균 대기시간 1000

print('P(500 이내):', expon.cdf(500))
print('중앙값:', expon.median())
```

- SciPy: `stats.expon(scale=1/λ)`
- 기대값: `1/λ`
- 분산: `1/λ²`
- 무기억성: 이미 기다린 시간과 관계없이 남은 대기시간 분포가 동일

#### 정규분포

평균을 중심으로 좌우 대칭인 종 모양 분포.

```python
norm = stats.norm(loc=70, scale=10)  # 평균 70, 표준편차 10

print('P(X≥80):', norm.sf(80))
print('P(X≤60):', norm.cdf(60))
print('상위 10% 경계:', norm.ppf(0.90))
```

- SciPy: `stats.norm(loc=μ, scale=σ)`
- 기대값: `μ`
- 분산: `σ²`
- `scale`에는 분산이 아니라 **표준편차 σ**를 입력

#### 연속형 확률 계산

연속형에서는 한 점의 확률이 0이므로 `<`와 `≤`, `>`와 `≥`의 확률이 같다.

| 구하려는 값 | SciPy |
|---|---|
| `P(X≤x)` | `dist.cdf(x)` |
| `P(X≥x)` | `dist.sf(x)` |
| `P(a≤X≤b)` | `dist.cdf(b) - dist.cdf(a)` |
| 하위 `p` 비율 경계 | `dist.ppf(p)` |
| 상위 `p` 비율 경계 | `dist.ppf(1-p)` |

## 6. 표준화와 Z-score

서로 평균과 표준편차가 다른 값을 평균 0, 표준편차 1인 공통 척도로 변환한다.

\[
Z=\frac{x-\mu}{\sigma}
\]

- `Z=2`: 평균보다 표준편차 2개만큼 큼
- `Z=-1`: 평균보다 표준편차 1개만큼 작음
- 단위가 사라져 서로 다른 척도의 위치를 비교 가능

표본을 표준화할 때는 보통 다음을 사용한다.

\[
Z=\frac{x-\bar{x}}{s}
\]

```python
z = stats.zscore(x, nan_policy='omit')
```

### 정규분포의 68-95-99.7 법칙

정규분포에서만 적용되는 근사 규칙.

- 평균 ± 1σ: 약 68%
- 평균 ± 2σ: 약 95%
- 평균 ± 3σ: 약 99.7%

## 7. 추론통계

### 7.1 모집단과 표본

| 구분 | 모집단 `population` | 표본 `sample` |
|---|---|---|
| 대상 | 알고 싶은 전체 | 실제로 관찰한 일부 |
| 요약값 | 모수 `parameter` | 통계량 `statistic` |
| 평균 기호 | `μ` | `x̄` |
| 표준편차 기호 | `σ` | `s` |
| 성질 | 고정돼 있지만 보통 알 수 없음 | 표본을 다시 뽑으면 달라짐 |

추론이 타당하려면 표본의 크기뿐 아니라 **무작위성·대표성**도 중요하다. 큰 편향 표본은 크기가 커도 모집단을 제대로 설명하지 못한다.

---

### 7.2 표본분포와 중심극한정리

같은 크기의 표본을 반복해서 뽑아 평균을 계산하면 표본평균들도 하나의 분포를 만든다. 이것이 **표본평균의 표본분포**다.

중심극한정리:

- 독립적인 무작위 표본이며 모집단 분산이 유한하다는 등의 조건에서
- 표본크기 `n`이 충분히 커지면
- 모집단의 원래 모양이 정규분포가 아니어도 표본평균의 분포가 정규분포에 가까워짐

\[
\bar{X} \approx N\left(\mu, \frac{\sigma^2}{n}\right)
\]

표본평균의 평균은 `μ`, 표준편차는 `σ/√n`이다.

---

### 7.3 표준오차

표준오차 `SE`는 표본평균이 표본마다 얼마나 흔들리는지 나타낸다.

모표준편차를 아는 경우:

\[
SE=\frac{\sigma}{\sqrt{n}}
\]

모표준편차를 모르는 경우:

\[
SE\approx\frac{s}{\sqrt{n}}
\]

```python
se = stats.sem(sample)  # 기본 ddof=1
```

- `n`이 4배가 되면 SE는 절반
- 표본 수가 커질수록 추정이 정밀해짐

---

### 7.4 점추정과 구간추정

| 구분 | 의미 | 예시 |
|---|---|---|
| 점추정 | 모수를 숫자 하나로 추정 | `x̄ = 22.6` |
| 구간추정 | 오차를 포함한 범위로 추정 | `[19.5, 25.6]` |

점추정은 간단하지만 불확실성의 크기를 보여주지 못한다. 신뢰구간은 점추정값 주변에 오차범위를 붙인다.

\[
신뢰구간 = 점추정값 \pm 임계값 \times 표준오차
\]

---

### 7.5 평균의 신뢰구간

#### 어떤 분포를 사용할까?

- 모집단 표준편차 `σ`를 알고 있으면 정규분포 `z` 사용
- `σ`를 모르고 표본표준편차 `s`로 대신하면 t분포 사용
- 표본이 커질수록 t분포는 정규분포에 가까워짐

실무에서는 `σ`를 모르는 경우가 대부분이므로 평균 신뢰구간에는 t분포를 기본으로 사용하는 편이 안전하다.

```python
sample = mpg['mpg'].dropna().sample(n=30, random_state=42)
n = len(sample)
mean_hat = sample.mean()
se = stats.sem(sample)

ci_t = stats.t.interval(
    confidence=0.95,
    df=n - 1,
    loc=mean_hat,
    scale=se
)

print('t 기반 95% 신뢰구간:', ci_t)
```

모표준편차를 알고 있을 때:

```python
sigma = 10  # 알고 있다고 가정한 모집단 표준편차
se_known = sigma / np.sqrt(n)

ci_z = stats.norm.interval(
    confidence=0.95,
    loc=mean_hat,
    scale=se_known
)
```

#### t분포의 특징

- 정규분포와 비슷하지만 꼬리가 더 두꺼움
- 표본이 작아 생기는 추가 불확실성을 반영
- 자유도 `df=n-1`이 커질수록 정규분포에 가까워짐

#### 95% 신뢰구간의 올바른 해석

틀린 해석:

> 계산된 이 구간 안에 모평균이 있을 확률이 95%다.

올바른 해석:

> 같은 표본추출과 계산을 매우 많이 반복하면, 그렇게 만들어진 구간의 약 95%가 실제 모평균을 포함한다.

모평균은 고정값이고, 반복할 때 달라지는 것은 표본과 신뢰구간이다.

#### 신뢰수준과 구간 너비

- 신뢰수준 증가 → 임계값 증가 → 구간이 넓어짐
- 표본크기 증가 → 표준오차 감소 → 구간이 좁아짐
- 변동성 증가 → 표준오차 증가 → 구간이 넓어짐

주장한 모평균 값이 95% 신뢰구간 밖에 있으면, 같은 조건의 양측 5% 가설검정에서는 보통 귀무가설을 기각한다. 구간 안에 있다는 사실은 그 값이 참이라는 증명이 아니라, 현재 데이터와 뚜렷하게 모순되지 않는다는 뜻이다.

---

### 7.6 가설검정 기초

추론통계의 다른 핵심 도구. 원문에서 빠져 있던 부분을 보완한 내용.

- **귀무가설 `H₀`**: 차이·효과가 없다는 기본 주장
- **대립가설 `H₁`**: 차이·효과가 있다는 주장
- **유의수준 `α`**: H₀가 참인데도 기각할 위험의 기준. 흔히 0.05
- **p-value**: H₀가 참이라고 가정했을 때 현재 결과 이상으로 극단적인 결과가 나올 확률

판정:

- `p-value < α` → H₀ 기각
- `p-value ≥ α` → H₀를 기각할 근거 부족

> `H₀를 기각하지 못함`은 `H₀가 참이라고 증명됨`과 다르다.

오류:

| 오류 | 의미 |
|---|---|
| 1종 오류 | 참인 H₀를 잘못 기각 |
| 2종 오류 | 거짓인 H₀를 기각하지 못함 |

통계적 유의성과 실제 중요성도 구분해야 한다. 표본이 매우 크면 실제로는 작은 차이도 유의하게 나올 수 있으므로 효과크기와 신뢰구간을 함께 확인한다.

## 9. 최종 핵심정리

1. **중심**: 평균은 전체 크기를 반영하지만 이상치에 민감. 중앙값은 이상치에 강함.
2. **퍼짐**: 표준편차는 원래 단위, CV는 상대적 퍼짐. 표본분산은 `n-1`로 나눔.
3. **분포 모양**: 왜도는 좌우 치우침, 첨도는 꼬리와 극단값의 정도.
4. **상관**: 피어슨은 선형 관계, 스피어만은 순위 기반 단조 관계. 상관은 인과가 아님.
5. **확률분포**: 이산형은 PMF, 연속형은 PDF의 넓이, 누적확률은 CDF.
6. **표준화**: Z-score는 평균으로부터 표준편차 몇 개만큼 떨어졌는지 표시.
7. **중심극한정리**: 조건이 맞고 `n`이 충분히 크면 표본평균 분포가 정규분포에 가까워짐.
8. **표준오차**: `SE = s/√n`. 표본이 커질수록 평균 추정의 흔들림이 작아짐.
9. **신뢰구간**: 점추정값에 불확실성을 포함한 범위. 모표준편차를 모르면 보통 t분포 사용.
10. **가설검정**: p-value는 귀무가설이 참일 확률이 아니라, 귀무가설 아래에서 현재 결과 이상이 나올 확률.
