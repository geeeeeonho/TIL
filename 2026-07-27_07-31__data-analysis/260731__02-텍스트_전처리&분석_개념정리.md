# 텍스트 전처리 02

한국어 텍스트를 **정제 → 형태소 분석 → 불용어 제거 → 수치화 → 핵심어·연관어 분석 → 시각화**하는 과정.

---

## 1. 전체 흐름

```text
원문 텍스트
→ 정제
→ 토큰화·형태소 분석
→ 필요한 품사만 선택
→ 불용어 제거
→ 빈도·TF-IDF·n-gram 분석
→ 그래프·워드클라우드·연관어 네트워크
```

| 단계 | 도구 | 역할 |
|---|---|---|
| 정제 | `re`, `unicodedata` | URL·이메일·특수문자 제거, 표기 통일 |
| 형태소 분석 | `kiwipiepy` | 문장을 형태소로 분리하고 품사 부착 |
| 빈도 분석 | `Counter` | 단어별 등장 횟수 계산 |
| 수치화 | `CountVectorizer` | 문서를 단어 개수 벡터로 변환 |
| 핵심어 분석 | `TfidfVectorizer` | 문서별 중요한 단어 계산 |
| 연관 분석 | n-gram, 동시 출현 | 붙어 나오는 표현과 관련 단어 탐색 |
| 시각화 | `matplotlib`, `wordcloud` | 막대그래프·워드클라우드·네트워크 |

## 2. 텍스트 정제

### 정제 종류

- **제거**: URL, 이메일, 특수문자, 이모티콘 삭제
- **정규화**: 대소문자, 공백, 반복 문자 등 표기 통일
- **유니코드 정규화**: 같은 글자의 저장 방식 차이 통일

```python
import re
import unicodedata

def clean(text):
    text = unicodedata.normalize("NFC", text)       # 유니코드 통일
    text = text.lower()                             # 영문 소문자 통일
    text = re.sub(r"https?://\S+", " ", text)       # URL 제거
    text = re.sub(
        r"[\w.+-]+@[\w-]+\.[\w.]+",
        " ",
        text
    )                                               # 이메일 제거
    text = re.sub(
        r"[^가-힣a-zA-Z0-9\s]",
        " ",
        text
    )                                               # 특수문자 제거
    text = re.sub(r"\s+", " ", text).strip()        # 연속 공백 정리
    return text
```

### 정규표현식 핵심

| 패턴 | 의미 |
|---|---|
| `\d` | 숫자 한 글자 |
| `\w` | 문자·숫자·밑줄 |
| `\s` / `\S` | 공백 / 공백이 아닌 문자 |
| `.` | 줄바꿈을 제외한 아무 문자 |
| `[가-힣]` | 완성형 한글 |
| `[^가-힣]` | 완성형 한글이 아닌 문자 |
| `+` | 1회 이상 |
| `*` | 0회 이상 |
| `?` | 0회 또는 1회 |
| `{2,3}` | 2~3회 |
| `^` / `$` | 문자열 시작 / 끝 |
| `( )` | 패턴 그룹 |
| `&#124;` | 또는 |

정규표현식은 일반적으로 `r"패턴"` 형태의 **raw string**으로 작성.

```python
r"\b커피\b"
```

`r`을 사용하면 `\b`, `\d` 같은 문자를 파이썬이 먼저 해석하지 않고 정규표현식에 그대로 전달.

### `re` 주요 함수

```python
re.findall(pattern, text)            # 모든 결과를 리스트로 반환
re.search(pattern, text)             # 첫 번째 결과 반환, 없으면 None
re.sub(pattern, replacement, text)   # 검색 후 변경 또는 삭제
re.compile(pattern)                  # 반복 사용할 패턴을 미리 생성
```

## 3. 형태소 분석과 토큰화

한국어는 조사와 어미가 단어에 붙는 **교착어**.

```text
커피랑   → 커피/NNG + 랑/JKB
분위기가 → 분위기/NNG + 가/JKS
맛있어요 → 맛있/VA + 어요/EF
```

띄어쓰기만으로 나누지 않고 뜻을 가진 최소 단위인 **형태소**로 분리.

### 주요 품사 태그

| 태그 | 의미 | 예 |
|---|---|---|
| `NNG` | 일반 명사 | 커피, 분위기, 주차 |
| `NNP` | 고유 명사 | 티라미수, 상호명 |
| `VV` | 동사 | 가다, 먹다 |
| `VA` | 형용사 | 좋다, 맛있다 |
| `MAG` | 일반 부사 | 정말, 너무 |
| `JKS` | 주격 조사 | 이, 가 |
| `JKB` | 부사격 조사 | 에, 랑 |
| `JX` | 보조사 | 은, 는 |
| `EF` | 종결 어미 | 어요 |
| `EC` | 연결 어미 | 고, 지만 |

### 명사 토큰 추출

```python
from kiwipiepy import Kiwi

kiwi = Kiwi()

def tokenize(text):
    return [
        token.form
        for token in kiwi.tokenize(text)
        if token.tag in ("NNG", "NNP")
        and len(token.form) > 1
    ]
```

```python
text = "커피 맛이 정말 좋아요. 원두 향이 진하고 라떼도 부드러워요."

print(tokenize(clean(text)))
# ['커피', '원두', '라떼']
```

신조어나 브랜드명을 제대로 분석하지 못하면 사용자 사전에 등록.

```python
kiwi.add_user_word("아아", "NNG")
```

## 4. 불용어 제거

**불용어**: 자주 등장하지만 분석에 의미를 거의 주지 않는 단어.

```python
STOPWORDS = {
    "후기",
    "정도",
    "이용",
    "진짜"
}

tokens = [
    word
    for word in tokens
    if word not in STOPWORDS
    and len(word) > 1
]
```

전처리 결과:

```text
"라떼 향이 좋아요!!"
→ 특수문자 제거
→ 라떼/NNG, 향/NNG, 이/JKS, 좋/VA
→ 명사만 선택
→ 라떼, 향
```

## 5. 빈도와 BoW

### 단어 빈도

```python
from collections import Counter

freq = Counter(tokens)
print(freq.most_common(10))
```

- 막대그래프: 정확한 빈도 비교
- 워드클라우드: 빈도가 높은 단어를 크게 표시

### BoW

**Bag of Words**: 단어의 순서를 버리고 각 단어의 등장 횟수만 저장하는 방식.

```python
import pandas as pd
from sklearn.feature_extraction.text import CountVectorizer

corpus = [" ".join(tokens) for tokens in docs]

cv = CountVectorizer(
    token_pattern=r"(?u)\b\w+\b"
)

X = cv.fit_transform(corpus)

dtm = pd.DataFrame(
    X.toarray(),
    columns=cv.get_feature_names_out()
)
```

`DTM` 구조:

```text
행: 문서
열: 단어
값: 해당 문서에서 단어가 등장한 횟수
```

```text
        커피  라떼  디저트  주차
리뷰1     1     1      0     0
리뷰2     0     0      0     0
리뷰3     0     0      0     0
```

## 6. TF-IDF

단순 빈도는 모든 문서에 흔히 나오는 단어도 중요하게 평가하는 문제 존재.

**TF-IDF = TF × IDF**

- `TF`: 현재 문서에서 단어가 나온 횟수
- `DF`: 전체 문서 중 해당 단어가 등장한 문서 수
- `IDF`: 여러 문서에 흔하게 나올수록 점수를 낮춤
- 개념식: `log(N / df)`

```python
from sklearn.feature_extraction.text import TfidfVectorizer

tv = TfidfVectorizer(
    token_pattern=r"(?u)\b\w+\b"
)

T = tv.fit_transform(corpus)
words = tv.get_feature_names_out()
```

### 문서별 상위 핵심어

```python
for i in [0, 5, 12]:
    scores = T[i].toarray()[0]
    top3 = scores.argsort()[::-1][:3]

    result = [
        f"{words[j]}({scores[j]:.3f})"
        for j in top3
    ]

    print(i, result)
```

### TF-IDF 활용

- 문서별 핵심어 추출
- 검색 결과 순위 계산
- 코사인 유사도를 이용한 유사 문서 검색
- 긍정·부정 분류
- 비슷한 주제의 문서 군집화
- 머신러닝 모델의 입력값 생성

### 주요 파라미터

| 파라미터 | 역할 |
|---|---|
| `min_df` | 너무 적은 문서에 나온 단어 제거 |
| `max_df` | 너무 많은 문서에 나온 흔한 단어 제거 |
| `ngram_range` | 여러 단어로 이루어진 표현 포함 |
| `max_features` | 점수 상위 N개 단어만 사용 |
| `sublinear_tf=True` | 지나치게 반복된 단어의 영향 완화 |

```python
TfidfVectorizer(
    min_df=2,
    max_df=0.5,
    ngram_range=(1, 2),
    max_features=1000,
    sublinear_tf=True
)
```

## 7. n-gram과 동시 출현

### n-gram

서로 바로 붙어 있는 단어를 하나의 표현으로 처리.

```text
unigram: 주차, 불편, 공간
bigram: 주차 불편, 주차 공간
trigram: 노트북 작업 카페
```

```python
tv = TfidfVectorizer(
    ngram_range=(1, 2)
)
```

한계: 단어가 서로 떨어져 있으면 하나의 표현으로 잡지 못함.

### 동시 출현

같은 문서에 함께 등장한 단어의 관계를 계산.

```text
n-gram
- 바로 옆에 있어야 함
- "주차 불편"

동시 출현
- 같은 문서 안에만 있으면 됨
- "직원 ... 가격"
```

계산 순서:

```text
문서-단어 행렬 B
→ 전치 행렬 B.T
→ B.T @ B
→ 단어끼리 같은 문서에 나온 횟수
```

```python
cv = CountVectorizer(
    binary=True,
    token_pattern=r"(?u)\b\w+\b"
)

B = cv.fit_transform(corpus)

co_matrix = (B.T @ B).toarray()
```

- 대각선: 해당 단어가 등장한 문서 수
- 대각선 이외: 두 단어가 함께 등장한 문서 수

시각화:

- 동시 출현 행렬 → 히트맵
- 단어 관계 → 네트워크 그래프
- 노드 크기 → 단어 빈도
- 선 굵기 → 두 단어의 동시 출현 횟수

re.sub(r"[^가-힣a-zA-Z0-9\s]", " ", text)

re.sub(r"\s+", " ", text).strip()

# 형태소 분석
kiwi.tokenize(text)

# 명사만 선택
token.tag in ("NNG", "NNP")

# 빈도 분석
Counter(tokens).most_common(10)

# BoW
CountVectorizer(token_pattern=r"(?u)\b\w+\b")

# TF-IDF
TfidfVectorizer(token_pattern=r"(?u)\b\w+\b")

# unigram + bigram

CountVectorizer(binary=True)
