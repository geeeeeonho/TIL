깃허브
기본생성: git init

확인하기: git config --global --list

깃 이그노어:
여기에 선언된 파일은 깃으로 관리 안함

주소 추가:
git remote add origin 깃허브_리포지토리_주소

주소 추가 확인:
git remote -v

(1)현재 변경 모두 깃에 추가:
git add .

(2)그 버전을 저장:
git commit -m “원하는 버전 혹은 커밋이름”

Copy relative path를 복사해서 개별 저장-커밋이 가능.
git add 불여넣은_경로

로그로 커밋과 같은 기록 확인 가능:
git log

깃에 저장이 안된 변경이 있는 파일은 vscode에서 파일 옆에 M 이 표시됨.

(3)깃 레포지토리에 올리기(처음에만):
git push -u origin main 

(4)깃 레포지토리에 올리기(처음이후)
git push 

깃허브 최신 버전(리포지토리 가져오기)
git pull

—
바로 등록도 가능함

이미 생성된 깃 리포지토리를 이용해 주소-연결 바로하기
git clone 깃허브_리포지토리_주소
