## 0. 사용하는 도구


|---|---|---|
| 정규성 | `pg.normality()` | `pg.qqplot()` |
| 등분산성 | `pg.homoscedasticity()` | Levene 검정 |
| t-검정 | `pg.ttest()` | 효과크기·신뢰구간 포함 |
| Mann-Whitney U | `pg.mwu()` | RBC·CLES 포함 |
| Wilcoxon | `pg.wilcoxon()` | RBC·CLES 포함 |
| 일반 ANOVA | `pg.anova()` | 부분 η² 포함 |
| Welch ANOVA | `pg.welch_anova()` | 이분산 집단 비교 |
| Tukey | `pg.pairwise_tukey()` | 일반 ANOVA 사후검정 |
| Games-Howell | `pg.pairwise_gameshowell()` | Welch ANOVA 사후검정 |
| Dunn | `sp.posthoc_dunn()` | Pingouin 미지원 |

> [!NOTE]
> Pingouin은 검정 결과를 DataFrame으로 반환해 `p-value`, 신뢰구간, 효과크기를 한 번에 확인하기 좋음.  
> 회귀분석은 Pingouin이 아니라 `statsmodels`의 `smf.ols()` 사용.

# 1. 전체 가설검정 흐름

```text
① 질문과 가설 설정
   ↓
② 유의수준 α 설정
   ↓
③ 변수 유형과 비교 구조 확인
   ├─ 수치형 평균·값 비교
   └─ 범주형 빈도·관련성 비교
   ↓
④ 가정 점검
   ├─ 독립성
   ├─ 정규성
   ├─ 등분산성
   └─ 카이제곱 기대빈도
   ↓
⑤ 검정 선택·수행
   ↓
⑥ p-value로 유의성 판단
   ↓
⑦ 효과크기로 차이의 크기 판단
   ↓
⑧ 실제 값으로 방향 판단
   ↓
⑨ 필요하면 사후검정·사후분석
   ↓
⑩ 결론 작성
```

## 검정 선택표

| 상황 | 기본 검정 | 가정이 맞지 않을 때 | 유의 후 분석 |
|---|---|---|---|
| 한 집단 vs 기준값 | 1표본 t | Wilcoxon 부호순위 | 효과크기 |
| 같은 대상 전·후 | 대응표본 t | Wilcoxon 부호순위 | 효과크기 |
| 독립 두 집단 | Student t / Welch t | Mann-Whitney U | 효과크기 |
| 독립 세 집단 이상 | 일반 ANOVA / Welch ANOVA | Kruskal-Wallis | Tukey / Games-Howell / Dunn |
| 범주 1개 분포 | 카이제곱 적합도 | 정확 다항검정 등 | Cohen's w |
| 범주 2개 관련성 | 카이제곱 독립성 | 작은 `2×2`는 Fisher | Cramér's V·조정잔차 |

# 2. 가설과 유의수준

## 2.1 가설 설정

```text
H₀: 차이·효과·관계가 없다.
H₁: 차이·효과·관계가 있다.
```

예:

```text
H₀: 두 집단 평균은 같다.
H₁: 두 집단 평균은 다르다.
```

## 2.2 유의수준과 p-value

| 구분 | 유의수준 `α` | p-value |
|---|---|---|
| 결정 시점 | 분석 전에 정함 | 데이터로 계산 |
| 역할 | 판정 기준선 | H₀ 아래에서 관측 결과가 드문 정도 |
| 일반값 | 보통 `0.05` | 데이터마다 다름 |

```text
p-value < α
→ H₀ 기각
→ 통계적으로 유의

p-value ≥ α
→ H₀ 기각 못 함
→ 차이가 없다는 확정이 아니라 증거 부족
```

> [!WARNING]
> p-value는 다음을 뜻하지 않음.
>
> - H₀가 참일 확률
> - 결과가 우연일 확률
> - 효과의 크기

## 2.3 양측검정과 단측검정

| 설정 | 대립가설 | Pingouin |
|---|---|---|
| 양측 | 다르다 `≠` | `alternative='two-sided'` |
| 왼쪽 단측 | 더 작다 `<` | `alternative='less'` |
| 오른쪽 단측 | 더 크다 `>` | `alternative='greater'` |

```python
pg.ttest(x, 기준값, alternative='two-sided')
pg.ttest(x, 기준값, alternative='less')
pg.ttest(x, 기준값, alternative='greater')
```

> [!IMPORTANT]
> 단측 방향은 **데이터를 보기 전에** 정함.  
> 결과를 본 뒤 유리한 방향으로 바꾸면 1종 오류가 커짐.

# 3. Pingouin 결과표 읽기

## 3.1 결론에 우선 사용하는 값

```text
1. 유의한가?     → p-value
2. 얼마나 큰가? → 효과크기
3. 어느 방향인가? → 평균·중앙값·비율·diff
```

| 열 | 의미 | 읽는 법 |
|---|---|---|
| `p_val`, `pval`, `p_unc` | p-value | `< 0.05`면 유의 |
| `p_tukey` | Tukey 보정 p-value | `< 0.05`면 해당 쌍이 유의 |
| `cohen_d` | t-검정 효과크기 | `|d|`로 크기 해석 |
| `hedges` | 소표본 보정 효과크기 | 기준은 Cohen's d와 비슷 |
| `RBC` | 순위 기반 효과크기 | 부호=방향, 절댓값=크기 |
| `cramer` | Cramér's V | 범주형 연관 강도 |
| `np2` | 부분 에타제곱 | 집단 효과의 크기 |
| `normal` | 정규성 판정 | `True`면 정규성 기각 못 함 |
| `equal_var` | 등분산 판정 | `True`면 등분산 기각 못 함 |
| `mean_A`, `mean_B`, `diff` | 실제 평균·차이 | 차이 방향 확인 |

> [!NOTE]
> Pingouin의 `np2`는 **부분 에타제곱(partial η²)**.  
> 일원 ANOVA에서는 η²와 값이 같아질 수 있지만 이름은 구분.

## 3.2 참고로 보는 값

| 열 | 의미 |
|---|---|
| `T`, `F`, `U_val`, `W_val`, `chi2`, `H` | 검정통계량 |
| `dof`, `DF`, `ddof1`, `ddof2` | 자유도 |
| `CI95` | 95% 신뢰구간 |
| `alternative` | 양측·단측 방향 |
| `CLES` | 첫 번째 집단 값이 두 번째보다 클 확률 |
| `power` | 관측 효과크기로 사후 계산한 검정력 |
| `BF10` | 베이즈 인자 |

> [!NOTE]
> `power`는 실험 전에 표본 수를 정할 때 사용하는 검정력과 다름.  
> 관측 검정력은 결론의 핵심 근거로 사용하지 않음.

# 4. 가정 점검

## 4.1 독립성

관측값끼리 서로 영향을 주지 않아야 함.

```text
서로 다른 대상 → 독립표본
같은 대상의 전·후 → 대응표본
```

독립성은 함수보다 **자료 수집 방식**으로 판단.

## 4.2 정규성

### 한 열 확인

```python
normality = pg.normality(df['값열'])
display(normality)
```

### 집단별 확인

```python
normality = pg.normality(
    data=df,
    dv='값열',
    group='집단열'
)
display(normality)
```

### Q-Q Plot

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6, 5))
pg.qqplot(df['값열'], dist='norm', ax=ax)
ax.set_title('Q-Q Plot')
plt.show()
```

```text
pval > 0.05, normal=True
→ 정규성을 기각하지 못함

pval < 0.05, normal=False
→ 정규성 위배 가능성
```

> [!IMPORTANT]
> 정규성은 Shapiro-Wilk 결과만으로 결정하지 않음.  
> Q-Q Plot·표본 크기·이상치·분포 모양을 함께 확인.

## 4.3 등분산성

독립된 두 집단 또는 세 집단 이상에서 확인.

```python
variance = pg.homoscedasticity(
    data=df,
    dv='값열',
    group='집단열'
)
display(variance)
```

```text
equal_var=True
→ Student t / 일반 ANOVA

equal_var=False
→ Welch t / Welch ANOVA
```

> [!NOTE]
> 1표본 t와 대응표본 t에는 집단 간 등분산 검정이 필요 없음.  
> 대응표본은 **전·후 차이값의 정규성**을 확인.

## 4.4 가정 조합에 따른 선택

| 정규성 | 등분산성 | 독립 2집단 | 독립 3집단 이상 |
|---|---|---|---|
| 만족 | 만족 | Student t | 일반 ANOVA |
| 만족 | 불만족 | Welch t | Welch ANOVA |
| 크게 위배 | 판단 불필요 | Mann-Whitney U | Kruskal-Wallis |

> [!CAUTION]
> 표본이 크다고 정규성 위배를 항상 무시하는 것은 아님.  
> 심한 왜도·극단적 이상치·집단별 표본 수 불균형이 있으면 Welch 또는 비모수 검정을 함께 고려.

# 5. t-검정

## 5.1 1표본 t-검정

한 집단 평균과 기준값 비교.

```python
x = df['값열']

# 가정 확인
display(pg.normality(x))

# 검정
result = pg.ttest(x, 기준값)
display(result)

# 실제 값
print('표본 평균:', x.mean())
```

결론에 사용할 값:

```text
p_val + cohen_d + 표본 평균 + CI95
```

## 5.2 대응표본 t-검정

같은 대상의 전·후 비교.

```python
before = df['전']
after = df['후']
diff = after - before

# 차이값의 정규성
display(pg.normality(diff))

# 대응 t-검정
result = pg.ttest(after, before, paired=True)
display(result)

print('평균 변화(후-전):', diff.mean())
```

> [!NOTE]
> 인자 순서가 방향을 결정함.
>
> ```python
> pg.ttest(after, before, paired=True)
> ```
>
> `diff = after - before`와 같은 방향으로 맞추면 해석이 쉬움.

## 5.3 독립 2표본 t-검정

서로 다른 두 집단 평균 비교.

```python
a = df.loc[df['집단열'] == 'A', '값열']
b = df.loc[df['집단열'] == 'B', '값열']

# 집단별 정규성
display(pg.normality(df, dv='값열', group='집단열'))

# 등분산성
var_result = pg.homoscedasticity(
    data=df,
    dv='값열',
    group='집단열'
)
display(var_result)

equal_var = bool(var_result['equal_var'].iloc[0])

# True면 Student, False면 Welch
result = pg.ttest(a, b, correction=not equal_var)
display(result)

print('A 평균:', a.mean())
print('B 평균:', b.mean())
```

# 6. 비모수 검정

## 6.1 검정 대응 관계

| 상황 | 모수 검정 | 비모수 대안 |
|---|---|---|
| 한 집단 vs 기준값 | 1표본 t | Wilcoxon 부호순위 |
| 같은 대상 전·후 | 대응 t | Wilcoxon 부호순위 |
| 독립 두 집단 | 독립 t | Mann-Whitney U |
| 독립 세 집단 이상 | ANOVA | Kruskal-Wallis |

## 6.2 Mann-Whitney U

독립된 두 집단의 순위·분포 위치 비교.

```python
a = df.loc[df['집단열'] == 'A', '값열']
b = df.loc[df['집단열'] == 'B', '값열']

result = pg.mwu(a, b)
display(result)

print('A 중앙값:', a.median())
print('B 중앙값:', b.median())
```

주요 열:

```text
U_val → 검정통계량
p_val → 유의성
RBC   → 효과크기·방향
CLES  → A에서 뽑은 값이 B보다 클 확률
```

> [!CAUTION]
> Mann-Whitney U는 단순한 평균 검정이 아님.  
> 두 집단의 분포 모양이 비슷할 때 중앙값 차이로 해석하기 쉬움.

## 6.3 Wilcoxon 부호순위

### 한 집단과 기준값

```python
result = pg.wilcoxon(df['값열'] - 기준값)
display(result)
```

### 같은 대상의 전·후

```python
result = pg.wilcoxon(after, before)
display(result)
```

> [!NOTE]
> Wilcoxon도 인자 순서에 따라 RBC 부호와 방향이 달라짐.

## 6.4 RBC 해석

| `|RBC|` | 일반적 해석 |
|---:|---|
| 0.1 미만 | 매우 작음 |
| 0.1~0.3 | 작음 |
| 0.3~0.5 | 중간 |
| 0.5 이상 | 큼 |

```text
RBC > 0 → 첫 번째 집단이 더 큰 경향
RBC < 0 → 두 번째 집단이 더 큰 경향
```

# 7. 세 집단 이상 비교

## 7.1 일반 ANOVA

정규성과 등분산성이 적절한 세 집단 이상 평균 비교.

```python
aov = pg.anova(
    data=df,
    dv='값열',
    between='집단열',
    detailed=True
)
display(aov)
```

주요 값:

```text
F      → 집단 간 변동 / 집단 내 변동
p_unc  → 적어도 한 집단이 다른지
np2    → 부분 에타제곱
```

ANOVA가 유의해도 알 수 있는 것은 다음까지.

```text
적어도 한 집단의 평균이 다르다.
```

### Tukey 사후검정

```python
tukey = pg.pairwise_tukey(
    data=df,
    dv='값열',
    between='집단열'
)
display(tukey)
```

주요 열:

```text
A, B                 → 비교 집단
mean_A, mean_B, diff → 방향
p_tukey              → 보정 p-value
hedges               → 쌍별 효과크기
```

## 7.2 Welch ANOVA

정규성은 크게 문제없지만 등분산성이 깨진 경우.

```python
welch = pg.welch_anova(
    data=df,
    dv='값열',
    between='집단열'
)
display(welch)
```

### Games-Howell 사후검정

```python
games = pg.pairwise_gameshowell(
    data=df,
    dv='값열',
    between='집단열'
)
display(games)
```

## 7.3 Kruskal-Wallis

정규성 위배가 큰 독립 세 집단 이상 비교.

```python
kruskal = pg.kruskal(
    data=df,
    dv='값열',
    between='집단열'
)
display(kruskal)
```

Kruskal-Wallis도 다음까지만 알려줌.

```text
적어도 한 집단의 순위·분포 위치가 다르다.
```

### Dunn 사후검정

```python
dunn = sp.posthoc_dunn(
    df,
    val_col='값열',
    group_col='집단열',
    p_adjust='holm'
)
display(dunn)
```

### 쌍별 RBC 확인

```python
groups = df['집단열'].dropna().unique()

for a, b in combinations(groups, 2):
    x = df.loc[df['집단열'] == a, '값열']
    y = df.loc[df['집단열'] == b, '값열']

    p_adjusted = dunn.loc[a, b]
    rbc = pg.mwu(x, y)['RBC'].iloc[0]

    print(f'{a} vs {b}: p={p_adjusted:.4g}, RBC={rbc:.3f}')
```

# 8. 카이제곱 검정

범주형 자료는 평균이 아니라 **빈도**를 비교.

## 8.1 적합도 검정

범주 하나의 관측 분포가 기대 분포와 같은지 확인.

```python
observed = df['범주열'].value_counts().sort_index()
n = observed.sum()

expected = np.repeat(n / len(observed), len(observed))

chi2, p = stats.chisquare(
    f_obs=observed.values,
    f_exp=expected
)

cohens_w = np.sqrt(chi2 / n)

print('chi2:', chi2)
print('p-value:', p)
print("Cohen's w:", cohens_w)
```

## 8.2 독립성 검정

두 범주형 변수가 서로 관련 있는지 확인.

```python
expected, observed, stats_table = pg.chi2_independence(
    data=df,
    x='범주열1',
    y='범주열2'
)

display(expected)
display(observed)
display(stats_table)

pearson = stats_table.loc[
    stats_table['test'] == 'pearson'
].iloc[0]

print('chi2:', pearson['chi2'])
print('p-value:', pearson['pval'])
print("Cramér's V:", pearson['cramer'])
```

### 기대빈도 조건

```text
모든 칸의 기대빈도 ≥ 1
기대빈도 5 미만인 칸 ≤ 전체 칸의 20%
```

작은 `2×2` 교차표에서 조건이 부족하면 Fisher 정확검정 고려.

> [!NOTE]
> `pg.chi2_independence()`는 여러 카이제곱 계열 결과를 보여줌.  
> 기본 해석은 `test == 'pearson'` 행 사용.

## 8.3 조정잔차

카이제곱 검정이 유의하면 어느 칸이 관계를 만드는지 확인.

```python
adjusted = Table(observed.values).standardized_resids

residuals = pd.DataFrame(
    adjusted,
    index=observed.index,
    columns=observed.columns
)

display(residuals.round(2))
```

```text
조정잔차 > +2 → 기대보다 많음
조정잔차 < -2 → 기대보다 적음
|조정잔차| > 2 → 두드러진 칸
```

> [!IMPORTANT]
> 카이제곱 독립성 검정은 **두 범주가 관련 있다**까지만 알려줌.  
> 방향은 조정잔차와 실제 비율을 함께 확인.

# 9. 효과크기 기준

## 9.1 t-검정·사후검정

| `|d|`, `|g|` | 해석 |
|---:|---|
| 0.2 미만 | 매우 작음 |
| 0.2~0.5 | 작음 |
| 0.5~0.8 | 중간 |
| 0.8 이상 | 큼 |

## 9.2 ANOVA

| 부분 η² | 해석 |
|---:|---|
| 0.01 미만 | 매우 작음 |
| 0.01~0.06 | 작음 |
| 0.06~0.14 | 중간 |
| 0.14 이상 | 큼 |

## 9.3 비모수·카이제곱

| `|RBC|`, Cohen's w, Cramér's V | 해석 |
|---:|---|
| 0.1 미만 | 매우 작음 |
| 0.1~0.3 | 작음 |
| 0.3~0.5 | 중간 |
| 0.5 이상 | 큼 |

> [!NOTE]
> 효과크기 기준은 일반적 관습. 분야·연구 목적에 따라 달라질 수 있음.

# 11. 최종 핵심

```text
가설을 먼저 명확히 작성
```
