# Pandas 데이터 결합: `merge`와 `concat`

## 1. `merge` — 키를 기준으로 열 붙이기

`merge`는 두 DataFrame의 **공통 키값을 찾아 옆으로 결합**하는 기능임.

```python
결과 = 왼쪽표.merge(
    오른쪽표,
    on='기준열',
    how='병합방식'
)
```

예:

```python
merged = df.merge(
    day_info,
    on='day',
    how='left'
)
```

이 코드에서:

```text
왼쪽 표  = df
오른쪽 표 = day_info
병합 키   = day
병합 방식 = left join
```

즉, `df`의 행을 모두 유지하면서 `day_info`의 정보를 오른쪽에 붙임.

```text
df
total_bill | tip | day
                 ↓ day로 연결
day_info
day | is_weekend | sort_order
                 ↓
merged
total_bill | tip | day | is_weekend | sort_order
```

---

## 2. 어느 표가 왼쪽인가

### DataFrame 방식

```python
df.merge(day_info, on='day')
```

`.` 앞의 `df`가 왼쪽 표이고, 괄호 안의 `day_info`가 오른쪽 표임.

```text
df.merge(day_info)
↑        ↑
왼쪽     오른쪽
```

### `pd.merge` 방식

```python
pd.merge(df, day_info, on='day')
```

첫 번째 인자가 왼쪽 표, 두 번째 인자가 오른쪽 표임.

```text
pd.merge(df, day_info)
         ↑   ↑
       왼쪽 오른쪽
```

두 코드는 같은 의미임.

```python
df.merge(day_info, on='day')

pd.merge(df, day_info, on='day')
```

# `how` 병합 방식

## 3. `inner` — 양쪽에 모두 있는 키만 유지

```python
result = left.merge(
    right,
    on='key',
    how='inner'
)
```

`inner`는 기본값이므로 생략할 수 있음.

```python
left.merge(right, on='key')
```

예시:

```text
왼쪽 키  : A, B, C
오른쪽 키: B, C, D

결과 키  : B, C
```

양쪽 표에 모두 존재하는 키만 남음.

오른쪽에 짝이 없는 왼쪽 행도 사라지고, 왼쪽에 짝이 없는 오른쪽 행도 사라짐.

---

## 4. `left` — 왼쪽 표의 행을 모두 유지

```python
result = left.merge(
    right,
    on='key',
    how='left'
)
```

예시:

```text
왼쪽 키  : A, B, C
오른쪽 키: B, C, D

결과 키  : A, B, C
```

* 왼쪽 표의 행은 모두 유지
* 오른쪽에 같은 키가 있으면 정보가 붙음
* 오른쪽에 같은 키가 없으면 오른쪽 열이 `NaN`

```text
왼쪽       오른쪽        결과
A           없음          A | NaN
B           B             B | 오른쪽 정보
C           C             C | 오른쪽 정보
            D             결과에서 제외
```

### 핵심

```python
df.merge(day_info, how='left')
```

이 경우 왼쪽은 `df`임.

따라서:

```text
df의 행은 전부 유지
day_info는 df에 정보를 제공하는 표
```

괄호 안의 `day_info`를 유지하는 것이 아님.

---

## 5. `right` — 오른쪽 표의 행을 모두 유지

```python
result = left.merge(
    right,
    on='key',
    how='right'
)
```

예시:

```text
왼쪽 키  : A, B, C
오른쪽 키: B, C, D

결과 키  : B, C, D
```

* 오른쪽 표의 행은 모두 유지
* 왼쪽에 짝이 없으면 왼쪽 열이 `NaN`
* 왼쪽에만 있는 `A`는 사라짐

```python
df.merge(day_info, on='day', how='right')
```

이 경우 괄호 안에 있는 `day_info`가 오른쪽 표이므로 `day_info`의 키를 모두 유지함.

---

## 6. `outer` — 양쪽 키를 모두 유지

```python
result = left.merge(
    right,
    on='key',
    how='outer'
)
```

예시:

```text
왼쪽 키  : A, B, C
오른쪽 키: B, C, D

결과 키  : A, B, C, D
```

한쪽에만 존재하는 키도 모두 남김.

짝이 없는 쪽의 열에는 `NaN`이 들어감.

---

## 7. 병합 방식 비교

| `how`   | 유지되는 키      | 짝이 없는 경우      |
| ------- | ----------- | ------------- |
| `inner` | 양쪽에 모두 있는 키 | 행이 사라짐        |
| `left`  | 왼쪽 표의 키 전체  | 오른쪽 열이 `NaN`  |
| `right` | 오른쪽 표의 키 전체 | 왼쪽 열이 `NaN`   |
| `outer` | 양쪽 표의 모든 키  | 없는 쪽 열이 `NaN` |

기억:

```text
left  → .merge 앞쪽 표 유지
right → 괄호 안쪽 표 유지
inner → 양쪽 공통 키만
outer → 양쪽 키 모두
```

단, `pd.merge()` 방식에서는 다음과 같음.

```python
pd.merge(left, right)
```

```text
첫 번째 표  → left
두 번째 표  → right
```

## 9. 일부 키가 없는 경우

금요일 정보가 빠진 참조표 생성:

```python
day_info_partial = day_info[
    day_info['day'] != 'Fri'
]
```

```text
day_info_partial에 존재하는 키:
Sun, Sat, Thur
```

원본 `df`에는 금요일 주문도 존재함.

### `inner`

```python
inner_df = df.merge(
    day_info_partial,
    on='day',
    how='inner'
)
```

양쪽에 존재하는 요일만 유지하므로 금요일 주문이 제거됨.

```text
원본: 244행
결과: 225행
```

### `left`

```python
left_df = df.merge(
    day_info_partial,
    on='day',
    how='left'
)
```

왼쪽 `df`의 주문은 모두 유지함.

```text
원본: 244행
결과: 244행
```

단, 금요일은 오른쪽 정보가 없으므로 다음 열이 `NaN`이 됨.

```text
is_weekend
sort_order
```

```python
left_df['is_weekend'].isna().sum()
```

```text
19
```

금요일 주문 19개의 오른쪽 정보가 결측값으로 들어간 것임.

# 병합 키 이름이 다를 때

## 11. `left_on`과 `right_on`

왼쪽과 오른쪽의 키 열 이름이 다르면 `on`을 사용할 수 없음.

```text
왼쪽 표 키  : day
오른쪽 표 키: 요일
```

이때 각각 지정함.

```python
result = left.merge(
    right,
    left_on='day',
    right_on='요일',
    how='left'
)
```

* `left_on`: 왼쪽 표의 키
* `right_on`: 오른쪽 표의 키

```text
left.day ↔ right.요일
```

# 키 중복 주의

## 12. 오른쪽 키가 중복된 경우

왼쪽 한 행과 일치하는 오른쪽 행이 여러 개면 왼쪽 행이 복제됨.

예:

```text
왼쪽 표
day
Fri
```

```text
오른쪽 표
day | 정보
Fri | A
Fri | B
```

병합 결과:

```text
day | 정보
Fri | A
Fri | B
```

왼쪽의 `Fri` 한 행이 두 행으로 늘어남.

### 키 고유성 확인

```python
day_info['day'].is_unique
```

```text
True  → 중복 없음
False → 중복 있음
```

또는:

```python
day_info['day'].duplicated().sum()
```

참조 정보표처럼 키 하나당 한 행이어야 한다면 병합 전에 반드시 확인하는 것이 좋음.

---

## 13. 병합 관계 검사

```python
merged = df.merge(
    day_info,
    on='day',
    how='left',
    validate='many_to_one'
)
```

의미:

```text
왼쪽 df
→ 같은 day가 여러 번 나와도 됨

오른쪽 day_info
→ day 하나당 한 행만 있어야 함
```

오른쪽 키가 중복되어 있으면 오류가 발생해 행 복제를 미리 막을 수 있음.

# `concat` — 표를 그대로 이어 붙이기

## 14. `merge`와 `concat` 차이

```text
merge
→ 키값을 비교해 옆으로 결합

concat
→ 행이나 열 이름을 맞춰 그대로 이어 붙임
```

| 기능       | 기준          | 주 사용 상황              |
| -------- | ----------- | -------------------- |
| `merge`  | 특정 키 열      | 주문표에 회원정보 붙이기        |
| `concat` | 열 이름 또는 인덱스 | 1월 데이터 아래에 2월 데이터 쌓기 |

---

## 15. `axis=0` — 아래로 붙이기

기본값임.

```python
result = pd.concat(
    [january, february],
    axis=0
)
```

```text
january
↓
february
```

동일한 이름의 열끼리 맞춰 아래로 쌓음.

```python
result = pd.concat(
    [january, february],
    ignore_index=True
)
```

`ignore_index=True`를 사용하면 결과 인덱스를 `0`부터 다시 생성함.

---

## 16. 열 이름이 다르면

```python
a = df[['day', 'tip']].head(2)

b = (
    df[['day', 'tip']]
    .tail(2)
    .rename(columns={'tip': 'Tip'})
)
```

`tip`과 `Tip`은 대소문자가 다르므로 서로 다른 열임.

```python
pd.concat([a, b])
```

결과:

| day  |  tip |  Tip |
| ---- | ---: | ---: |
| Sun  | 1.01 |  NaN |
| Sun  | 1.66 |  NaN |
| Sat  |  NaN | 1.75 |
| Thur |  NaN | 3.00 |

`concat`은 오류를 내지 않고 두 열을 따로 생성함.

```text
tip ≠ Tip
```

공통 열만 유지하려면:

```python
pd.concat(
    [a, b],
    join='inner'
)
```

두 표에 공통으로 있는 `day` 열만 남음.

## 17. `axis=1` — 옆으로 붙이기

```python
left_cols = df[
    ['total_bill', 'tip']
].head(3)

right_cols = df[
    ['day', 'time']
].head(3)
```

```python
side_by_side = pd.concat(
    [left_cols, right_cols],
    axis=1
)
```

결과:

| total_bill |  tip | day | time   |
| ---------: | ---: | --- | ------ |
|      16.99 | 1.01 | Sun | Dinner |
|      10.34 | 1.66 | Sun | Dinner |
|      21.01 | 3.50 | Sun | Dinner |

### 중요

`axis=1`은 단순히 현재 보이는 행 위치가 아니라 **인덱스 값이 같은 행끼리** 붙임.

```text
인덱스 0 ↔ 인덱스 0
인덱스 1 ↔ 인덱스 1
인덱스 2 ↔ 인덱스 2
```

인덱스가 다르면 같은 위치에 있어도 서로 붙지 않고 `NaN`이 생김.

```python
left = df[['tip']].head(3)

right = (
    df[['day']]
    .tail(3)
)
```

```python
pd.concat([left, right], axis=1)
```

왼쪽 인덱스:

```text
0, 1, 2
```

오른쪽 인덱스:

```text
241, 242, 243
```

인덱스가 일치하지 않으므로 6행이 만들어지고 빈칸이 생김.

필요하면 인덱스를 초기화한 뒤 결합함.

```python
result = pd.concat(
    [
        left.reset_index(drop=True),
        right.reset_index(drop=True)
    ],
    axis=1
)
```

# 최종 구분

```text
df.merge(day_info)
→ df가 왼쪽
→ day_info가 오른쪽

pd.merge(df, day_info)
→ 첫 번째 df가 왼쪽
→ 두 번째 day_info가 오른쪽

how='left'
→ 왼쪽 표의 행 유지

how='right'
→ 오른쪽 표의 행 유지

how='inner'
→ 양쪽에 공통인 키만 유지

how='outer'
→ 양쪽의 모든 키 유지
```

```text
merge
→ 키값을 찾아 옆으로 병합

concat(axis=0)
→ 같은 열 이름끼리 맞춰 아래로 쌓기

concat(axis=1)
→ 같은 인덱스끼리 맞춰 옆으로 붙이기
```

## 가장 중요한 형태

```python
결과 = 왼쪽표.merge(
    오른쪽표,
    on='공통키',
    how='left'
)
```

해석:

```text
왼쪽표의 행을 전부 남기고
공통키가 같은 오른쪽표의 열을 가져와 붙임
짝이 없으면 오른쪽 정보는 NaN
```
