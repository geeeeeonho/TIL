# 추론통계 기초 정리

> 기술통계로 관찰한 **표본**을 이용해, 직접 알기 어려운 **모집단**의 특성을 추정하는 과정  
> 핵심 흐름: **모집단·표본 → 표본분포 → 중심극한정리 → 표준오차 → 신뢰구간 → p-value 기초**

## 1. 모집단과 표본

| 구분 | 대상 | 요약값 이름 | 성질 |
|---|---|---|---|
| 모집단 `population` | 알고 싶은 전체 | 모수 `parameter` — `μ`, `σ` | 고정된 값이지만 보통 알 수 없음 |
| 표본 `sample` | 실제로 관찰한 일부 | 통계량 `statistic` — `x̄`, `s` | 표본을 뽑을 때마다 달라짐 |

- **모수**: 모집단의 실제 평균·표준편차
- **통계량**: 표본에서 계산한 평균·표준편차
- **추론통계의 목표**: 관찰 가능한 통계량으로 관찰하기 어려운 모수를 추정

## 2. 표본과 표본분포

한 번 뽑은 표본의 평균은 `표본평균`이다.  
표본을 여러 번 뽑으면 표본평균이 조금씩 달라진다. 이 표본평균들이 이루는 분포가 **표본분포**다.

| 함수·인자 | 작동 |
|---|---|
| `df.sample(n=30)` | DataFrame에서 30행 추출 |
| `random_state=42` | 같은 표본이 다시 나오도록 난수 고정 |
| `series.to_numpy()` | pandas Series를 NumPy 배열로 변환 |
| `np.random.default_rng(42)` | 재현 가능한 난수 생성기 생성 |
| `rng.choice(values, size=n)` | 배열에서 `n`개 추출 |
| `replace=True` | 추출한 값을 다시 넣는 복원추출 |
| `.mean()` | 평균 계산 |

### ⭐ 핵심 예시 — 표본을 뽑을 때마다 평균이 달라짐

```python
mpg_population = population['mpg'].dropna()  # 연비 열 선택 후 결측값 제거
pop_mean = mpg_population.mean()              # 개념 확인용 모평균

print(f'모평균 μ = {pop_mean:.3f}')

for state in [1, 2, 3]:                       # 서로 다른 표본 3개 추출
    sample = population.sample(
        n=30,                                 # 표본크기
        random_state=state                    # 같은 state면 같은 표본 재현
    )['mpg'].dropna()

    print(f'표본 {state}: 표본평균 x̄ = {sample.mean():.3f}')
```

### ⭐ 핵심 예시 — 표본평균 1,000개로 표본분포 만들기

```python
rng = np.random.default_rng(42)                # 재현 가능한 난수 생성기
pop_values = mpg_population.to_numpy()         # Series를 NumPy 배열로 변환

sample_means = [
    rng.choice(
        pop_values,
        size=30,                               # 표본 하나의 크기
        replace=True                           # 뽑은 값을 다시 넣는 복원추출
    ).mean()                                   # 이번 표본의 평균
    for _ in range(1000)                       # 표본추출 1,000번 반복
]

sns.histplot(sample_means, bins=30, kde=True)  # 표본평균 분포 시각화
plt.axvline(pop_mean, linestyle='--', label=f'모평균 {pop_mean:.2f}')  # 모평균 표시
plt.title('표본평균 1,000개의 표본분포')
plt.xlabel('표본평균')
plt.legend()
plt.show()

print(f'표본평균들의 평균 = {np.mean(sample_means):.3f}')
```

## 3. 중심극한정리

**표본크기 `n`이 커지면 표본평균의 분포가 정규분포에 가까워지는 성질**

\[
\bar{X} \approx N\left(\mu,\frac{\sigma}{\sqrt{n}}\right)
\]

- 중심은 모집단 평균 `μ`에 가까워짐
- 퍼짐은 `σ / √n`만큼 작아짐
- 원자료가 정규분포가 아니어도 표본평균 분포는 정규분포에 가까워질 수 있음
- 정규분포에 가까워지는 대상은 **원자료가 아니라 표본평균의 분포**

### ⭐ 핵심 예시 — 표본크기에 따른 표본평균 분포 비교

```python
rng = np.random.default_rng(42)                 # 재현 가능한 난수 생성기
pop_values = mpg_population.to_numpy()

fig, axes = plt.subplots(2, 2, figsize=(11, 8)) # 2행 2열 그래프 생성

for ax, n in zip(axes.flat, [1, 5, 30, 100]):  # 표본크기별로 한 칸씩 사용
    means = [
        rng.choice(pop_values, size=n, replace=True).mean()  # 크기 n인 표본평균
        for _ in range(2000)                    # 각 n마다 2,000번 반복
    ]

    sns.histplot(means, bins=30, kde=True, ax=ax)
    ax.axvline(pop_mean, linestyle='--')         # 모평균 위치 표시
    ax.set_title(f'표본크기 n={n}')
    ax.set_xlabel('표본평균')

fig.suptitle('n이 커질수록 표본평균 분포가 좁고 대칭적으로 변함')
fig.tight_layout()                               # 그래프 간격 자동 정리
plt.show()
```

## 4. 표준오차

**표준오차 `SE`**: 표본평균이 표본마다 얼마나 흔들리는지 나타내는 값

\[
SE=\frac{\sigma}{\sqrt{n}}
\]

모표준편차 `σ`를 모를 때는 표본표준편차 `s`로 추정한다.

\[
SE\approx\frac{s}{\sqrt{n}}
\]

| 구분 | 의미 |
|---|---|
| 표준편차 `SD` | 개별 데이터가 평균 주변에서 퍼진 정도 |
| 표준오차 `SE` | 표본평균이 표본마다 흔들리는 정도 |

- 표본크기가 커질수록 `SE`는 감소
- 표본크기가 **4배**가 되면 `SE`는 **절반**
- 정확도를 높이려면 표본을 늘려야 하지만 시간·비용도 증가

### ⭐ 핵심 예시 — 표준오차 계산

```python
sample30 = population.sample(n=30, random_state=42)['mpg'].dropna()  # 표본 30개

n = len(sample30)                         # 실제 표본 개수
s = sample30.std(ddof=1)                  # 표본표준편차
se_manual = s / np.sqrt(n)                # SE = s / √n
se_scipy = stats.sem(sample30)            # 같은 계산을 하는 SciPy 함수

print(f'표본표준편차 s = {s:.4f}')
print(f'직접 계산 SE = {se_manual:.4f}')
print(f'stats.sem() = {se_scipy:.4f}')
```

## 5. 점추정과 구간추정

| 방식 | 결과 | 특징 |
|---|---|---|
| 점추정 | `x̄ = 22.6`처럼 숫자 하나 | 간단하지만 추정의 불확실성을 표현하지 못함 |
| 구간추정 | `[19.5, 25.6]`처럼 범위 | 오차를 포함해 모수가 있을 만한 범위를 제시 |

- **점추정값**: 표본평균과 같은 대표값 하나
- **구간추정**: 점추정값 좌우에 오차범위를 붙인 결과
- 대표적인 구간추정 방법이 **신뢰구간**

## 6. 신뢰구간

신뢰구간의 기본 구조:

\[
점추정값 \pm 임계값 \times 표준오차
\]

| 유형 | 범위 형태 | 주로 묻는 질문 |
|---|---|---|
| 양측 신뢰구간 | `(하한, 상한)` | 모수가 어느 범위에 있는가 |
| 하한 단측 신뢰구간 | `(하한, +∞)` | 모수가 최소 얼마 이상인가 |
| 상한 단측 신뢰구간 | `(-∞, 상한)` | 모수가 최대 얼마 이하인가 |

이 문서의 예시는 주로 **양측 95% 신뢰구간**을 사용한다.

---

## 7. 부트스트랩 신뢰구간

**부트스트랩**: 현재 표본에서 복원추출을 반복해 새로운 표본을 만들고, 통계량의 분포를 추정하는 방법

| 함수 | 작동 |
|---|---|
| `rng.choice(sample, replace=True)` | 현재 표본에서 복원추출 |
| `np.percentile(values, [2.5, 97.5])` | 양쪽 2.5%를 제외한 95% 범위 계산 |

### ⭐ 핵심 예시 — 부트스트랩 95% 신뢰구간

```python
sample30 = population.sample(n=30, random_state=42)['mpg'].dropna()  # 원래 표본
sample_values = sample30.to_numpy()

rng = np.random.default_rng(42)

boot_means = [
    rng.choice(
        sample_values,
        size=len(sample_values),              # 원래 표본과 같은 크기
        replace=True                           # 현재 표본에서 복원추출
    ).mean()                                   # 재표본의 평균
    for _ in range(2000)                       # 재표본추출 2,000번 반복
]

ci_low, ci_high = np.percentile(
    boot_means,
    [2.5, 97.5]                                # 양쪽 2.5%를 제외한 95% 구간
)

print(f'부트스트랩 95% 신뢰구간 = [{ci_low:.3f}, {ci_high:.3f}]')
```

## 8. 정규분포와 t분포 신뢰구간

| 함수 | 사용 |
|---|---|
| `stats.norm.interval()` | 모표준편차를 알고 있거나 정규근사를 직접 사용할 때 |
| `stats.t.interval()` | 모표준편차를 모르고 표본표준편차로 표준오차를 추정할 때 |
| `df=n-1` | t분포의 자유도 |

실제 분석에서는 모표준편차를 모르는 경우가 많으므로 `t.interval()`이 기본적으로 안전하다.

- t분포는 정규분포보다 꼬리가 두꺼움
- 작은 표본의 추가 불확실성을 반영해 구간이 조금 더 넓음
- 자유도 `df`가 커질수록 t분포는 정규분포에 가까워짐

### ⭐ 핵심 예시 — t분포 기반 95% 신뢰구간

```python
sample30 = population.sample(n=30, random_state=42)['mpg'].dropna()

mean_hat = sample30.mean()              # 점추정값: 표본평균
se = stats.sem(sample30)                # 표본평균의 표준오차
df = len(sample30) - 1                  # t분포 자유도

ci_low, ci_high = stats.t.interval(
    confidence=0.95,                    # 95% 양측 신뢰구간
    df=df,
    loc=mean_hat,                       # 구간의 중심
    scale=se                            # 구간 너비 계산에 사용할 SE
)

print(f'표본평균 = {mean_hat:.2f}')
print(f'95% 신뢰구간 = [{ci_low:.2f}, {ci_high:.2f}]')
```

---

## 9. 신뢰구간 해석

### 올바른 해석

같은 방법으로 표본을 반복해서 뽑고 95% 신뢰구간을 계속 만들면, 만들어진 구간 중 약 95%가 실제 모수를 포함한다.

### 주의

- 모수는 고정된 값
- 계산된 하나의 구간에 모수가 들어갈 확률이 95%라고 표현하지 않음
- 신뢰수준은 **구간을 만드는 절차의 장기적 성공률**

---

## 10. 신뢰구간으로 주장값 확인

- 주장값이 신뢰구간 **안**에 있음  
  → 현재 데이터와 모순된다고 보기 어려움
- 주장값이 신뢰구간 **밖**에 있음  
  → 현재 데이터와 잘 맞지 않음

신뢰구간 안에 있다는 사실만으로 주장이 참이라고 증명되는 것은 아니다.

### ⭐ 핵심 예시 — 평균 연비 27이라는 주장 확인

```python
sample30 = population.sample(n=30, random_state=42)['mpg'].dropna()

observed_mean = sample30.mean()         # 관찰한 표본평균
se = stats.sem(sample30)                # 표준오차

ci_low, ci_high = stats.t.interval(
    confidence=0.95,
    df=len(sample30) - 1,
    loc=observed_mean,
    scale=se
)

claim = 27.0                            # 확인할 주장값
inside = ci_low <= claim <= ci_high     # 주장값의 구간 포함 여부

print(f'표본평균 = {observed_mean:.2f}')
print(f'95% 신뢰구간 = [{ci_low:.2f}, {ci_high:.2f}]')
print(f'주장값 {claim:.0f}이 구간 안에 있는가? {inside}')

if inside:
    print('→ 현재 데이터와 모순된다고 보기 어려움')
else:
    print('→ 현재 데이터와 잘 맞지 않음')
```

## 11. p-value 기초

**p-value**

주장이 옳다고 가정했을 때, 현재 관찰한 결과 또는 그보다 더 극단적인 결과가 우연히 나올 확률

| p-value | 해석 |
|---|---|
| 작음 | 주장이 맞는 상황에서는 보기 드문 결과 → 주장을 의심할 근거 |
| 큼 | 주장이 맞아도 충분히 나올 수 있는 결과 → 주장과 모순된다고 보기 어려움 |

### 흔한 오해

| 잘못된 해석 | 올바른 이해 |
|---|---|
| p-value는 주장이 맞을 확률 | 주장이 맞다고 **가정한 뒤** 계산한 조건부 확률 |
| p-value가 크면 주장이 참 | 틀렸다는 증거가 부족할 뿐, 참이라는 증명은 아님 |
| `p < 0.05`면 무조건 중요한 발견 | `0.05`는 관례적인 기준이며 절대 법칙이 아님 |
| p-value가 작으면 차이가 큼 | p-value는 차이의 크기를 직접 나타내지 않음 |
| `0.049`와 `0.051`은 완전히 다름 | 경계 근처 값은 실질적으로 매우 비슷할 수 있음 |

> p-value는 이 단계에서는 **원리와 해석만 이해**  
> 실제 검정 함수와 가설 설정은 이후 과정에서 학습

## 13. 최종 압축 정리

| 주제 | 핵심 |
|---|---|
| 추론통계 | 표본을 이용해 모집단의 모수를 추정 |
| 표본분포 | 반복해서 뽑은 표본의 통계량이 이루는 분포 |
| 중심극한정리 | `n`이 커지면 표본평균 분포가 정규분포에 가까워짐 |
| 표준오차 | 표본평균의 흔들림, `SE ≈ s/√n` |
| 점추정 | 숫자 하나로 모수를 추정 |
| 구간추정 | 오차를 포함한 범위로 모수를 추정 |
