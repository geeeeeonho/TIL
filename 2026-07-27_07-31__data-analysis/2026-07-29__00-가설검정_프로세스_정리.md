# 가설검정 전체 흐름 · 프로세스 요약

## 1. 전체 흐름

```text
┌─────────────────────────────┐
│ (1) 가설 설정                 │
│ H₀: 차이·효과·관계 없음        │
│ H₁: 차이·효과·관계 있음        │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│ (2) 유의수준 설정             │
│ 보통 α = 0.05                │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│ (3) 데이터와 질문 유형 확인    │
└──────────────┬──────────────┘
               ↓
        ┌──────┴──────┐
        │             │
        ▼             ▼
┌─────────────┐  ┌─────────────┐
│ 수치형 비교   │  │ 범주형 비교   │
└──────┬──────┘  └──────┬──────┘
       │                │
       ▼                ▼
┌─────────────┐  ┌────────────────────┐
│ 비교 구조    │  │ 범주 변수 개수       │
│ · 1표본     │   │ · 1개: 적합도       │
│ · 대응표본   │  │ · 2개: 독립성       │
│ · 독립 2집단 │  └─────────┬──────────┘
│ · 3집단 이상 │            │
└──────┬──────┘            ▼
       │          ┌─────────────────┐
       ▼          │ 기대빈도 확인     │
┌─────────────┐   │ 부족하면 정확검정  │
│ 가정 확인    │   └─────────┬───────┘
│ · 독립성     │             │
│ · 정규성     │             │
│ · 등분산성   │             │
└──────────┬──┘             │
           └──────────────┬─┘
                          ↓
┌────────────────────────────────────┐
│ (4) 검정 방법 선택                   │
│ 모수검정 / Welch / 비모수 / 정확검정   │
└──────────────────┬─────────────────┘
                   ↓
┌────────────────────────────────────┐
│ (5) 검정 수행                        │
│ p-value와 α 비교                    │
└──────────────────┬─────────────────┘
                   ↓
          ┌────────┴────────┐
          │                 │
          ▼                 ▼
┌──────────────────┐  ┌──────────────────┐
│ p < α            │  │ p ≥ α            │
│ H₀ 기각           │  │ H₀ 기각 못 함     │
│ H₁ 지지           │  │ 증거 부족         │
└────────┬─────────┘  └────────────┬─────┘
         │                         │
         ▼                         │
┌──────────────────┐               │
│ (6) 효과크기 확인  │               │
│ 차이가 얼마나 큰가  │               │
└────────┬─────────┘               │
         ▼                         │
┌─────────────────────────────┐    │
│ (7) 필요하면 사후분석          │    │
│ · ANOVA → Tukey             │    │
│ · Welch ANOVA → Games-Howell│    │
│ · Kruskal → Dunn            │    │
│ · 카이제곱 → 조정잔차          │    │
└────────────┬────────────────┘    │
             └──────────┬──────────┘
                        ↓
┌────────────────────────────────────┐
│ (8) 최종 결론                        │
│ 검정방법 + p-value + 효과크기         │
│ + 사후분석 결과를 함께 설명            │
└────────────────────────────────────┘
```

---

## 2. 검정 선택 요약

| 질문 | 기본 검정 | 가정이 맞지 않을 때 | 유의한 뒤 확인 |
|---|---|---|---|
| 한 집단과 기준값 비교 | 1표본 t-검정 | Wilcoxon 부호순위 | 효과크기 |
| 같은 대상의 전·후 비교 | 대응표본 t-검정 | Wilcoxon 부호순위 | 효과크기 |
| 서로 다른 두 집단 비교 | Student t / Welch t | Mann-Whitney U | 효과크기 |
| 서로 다른 세 집단 이상 비교 | ANOVA | Welch ANOVA / Kruskal-Wallis | Tukey / Games-Howell / Dunn |
| 범주 1개의 분포 비교 | 카이제곱 적합도 | 정확 다항검정 등 | Cohen's w |
| 범주 2개의 관계 확인 | 카이제곱 독립성 | Fisher 정확검정 | Cramér's V + 조정잔차 |

## 3. 수치형 검정 선택

```text
수치형 자료
│
├─ 한 집단 vs 기준값
│  ├─ 정규성 만족       → 1표본 t-검정
│  └─ 정규성 크게 위배  → Wilcoxon 부호순위
│
├─ 같은 대상의 전·후
│  ├─ 차이값 정규성 만족      → 대응표본 t-검정
│  └─ 차이값 정규성 크게 위배 → Wilcoxon 부호순위
│
├─ 독립 두 집단
│  ├─ 정규성 만족
│  │  ├─ 등분산 만족     → Student t-검정
│  │  └─ 등분산 불만족   → Welch t-검정
│  └─ 정규성 크게 위배   → Mann-Whitney U
│
└─ 독립 세 집단 이상
   ├─ 정규성 만족
   │  ├─ 등분산 만족     → ANOVA
   │  └─ 등분산 불만족   → Welch ANOVA
   └─ 정규성 크게 위배   → Kruskal-Wallis
```

## 4. 범주형 검정 선택

```text
범주형 자료
│
├─ 범주 변수 1개
│  └─ 관측 분포가 기대 분포와 같은가?
│      → 카이제곱 적합도 검정
│
└─ 범주 변수 2개
   └─ 두 범주가 서로 관련 있는가?
       → 카이제곱 독립성 검정
```

### 기대빈도 확인

```text
모든 칸의 기대빈도 ≥ 1
기대빈도 5 미만인 칸 ≤ 전체의 20%
```

조건이 부족한 작은 `2×2` 교차표:

```text
카이제곱 독립성 검정 → Fisher 정확검정
```

---

## 5. 결과 판정

| 조건 | 판정 | 의미 |
|---|---|---|
| `p-value < α` | 귀무가설 기각 | 대립가설을 지지할 통계적 근거가 있음 |
| `p-value ≥ α` | 귀무가설 기각 못 함 | 차이가 없다는 확정이 아니라 증거 부족 |

```text
p-value → 차이가 우연이라고 보기 어려운가?
효과크기 → 실제 차이가 얼마나 큰가?
```

---

## 6. 사후분석

| 전체 검정 | 전체 검정이 알려주는 것 | 구체적인 차이 확인 |
|---|---|---|
| ANOVA | 적어도 한 집단 평균이 다름 | Tukey HSD |
| Welch ANOVA | 적어도 한 집단 평균이 다름 | Games-Howell |
| Kruskal-Wallis | 적어도 한 집단의 순위·분포 위치가 다름 | Dunn 검정 |
| 카이제곱 독립성 | 두 범주가 서로 관련 있음 | 조정잔차 |

```text
|조정잔차| > 2
→ 기대빈도보다 눈에 띄게 많거나 적은 칸
```

## 7. 최종 압축

```text
가설 설정
→ 유의수준 설정
→ 데이터 유형 확인
→ 비교 구조 확인
→ 가정 확인
→ 검정 선택
→ p-value 판정
→ 효과크기 확인
→ 필요한 경우 사후분석
→ 최종 결론 작성
```
