# 텍스트 분석 04

전처리가 끝난 토큰을 이용해 **빈도·TF-IDF·특징어·연관어**를 분석하는 과정.

```text
단어 빈도
→ BoW·TF-IDF
→ 문서별 핵심어
→ 클래스별 특징어
→ n-gram
→ 동시 출현
→ 히트맵·네트워크
```

## 1. 기본 준비

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

from collections import Counter
from sklearn.feature_extraction.text import (
    CountVectorizer,
    TfidfVectorizer,
)
from wordcloud import WordCloud
```

사용 데이터 예시:

```text
reviews
├─ text    : 원문
├─ tokens  : 전처리된 토큰 리스트
└─ label   : 긍정 1 / 부정 0
```

# 2. 단어 빈도

## `Counter`로 전체 단어 세기

```python
word_counter = Counter()

for tokens in reviews["tokens"]:
    # 현재 문서의 토큰 빈도를 전체 결과에 누적
    word_counter.update(tokens)

print("서로 다른 단어 수:", len(word_counter))
print("빈도 TOP 10:", word_counter.most_common(10))
```

| 코드 | 의미 |
|---|---|
| `Counter()` | 빈 빈도 객체 생성 |
| `.update(tokens)` | 단어 빈도 누적 |
| `len(counter)` | 서로 다른 단어 수 |
| `.most_common(10)` | 빈도 상위 10개 |

## 워드클라우드

```python
wc = WordCloud(
    font_path=FONT_PATH,

    height=400,

fig, ax = plt.subplots(figsize=(10, 5))
```

# 3. BoW와 TF-IDF

## BoW

**Bag of Words**는 문서를 단어별 등장 횟수로 표현.

```text
행 = 문서
열 = 단어
값 = 해당 문서에서 단어가 나온 횟수
```

어순은 저장하지 않음.

## TF-IDF

문서 안에서는 자주 나오지만 다른 문서에는 드문 단어에 높은 점수 부여.

```text
TF-IDF = TF × IDF
```

- `TF`: 현재 문서에서의 단어 빈도
- `IDF`: 전체 문서에서 드문 정도
- 활용: 문서별 핵심어, 문서 비교, 분류 입력값

---

## 문서 벡터화

토큰 리스트를 공백으로 이어 하나의 문서 문자열로 변환.

```python
docs = [
    " ".join(tokens)
    for tokens in reviews["tokens"]
]

# BoW
count_vec = CountVectorizer(
    min_df=5,
    token_pattern=r"\S+",
)
bow = count_vec.fit_transform(docs)

# TF-IDF
tfidf_vec = TfidfVectorizer(
    min_df=5,
    token_pattern=r"\S+",
)
X = tfidf_vec.fit_transform(docs)

# 행렬 열 순서와 일치하는 단어 목록
terms = tfidf_vec.get_feature_names_out()

print("BoW 크기:", bow.shape)
print("TF-IDF 크기:", X.shape)
print("어휘 수:", len(terms))
```

### `token_pattern=r"\S+"`

```text
\S  공백이 아닌 문자
+   한 번 이상
```

공백으로 나눈 토큰 덩어리 하나를 한 단어로 읽음.

---

## `fit`, `transform`, `fit_transform`

| 메서드 | 역할 | 사용 시점 |
|---|---|---|
| `fit(docs)` | 어휘와 IDF 학습 | 규칙만 학습 |
| `transform(docs)` | 기존 기준으로 문서 변환 | 새 문서 처리 |
| `fit_transform(docs)` | 학습 후 같은 문서 변환 | 최초 학습 데이터 |

새 문서에는 기존 벡터라이저 사용.

```python
new_docs = ["배우 연기 최고"]
new_X = tfidf_vec.transform(new_docs)
```

# 4. 문서별 TF-IDF 핵심어

벡터라이저 결과는 대부분이 0인 **희소 행렬**.

전체를 `X.toarray()`로 바꾸지 않고 필요한 행만 변환.

```python
doc_index = 0

# 특정 문서의 TF-IDF 점수
row = X[doc_index].toarray()[0]

scores = pd.Series(
    row,
    index=terms,
)

# 실제 등장한 단어만 남기고 상위 5개
top5 = scores[scores > 0].nlargest(5)

print("원문:", reviews.loc[doc_index, "text"])
print("토큰:", reviews.loc[doc_index, "tokens"])
print(top5)
```

### 0점 필터가 필요한 이유

```python
scores.nlargest(5)
```

문서에 단어가 5개보다 적으면 0점 단어가 결과에 포함될 수 있음.

```python
scores[scores > 0].nlargest(5)
```

실제로 등장한 단어만 추출.

# 5. Count와 TF-IDF 차이

| 구분 | `CountVectorizer` | `TfidfVectorizer` |
|---|---|---|
| 값 | 단어 등장 횟수 | TF × IDF |
| 흔한 단어 | 그대로 큰 값 | 영향 감소 |
| 주요 목적 | 빈도·동시 출현 | 핵심어·문서 비교 |
| 기본 정규화 | 없음 | L2 정규화 |

같은 횟수로 나온 단어도 다른 문서에서 드물수록 TF-IDF 점수가 높아짐.

# 6. `min_df`와 `max_df`

둘 다 단어의 **전체 등장 횟수**가 아니라 **등장한 문서 수**를 기준으로 필터링.

| 옵션 | 정수 | 0~1 실수 |
|---|---|---|
| `min_df` | 최소 문서 수 | 최소 문서 비율 |
| `max_df` | 최대 문서 수 | 최대 문서 비율 |

문서가 2,000개일 때:

```text
min_df=5     → 5개 이상 문서에 나온 단어 유지
min_df=0.01  → 20개 이상 문서에 나온 단어 유지

max_df=1000  → 1,000개 이하 문서에 나온 단어 유지
max_df=0.85  → 1,700개 이하 문서에 나온 단어 유지
```

### 자료형 주의

```text
max_df=1    → 정수 1문서
max_df=1.0  → 비율 100%
```

둘은 전혀 다른 설정.

### 사용 기준

- 작은 데이터: `min_df=2`, `min_df=5`
- 문서 수가 자주 변함: `min_df=0.01`
- `max_df`를 너무 낮추면 핵심어까지 삭제될 수 있음
- 제거 전후 어휘 수와 실제 제거 단어 확인 필요

> `max_df`는 불용어를 자동 확정하는 기능이 아니라 불용어 후보를 찾는 기준.

# 7. 클래스별 핵심어

예: 긍정 리뷰와 부정 리뷰 비교.

## 클래스별 평균 TF-IDF

```python
y = reviews["label"].to_numpy()

# 각 클래스 문서의 열별 평균
pos_mean = np.asarray(
    X[y == 1].mean(axis=0)
).ravel()

neg_mean = np.asarray(
    X[y == 0].mean(axis=0)
).ravel()

pos_top = [
    terms[i]
    for i in np.argsort(-pos_mean)[:10]
]

neg_top = [
    terms[i]
    for i in np.argsort(-neg_mean)[:10]
]

mean_table = pd.DataFrame(
    {
        "긍정 평균 TOP 10": pos_top,
        "부정 평균 TOP 10": neg_top,
    },
    index=range(1, 11),
)

display(mean_table)
```

평균이 높다는 뜻:

```text
해당 클래스에서 그 단어의 TF-IDF 중요도가 전반적으로 높음
```

원시 등장 횟수가 많다는 뜻과는 다름.

---

## 평균 차이로 특징어 찾기

양쪽 클래스에 모두 흔한 단어는 평균만 보면 중복될 수 있음.

```python
diff = pos_mean - neg_mean
```

```text
큰 양수 → 긍정 특징어
큰 음수 → 부정 특징어
0 근처 → 양쪽에서 비슷하게 등장
```

```python
# 긍정 특징어: 큰 값부터
pos_idx = np.argsort(-diff)[:10]

# 부정 특징어: 작은 값부터
neg_idx = np.argsort(diff)[:10]

feature_table = pd.DataFrame(
    {
        "긍정 특징어": [terms[i] for i in pos_idx],
        "긍정 차이": [diff[i] for i in pos_idx],
        "부정 특징어": [terms[i] for i in neg_idx],
        "부정 차이": [diff[i] for i in neg_idx],
    },
    index=range(1, 11),
)

display(feature_table)
```

### 기존 코드 오류

```python
# 오류
np.argsort(diff, descending=True)
```

NumPy의 `argsort()`에는 `descending` 인자가 없음.

```python
np.argsort(-diff)  # 내림차순 효과
np.argsort(diff)   # 오름차순
```

# 8. n-gram

n-gram은 연속된 단어 묶음을 하나의 항목으로 처리.

| 이름 | 단위 | 예: `배우 연기 최고` |
|---|---|---|
| Unigram | 1단어 | 배우, 연기, 최고 |
| Bigram | 연속 2단어 | 배우 연기, 연기 최고 |
| Trigram | 연속 3단어 | 배우 연기 최고 |

## 설정

| 설정 | 추출 범위 |
|---|---|
| `(1, 1)` | unigram |
| `(2, 2)` | bigram |
| `(1, 2)` | unigram + bigram |
| `(1, 3)` | unigram + bigram + trigram |

보통 `(1, 2)`부터 시작.

```python
ngram_vec = CountVectorizer(
    ngram_range=(1, 2),
    min_df=5,
    token_pattern=r"\S+",
)

ngram_matrix = ngram_vec.fit_transform(docs)
ngram_terms = ngram_vec.get_feature_names_out()

# 각 단어·구문의 전체 등장 횟수
ngram_counts = np.asarray(
    ngram_matrix.sum(axis=0)
).ravel()

top_idx = np.argsort(-ngram_counts)[:20]

for i in top_idx:
    print(
        f"{ngram_terms[i]:15s} "
        f"{int(ngram_counts[i])}회"
    )
```

bigram만 추출:

```python
CountVectorizer(
    ngram_range=(2, 2),
    min_df=5,
    token_pattern=r"\S+",
)
```

> `ngram_range=(1, 3)`은 bigram만 분석하는 설정이 아니라 unigram부터 trigram까지 모두 포함.

# 9. 동시 출현 분석

두 단어가 같은 문서에 함께 등장한 횟수를 계산.

```text
n-gram
→ 서로 바로 붙어 있어야 함

동시 출현
→ 같은 문서 안에만 있으면 됨
```

## 이진 문서-단어 행렬

```python
binary_vec = CountVectorizer(
    binary=True,
    min_df=10,
    max_df=0.85,
    token_pattern=r"\S+",
)

B = binary_vec.fit_transform(docs)
co_terms = binary_vec.get_feature_names_out()
```

```text
0 = 문서에 없음
1 = 문서에 있음
```

## 동시 출현 행렬

```python
co_matrix = (B.T @ B).toarray()

# 자기 자신과의 동시 출현값 제거
np.fill_diagonal(co_matrix, 0)

print("행렬 크기:", co_matrix.shape)
```

```text
co_matrix[i, j]
= 단어 i와 단어 j가 함께 등장한 문서 수
```

---

## 상위 단어쌍

행렬은 대칭이므로 상삼각만 사용.

```python
rows, cols = np.triu_indices_from(
    co_matrix,
    k=1,
)

values = co_matrix[rows, cols]
top_idx = np.argsort(-values)[:10]

for k in top_idx:
    print(
        f"({co_terms[rows[k]]}, "
        f"{co_terms[cols[k]]}) : "
        f"{int(values[k])}개 문서"
    )
```

# 10. 동시 출현 히트맵

```python
# 다른 단어와의 전체 연결 횟수
strength = co_matrix.sum(axis=1)

# 연결이 많은 상위 12개 단어
top_words = np.argsort(-strength)[:12]

sub_matrix = co_matrix[
    np.ix_(top_words, top_words)
]

labels = [
    co_terms[i]
    for i in top_words
]

fig, ax = plt.subplots(figsize=(8, 6.5))

sns.heatmap(
    sub_matrix,
    xticklabels=labels,
    yticklabels=labels,
    annot=True,
    fmt="d",
    ax=ax,
)

ax.set_title("단어 동시 출현 히트맵")
fig.tight_layout()
plt.show()
```

값이 클수록 두 단어가 같은 문서에 자주 함께 등장.

# 11. 네트워크 분석

동시 출현 관계를 네트워크로 표현.

| 요소 | 의미 |
|---|---|
| 노드 | 단어 |
| 노드 크기 | 다른 단어와 연결된 전체 횟수 |
| 선 | 두 단어의 동시 출현 관계 |
| 선 두께 | 함께 나온 문서 수 |
| 노드 거리 | 자동 배치 결과, 정확한 수치 거리는 아님 |

상위 단어쌍 목록 생성:

```python
pairs = []

for k in np.argsort(-values):
    if values[k] == 0:
        break

    pairs.append(
        (
            co_terms[rows[k]],
            co_terms[cols[k]],
            int(values[k]),
        )
    )

print(pairs[:10])
```

이 목록을 `networkx.Graph()`에 넣어 시각화.

핵심 흐름:

```text
단어쌍 추출
→ 단어를 노드로 생성
→ 동시 출현 횟수를 선의 가중치로 저장
→ 노드 크기·선 두께 계산
→ 네트워크 출력
```

# 핵심 코드

```python
# 문서 문자열 생성
docs = [
    " ".join(tokens)
    for tokens in reviews["tokens"]
]

# TF-IDF
tfidf_vec = TfidfVectorizer(
    min_df=5,
    token_pattern=r"\S+",
)

X = tfidf_vec.fit_transform(docs)
terms = tfidf_vec.get_feature_names_out()

# 문서별 핵심어
doc_index = 0

scores = pd.Series(
    X[doc_index].toarray()[0],
    index=terms,
)

doc_top = scores[scores > 0].nlargest(5)

# 클래스별 특징어
y = reviews["label"].to_numpy()

pos_mean = np.asarray(
    X[y == 1].mean(axis=0)
).ravel()

neg_mean = np.asarray(
    X[y == 0].mean(axis=0)
).ravel()

diff = pos_mean - neg_mean

pos_features = [
    terms[i]
    for i in np.argsort(-diff)[:10]
]

neg_features = [
    terms[i]
    for i in np.argsort(diff)[:10]
]

print("긍정 특징어:", pos_features)
print("부정 특징어:", neg_features)
```

# 총정리

| 분석 | 확인할 내용 | 도구 |
|---|---|---|
| 빈도 | 전체에서 많이 나온 단어 | `Counter` |
| 워드클라우드 | 단어 빈도의 시각적 경향 | `WordCloud` |
| BoW | 문서별 단어 횟수 | `CountVectorizer` |
| TF-IDF | 문서별 중요한 단어 | `TfidfVectorizer` |
| 클래스 평균 | 클래스에서 전반적으로 중요한 단어 | 열별 평균 |
| 평균 차이 | 한쪽 클래스에 더 특화된 단어 | `pos_mean - neg_mean` |
| n-gram | 연속된 단어 표현 | `ngram_range` |
| 동시 출현 | 같은 문서에 함께 나온 단어 | `B.T @ B` |
| 히트맵 | 단어 관계 표 | `sns.heatmap` |
| 네트워크 | 중심 단어와 관계 구조 | `networkx` |

```text
추천 순서

Counter로 전체 빈도 확인
→ TF-IDF로 문서별 핵심어 확인
→ 클래스 평균 차이로 특징어 비교
→ n-gram으로 연속 표현 확인
→ 동시 출현으로 단어 관계 분석
→ 히트맵·네트워크로 시각화
```
