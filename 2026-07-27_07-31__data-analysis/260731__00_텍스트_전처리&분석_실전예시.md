**II. 정규표현식 중, 반복되는 글자 지우기**  
n번 반복글자 \-\> 2번처리

squeeze \= **re**.**sub**(  
    r"(.)\\1{2,}",*\# I.같은 문자가 3번 이상 연속된 부분을 찾음*  
                   *\# (.)     : 문자 1개를 잡아서 1번 그룹으로 저장*  
                   *\# \\1      : 1번 그룹과 같은 문자가 다시 나오는지 확인*  
                   *\# {2,}    : 같은 문자가 2번 이상 추가로 반복*  
                   *\# 따라서 전체적으로 같은 문자 3번 이상을 의미*

                   *\# \\1      : 첫 번째로 잡은 문자*  
                   *\# \\1\\1    : 해당 문자를 2번 남김*  
                     
    sample3        *\# 대상 문자열*  
)

**I \+ II ⇒ 정제 함수화**  
I \+ II \+ 중복 공백 처리(+양끝 공백 제거)  
text \= '어깨가 쫙 펴져요ㅎㅎㅎㅎ   완전 만족\!\!\!   재구매 의사 있어요^^'

def **clean\_text**(text):  
*\# I. 특수문자&이모티콘 지우기*  
    step1 \= **re**.**sub**(r"\[^가-힣ㄱ-ㅎㅏ-ㅣa-zA-Z0-9\\s\]"," ",text)

    *\# II. 반복되는 글자 지우기*  
    step2 \= **re**.**sub**(r"(.)\\1{2,}",r"\\1\\1",step1)

    *\# \+ 여러 공백을 한 칸으로 줄이고 양끝 공백 제거*  
    step3 \= **re**.**sub**(r"\\s\+", " ", step2).**strip**()  
    return(step3)

**print**(text,'\\n\>\>clean\_text(text)\>\>\\n',**clean\_text**(text))
