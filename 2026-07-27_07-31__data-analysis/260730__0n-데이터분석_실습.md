## 14. IQR 이상치 계산

```python
q1, q3 = cu['age'].quantile(
    [0.25, 0.75]
    # 25% 지점과 75% 지점 계산
)
```

```python
IQR = q3 - q1           # 데이터 중간 50%의 범위
lower = q1 - 1.5 * IQR  # 정상 범위 아래 경계
upper = q3 + 1.5 * IQR  # 정상 범위 위 경계
```

```python
IQR_out = (
    (cu['age'] < lower) |
    (cu['age'] > upper)
    # | : 두 조건 중 하나 이상이 True
)
```

```python
print('정상 범위:', lower, '~', upper)
print('IQR 이상치 수:', IQR_out.sum())
```

Pandas Series 조건 결합:

```python
조건1 & 조건2  # 두 조건 모두 만족
조건1 | 조건2  # 둘 중 하나 이상 만족
~조건1         # 조건 반전
```

각 조건은 반드시 괄호로 묶어야 함.

## 15. Z-score 이상치 계산

```python
age_mean = cu['age'].mean()  # 결측치를 제외한 평균
age_std = cu['age'].std()    # 표본 표준편차, 기본 ddof=1
```

```python
z = (
    (cu['age'] - age_mean)  # 각 값과 평균의 차이
    / age_std               # 표준편차 단위로 변환
).abs()                     # 음수·양수를 모두 거리로 비교
```

```python
z_out = z > 3
# 평균에서 표준편차 3배 이상 떨어진 값
```

```python
under_10 = cu['age'] < 10

print(
    '10세 미만 중 IQR 이상치:',
    (IQR_out & under_10).sum()
    # IQR 이상치이면서 10세 미만인 행
)

print(
    '10세 미만 중 Z-score 이상치:',
    (z_out & under_10).sum()
)
```

### 특정 값의 Z-score 선택

```python
z_999 = z[
    cu['age'] == 999  # 나이가 999인 행만 선택
].iloc[0]             # 선택 결과의 첫 번째 위치값

print(z_999)
```

* `.loc[]`: 행·열의 이름으로 선택
* `.iloc[]`: 행·열의 정수 위치로 선택

## 18. 결측치 처리 방식 비교

```python
cu_clone = cu['club_member_status'].copy(
    deep=True
    # 원본과 분리된 복사본 생성
)
```

```python
filled_unknown = cu_clone.fillna(
    value='UNKNOWN'
    # 모든 결측치를 지정한 값으로 변경
)
```

```python
filled_forward = cu_clone.ffill(
    limit=None
    # 앞 행 값을 연속 개수 제한 없이 사용
)
```

```python
filled_backward = cu_clone.bfill(
    limit=None
    # 뒤 행 값을 연속 개수 제한 없이 사용
)
```

```python
print(filled_unknown.isna().sum())
print(filled_forward.isna().sum())
print(filled_backward.isna().sum())
```

* `fillna('UNKNOWN')`: 결측치를 별도 범주로 처리
* `ffill()`: 앞 행의 값으로 채움
* `bfill()`: 뒤 행의 값으로 채움
* `limit=2`: 연속 결측치를 최대 2개까지만 채움

## 36. 색상별 가격 집계

```python
df_color_csv = (
    df.groupby(
        by='colour_group_name',
        # 그룹을 나눌 기준 열

        dropna=True,
        # 색상 결측치는 별도 그룹으로 만들지 않음

        sort=True
        # 그룹 이름을 정렬
    )

    .agg(
        mean_price=(
            'price',
            'mean'
        ),  # price 평균

        median_price=(
            'price',
            'median'
        ),  # price 중앙값

        std_price=(
            'price',
            'std'
        ),  # price 표준편차

        purchase_count=(
            'price',
            'count'
        )   # price 결측치를 제외한 행 개수
    )

    .reset_index(
        drop=False
        # 그룹 기준 열을 삭제하지 않고 일반 열로 복원
    )

    .sort_values(
        by='mean_price',  # 정렬 기준 열
        ascending=False,  # 큰 값부터 정렬
        na_position='last'
        # 결측치는 마지막으로 배치
    )
)
```

`agg()`의 이름 있는 집계 형식:

# 핵심 함수 설정 요약

| 함수                  | 주요 설정              | 의미               |
| ------------------- | ------------------ | ---------------- |
| `read_csv()`        | `encoding`         | 파일 문자 인코딩        |
| `value_counts()`    | `dropna=False`     | 결측치도 개수에 포함      |
| `str.contains()`    | `case=False`       | 대소문자 무시          |
| `str.contains()`    | `na=False`         | 결측치를 False 처리    |
| `drop()`            | `columns=[...]`    | 지정한 열 제거         |
| `merge()`           | `on=`              | 결합 기준 열          |
| `merge()`           | `how='inner'`      | 양쪽에 있는 키만 유지     |
| `merge()`           | `validate=`        | 결합 관계 검증         |
| `drop_duplicates()` | `subset=`          | 중복 판단 기준 열       |
| `drop_duplicates()` | `keep=`            | 유지할 중복 행 지정      |
| `fillna()`          | `value=`           | 결측치를 지정값으로 변경    |
| `to_datetime()`     | `errors='coerce'`  | 잘못된 날짜를 `NaT` 처리 |
| `sample()`          | `random_state=`    | 표본 추출 결과 고정      |
| `duplicated()`      | `keep=False`       | 중복 그룹 전체 선택      |
| `groupby()`         | `by=`              | 그룹 기준 열          |
| `agg()`             | `이름=('열', '함수')`   | 집계 결과 열 이름 지정    |
| `sort_values()`     | `ascending=False`  | 내림차순 정렬          |
| `nlargest()`        | `n=10`             | 가장 큰 값의 상위 10행   |
| `isin()`            | 값 목록               | 목록에 포함되는지 검사     |
| `subplots()`        | `nrows`, `ncols`   | 그래프 배치 지정        |
| `barplot()`         | `ax=`              | 출력할 subplot 지정   |
| `boxplot()`         | `showfliers=False` | 이상치 점 숨김         |
| `bar_label()`       | `fmt=`             | 막대 숫자 출력 형식      |
