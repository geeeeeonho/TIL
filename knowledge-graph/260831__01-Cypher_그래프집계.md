# Cypher 그래프 집계 · 리스트 · 함수 문법 핵심 정리

> 원본 노트북을 **문법과 실사용 패턴 중심으로 압축**한 정리.  
> 데이터 적재 과정과 반복 퀴즈는 줄이고, 이후 쿼리 작성에 계속 쓰이는 문법은 예시와 함께 유지함.

---

# 1. 집계의 핵심: `count` · 그룹핑 · `WITH`

Cypher 집계에서 가장 먼저 구분할 것.

| 문법 | 의미 |
|---|---|
| `count(*)` | 만들어진 **행 전체**를 셈 |
| `count(x)` | `x`가 `null`이 아닌 행만 셈 |
| `count(DISTINCT x)` | 중복을 제거한 서로 다른 `x`의 수 |
| `min(x)` / `max(x)` | 최소 / 최대 |
| `avg(x)` | 평균 |
| `sum(x)` | 합계 |
| `collect(x)` | 여러 값을 리스트 하나로 모음 |

## 그룹핑 키

Cypher에는 일반 SQL처럼 `GROUP BY`를 따로 쓰지 않음.

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)
RETURN d.name AS 질병,
       count(c) AS 약물수
ORDER BY 약물수 DESC, 질병
LIMIT 5
```

여기서:

```text
d.name      → 집계하지 않은 값 = 그룹핑 기준
count(c)    → 각 그룹에서 계산할 값
```

즉,

```cypher
RETURN d.name, count(c)
```

는 **질병별 집계**.

```cypher
RETURN count(c)
```

는 그룹핑 기준이 없으므로 **전체를 한 번에 집계**.

그룹 기준을 여러 개 둘 수도 있음.

```cypher
RETURN p.name, d.name, count(c)
```

→ `p.name + d.name` 조합별로 집계.

---

## `MATCH`와 `OPTIONAL MATCH`가 집계 결과를 바꿈

일반 `MATCH`는 연결이 없는 노드를 제거함.

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)
RETURN count(DISTINCT d)
```

→ 치료약이 하나라도 연결된 질병만 남음.

연결이 없어도 기준 노드를 남기려면:

```cypher
MATCH (d:Disease)
OPTIONAL MATCH (c:Compound)-[:TREATS]->(d)
RETURN count(*) AS 행수,
       count(c) AS 약물연결수
```

`OPTIONAL MATCH`에서 연결이 없으면 `c = null`.

따라서:

```text
count(*) → null 행도 행이므로 셈
count(c) → c가 null이면 세지 않음
```

**집계에서는 무엇을 세는지가 곧 질문의 의미.**

---

## 경로가 갈라지면 `DISTINCT`

그래프는 여러 경로를 거치면서 같은 노드가 여러 행에 반복될 수 있음.

```cypher
MATCH (:Disease {name:'asthma'})
      <-[:TREATS]-(:Compound)
      -[:BINDS]->(g:Gene)

RETURN count(g) AS 경로에서세어진수,
       count(DISTINCT g) AS 실제유전자수
```

```text
몇 번 등장했는가 → count(g)
서로 다른 것이 몇 개인가 → count(DISTINCT g)
```

특히 **2-hop 이상이나 여러 관계 종류를 합친 패턴**에서는 중복 여부를 먼저 확인.

---

## 집계한 값을 다시 집계하려면 `WITH`

집계 함수 안에 집계 함수를 바로 중첩하지 않음.

```cypher
// 잘못된 형태
RETURN avg(count(c))
```

먼저 1차 집계를 끝낸 뒤 `WITH`로 넘김.

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)

WITH d,
     count(c) AS 약물수

RETURN count(d) AS 질병수,
       min(약물수) AS 최소,
       max(약물수) AS 최대,
       round(avg(약물수), 2) AS 평균,
       sum(약물수) AS 합계
```

흐름:

```text
MATCH
  ↓
1차 집계
  ↓
WITH
  ↓
2차 집계
  ↓
RETURN
```

`WITH`는 **다음 단계에 필요한 값만 전달**함.

```cypher
WITH d, count(c) AS 약물수
```

뒤에서는 `d`, `약물수`만 사용할 수 있음.

# 2. 집계에서 자주 틀리는 부분: `null` · 평균 · 나눗셈

## 집계 함수의 `null` 처리

대부분의 집계 함수는 `null`을 건너뜀.

| 문법 | `null` 처리 |
|---|---|
| `count(x)` | 세지 않음 |
| `count(*)` | 행 자체를 세므로 포함 |
| `avg(x)` | 제외하고 평균 |
| `min(x)` / `max(x)` | 제외 |
| `collect(x)` | 리스트에 넣지 않음 |
| `sum(x)` | 없는 값을 제외하고 합산 |

평균에서는 특히 **분모**를 확인해야 함.

### 연결된 질병만 평균

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)
WITH d, count(c) AS 약물수
RETURN count(d) AS 질병수,
       round(avg(약물수), 2) AS 평균
```

### 연결이 없는 질병도 `0`으로 포함

```cypher
MATCH (d:Disease)
OPTIONAL MATCH (c:Compound)-[:TREATS]->(d)

WITH d, count(c) AS 약물수

RETURN count(d) AS 질병수,
       round(avg(약물수), 2) AS 평균
```

두 쿼리는 합계가 같아도 평균은 달라질 수 있음.

```text
MATCH          → 연결된 대상만 분모에 포함
OPTIONAL MATCH → 연결 없는 대상도 0으로 분모에 포함
```

---

## `coalesce`: `null` 대체

```cypher
coalesce(a, b)
```

→ `a`가 `null`이 아니면 `a`, 아니면 `b`.

```cypher
RETURN coalesce(c.name, '(치료약 없음)')
```

여러 후보도 가능.

```cypher
coalesce(a, b, c, '기본값')
```

앞에서부터 처음으로 `null`이 아닌 값을 반환.

평균에서 빈 값을 `0`으로 포함해야 하는 경우:

```cypher
avg(coalesce(x, 0))
```

단, `null`이 **0이라는 의미인지 단순 미측정인지** 먼저 판단해야 함.

---

## 정수 나눗셈

비율을 만들 때는 자료형을 확인.

```cypher
RETURN toFloat(공유수) / 전체수 AS 비율
```

정수끼리 계산하는 경우 소수 부분이 사라질 수 있으므로, 비율 계산에서는 한쪽을 명시적으로 실수로 변환하는 형태가 안전함.

```cypher
toFloat(a) / b
```

---

## 평균만 보지 말고 분포도 확인

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)
WITH d, count(c) AS 약물수

RETURN round(avg(약물수), 2) AS 평균,
       percentileCont(약물수, 0.5) AS 중앙값,
       percentileCont(약물수, 0.9) AS p90,
       max(약물수) AS 최대,
       round(stDev(약물수), 2) AS 표준편차
```

| 문법 | 의미 |
|---|---|
| `percentileCont(x, 0.5)` | 중앙값 |
| `percentileCont(x, 0.9)` | 90% 지점 |
| `stDev(x)` | 표준편차 |

평균이 큰 값 몇 개에 끌려갈 수 있으므로 **평균 + 중앙값 + 최대값**을 같이 보는 편이 안전함.

# 3. 리스트 문법: `collect` · `UNWIND` · 컴프리헨션

## 여러 값을 하나의 리스트로: `collect`

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)

RETURN d.name AS 질병,
       count(c) AS 약물수,
       collect(c.name)[0..5] AS 약물맛보기
ORDER BY 약물수 DESC
```

```text
count(x)   → 몇 개인가
collect(x) → 무엇들인가
```

중복 제거:

```cypher
collect(DISTINCT c.name)
```

리스트 길이:

```cypher
size(약물목록)
```

슬라이싱:

```cypher
목록[0..5]   // 0~4
목록[1..]    // 1번부터 끝까지
목록[0]      // 첫 값
목록[-1]     // 마지막 값
```

`collect()`의 순서는 자동으로 보장되지 않음. 순서가 중요하면 **모으기 전에 정렬**.

```cypher
MATCH (c:Compound)-[:TREATS]->(:Disease {name:'migraine'})
WITH c.name AS 이름
ORDER BY 이름
WITH collect(이름) AS 약물들
RETURN 약물들
```

---

## 리스트를 다시 행으로: `UNWIND`

```cypher
UNWIND ['hypertension', 'asthma', 'migraine'] AS 병명

MATCH (c:Compound)-[:TREATS]->(d:Disease {name: 병명})

RETURN 병명,
       count(c) AS 치료약물수
```

파이썬 리스트를 파라미터로 넘기는 형태가 더 실용적.

```python
disease_names = [
    "hypertension",
    "asthma",
    "migraine",
]

rows = run_cypher(
    """
    UNWIND $병명목록 AS 병명
    MATCH (c:Compound)-[:TREATS]->(d:Disease {name: 병명})
    RETURN 병명, count(c) AS 치료약물수
    """,
    병명목록=disease_names,
)
```

핵심:

```text
Python list
   ↓
파라미터
   ↓
UNWIND
   ↓
Cypher의 여러 행
```

대량 적재에서도 같은 구조 사용.

```cypher
UNWIND $rows AS row
...
```

---

## 리스트 컴프리헨션

파이썬의 리스트 컴프리헨션과 유사.

```cypher
[x IN 목록 WHERE 조건 | 변환식]
```

예:

```cypher
[x IN 약물들 WHERE x STARTS WITH 'A']
```

→ `A`로 시작하는 값만 남김.

```cypher
[x IN 약물들 | size(x)]
```

→ 각 문자열을 길이로 변환.

구조 비교:

```text
Cypher
[x IN 목록 WHERE 조건 | 변환]

Python
[변환 for x in 목록 if 조건]
```

---

## 패턴을 바로 리스트로 받기: 패턴 컴프리헨션

```cypher
[(a)-[:관계]->(b) | b.name]
```

예:

```cypher
MATCH (d:Disease {name:'migraine'})

RETURN [(c:Compound)-[:TREATS]->(d) | c.name] AS 치료약,
       [(d)-[:PRESENTS]->(s:Symptom) | s.name][0..3] AS 증상맛보기
```

개수만 필요하면:

```cypher
size([
    (c:Compound)-[:TREATS]->(d) | c
])
```

연결된 대상이 없으면 **빈 리스트 `[]`**가 됨.

여러 종류의 목록을 한 행에 붙일 때 편리함.

---

## 값 하나를 바로 만드는 서브쿼리 식

바깥의 변수를 그대로 사용하면서 행을 늘리지 않고 값 하나를 만들 수 있음.

```cypher
MATCH (d:Disease {name:'migraine'})

RETURN EXISTS {
           (:Compound)-[:TREATS]->(d)
       } AS 치료약있나,

       COUNT {
           (:Compound)-[:TREATS]->(d)
       } AS 치료약수,

       COLLECT {
           MATCH (c:Compound)-[:TREATS]->(d)
           RETURN c.name
           ORDER BY c.name
           LIMIT 3
       } AS 치료약맛보기
```

| 문법 | 결과 |
|---|---|
| `EXISTS { ... }` | `true` / `false` |
| `COUNT { ... }` | 정수 |
| `COLLECT { ... }` | 리스트 |

# 4. 집계 후 필터 · 저장 · 조건 분기

## 집계 결과 필터: `WITH ... WHERE`

집계 전의 행을 거르는 조건:

```cypher
MATCH ...
WHERE ...
```

집계한 결과를 거르는 조건:

```cypher
MATCH ...
WITH 그룹기준, count(...) AS 개수
WHERE 개수 >= 20
RETURN ...
```

예:

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)

WITH d,
     count(c) AS 약물수

WHERE 약물수 >= 20

RETURN d.name AS 질병,
       약물수
ORDER BY 약물수 DESC, 질병
```

SQL의 `HAVING`에 해당하는 위치.

개수 하나만 조건으로 쓸 때는 `COUNT { }`로 짧게 작성 가능.

```cypher
MATCH (d:Disease)

WHERE COUNT {
    (:Compound)-[:TREATS]->(d)
} >= 20

RETURN d.name
```

정리:

```text
복합 집계·재사용 필요 → WITH
관계 개수 하나만 필요 → COUNT { }
```

---

## 집계값을 속성으로 저장: `SET`

```cypher
MATCH (c:Compound)-[:TREATS]->(d:Disease)

WITH d,
     count(c) AS 약물수

SET d.drug_count = 약물수
```

조회:

```cypher
MATCH (d:Disease)
WHERE d.drug_count IS NOT NULL

RETURN d.name,
       d.drug_count
```

삭제:

```cypher
MATCH (d:Disease)
REMOVE d.drug_count
```

파생 속성은 **계산한 순간의 사본**.

원본 관계가 바뀌어도 자동 갱신되지 않음.

```text
자주 읽고 원본 변화가 적음 → 저장 고려
원본이 자주 변함            → 조회 시 계산하거나 갱신 로직 필요
```

## `CASE`: 조건별 값 만들기

### 조건형

범위나 복합 조건.

```cypher
CASE
    WHEN 약물수 >= 20 THEN '선택지 많음'
    WHEN 약물수 >= 5  THEN '보통'
    ELSE '선택지 적음'
END
```

**좁은 조건을 먼저 배치.**

잘못된 순서:

```cypher
WHEN 약물수 >= 5 THEN ...
WHEN 약물수 >= 20 THEN ...
```

`20 이상`도 첫 조건에 먼저 걸리므로 두 번째 조건에 도달하지 못함.

---

### 단순형

비교 대상이 하나일 때.

```cypher
CASE type(r)
    WHEN 'TREATS' THEN '병 자체 치료'
    WHEN 'PALLIATES' THEN '증상 완화'
    ELSE '기타'
END
```

---

## 집계 함수 안에서 행마다 계산

```cypher
sum(수량 * 단가)
```

→ 각 행에서 `수량 * 단가`를 계산한 뒤 합계.

`CASE`도 넣을 수 있음.

```cypher
MATCH (c:Compound)-[r:TREATS|PALLIATES]->(d:Disease)

RETURN c.name AS 약물,
       sum(
           CASE type(r)
               WHEN 'TREATS' THEN 2
               ELSE 1
           END
       ) AS 가중점수
```

핵심:

```text
행별 계산
   ↓
집계
```

# 5. 자주 쓰는 내장 함수

함수를 전부 외울 필요 없음.

현재 DB에서 사용 가능한 함수 확인:

```cypher
SHOW FUNCTIONS
```

필요한 열만:

```cypher
SHOW FUNCTIONS
YIELD name, category
RETURN name, category
```

조건 검색:

```cypher
SHOW FUNCTIONS
YIELD name, category
WHERE category = 'String'
RETURN name
ORDER BY name
```

## 문자열

```cypher
trim(text)                 // 앞뒤 공백 제거
toUpper(text)              // 대문자
split(text, ',')           // 문자열 분리
replace(text, 'A', 'B')    // 치환

left(text, 5)              // 앞 5글자
right(text, 4)             // 뒤 4글자
substring(text, 6, 9)      // 시작 위치 6부터 9글자
size(text)                 // 문자열 길이
```

예:

```cypher
WITH '  Warfarin, Aspirin  ' AS 원본

RETURN trim(원본) AS 공백제거,
       toUpper(trim(원본)) AS 대문자,
       split(trim(원본), ', ') AS 분리
```

## 리스트

```cypher
head(xs)        // 첫 값
last(xs)        // 마지막 값
tail(xs)        // 첫 값을 제외한 나머지
reverse(xs)     // 순서 뒤집기
range(1, 5, 2)  // 1, 3, 5
```

한 리스트를 하나의 값으로 접기:

```cypher
reduce(합 = 0, x IN 목록 | 합 + x)
```

`sum`과 차이:

```text
sum(x)    → 여러 행을 하나로 집계
reduce()  → 한 행 안의 리스트를 하나의 값으로 계산
```

## 리스트 전체 조건 판정

```cypher
all(x IN xs WHERE 조건)      // 전부 만족
any(x IN xs WHERE 조건)      // 하나라도 만족
none(x IN xs WHERE 조건)     // 하나도 만족하지 않음
single(x IN xs WHERE 조건)   // 정확히 하나만 만족
```

예:

```cypher
WITH [12, 7, 3] AS 수들

RETURN all(x IN 수들 WHERE x > 0) AS 모두양수,
       any(x IN 수들 WHERE x > 10) AS 하나라도10초과,
       none(x IN 수들 WHERE x < 0) AS 음수없음,
       single(x IN 수들 WHERE x > 10) AS 하나만10초과
```

# 종합 예시: 2단계 집계

**약효분류별 소속 약물 수 + 약물당 평균 표적 유전자 수**

표적 유전자가 없는 약물도 포함해야 하므로 `OPTIONAL MATCH` 사용.

```cypher
MATCH (p:PharmacologicClass)-[:INCLUDES]->(c:Compound)

OPTIONAL MATCH (c)-[:BINDS]->(g:Gene)

// 1차 집계: 약물 하나마다 표적 수
WITH p,
     c,
     count(g) AS 표적수

// 2차 집계: 약효분류마다 다시 요약
RETURN p.name AS 약효분류,
       count(c) AS 약물수,
       round(avg(표적수), 2) AS 평균표적수

ORDER BY 약물수 DESC, 약효분류
LIMIT 5
```

구조:

```text
PharmacologicClass
        │
        │ INCLUDES
        ▼
     Compound
        │
        │ BINDS
        ▼
       Gene

1차: Compound별 Gene 수
          ↓
WITH
          ↓
2차: PharmacologicClass별 평균
```

# 최종 문법 치트시트

| 목적 | 문법 |
|---|---|
| 전체 행 수 | `count(*)` |
| 값이 있는 행 수 | `count(x)` |
| 중복 제거 개수 | `count(DISTINCT x)` |
| 그룹별 집계 | `RETURN 그룹키, count(...)` |
| 2단계 집계 | `WITH ... AS 집계값` → 다시 집계 |
| 최소·최대·평균·합계 | `min` · `max` · `avg` · `sum` |
| 중앙값·분포 | `percentileCont` · `stDev` |
| `null` 대체 | `coalesce(x, 기본값)` |
| 실수 비율 | `toFloat(a) / b` |
| 값들을 리스트로 | `collect(x)` |
| 리스트 길이 | `size(xs)` |
| 리스트 → 행 | `UNWIND xs AS x` |
| 리스트 조건/변환 | `[x IN xs WHERE 조건 \| 식]` |
| 패턴 → 리스트 | `[(a)-[:R]->(b) \| b.name]` |
| 패턴 존재 여부 | `EXISTS { ... }` |
| 패턴 개수 | `COUNT { ... }` |
| 패턴 결과 리스트 | `COLLECT { MATCH ... RETURN ... }` |
| 집계 후 조건 | `WITH ... WHERE ...` |
| 속성 저장 | `SET n.x = 값` |
| 속성 삭제 | `REMOVE n.x` |
| 조건 분기 | `CASE ... END` |
| 함수 검색 | `SHOW FUNCTIONS YIELD ...` |

## 핵심 흐름

```text
MATCH / OPTIONAL MATCH
        ↓
필요한 행 만들기
        ↓
WITH
        ↓
집계 · 가공 · CASE
        ↓
WHERE
        ↓
RETURN
        ↓
ORDER BY
        ↓
LIMIT
```

집계 문제를 볼 때 먼저 확인할 것.

```text
1. 무엇을 한 행으로 만들 것인가?
2. 무엇을 기준으로 묶을 것인가?
3. 무엇을 셀 것인가? (* / x / DISTINCT x)
4. 연결 없는 대상도 포함할 것인가? (MATCH / OPTIONAL MATCH)
5. 집계를 한 번 더 해야 하는가? (WITH)
6. null이 평균·합계에서 어떻게 처리되는가?
7. 중복 경로가 생기는가?
8. 결과를 저장할 것인가, 매번 계산할 것인가?
```
