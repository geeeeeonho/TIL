## 0. 실습 준비

Neo4j 연결과 Cypher 실행 함수를 먼저 준비.

```python
import os
from dotenv import load_dotenv
from neo4j import GraphDatabase

load_dotenv(".env")
load_dotenv("../.env")

NEO4J_URI = os.getenv("NEO4J_URI", "bolt://localhost:7687")
NEO4J_USER = os.getenv("NEO4J_USER", "neo4j")
NEO4J_PASSWORD = os.getenv("NEO4J_PASSWORD", "neo4j")

driver = GraphDatabase.driver(
    NEO4J_URI,
    auth=(NEO4J_USER, NEO4J_PASSWORD),
)
driver.verify_connectivity()


def run_cypher(query, **params):
    """Cypher 실행 → 결과를 dict 리스트로 반환."""
    with driver.session() as session:
        return [record.data() for record in session.run(query, **params)]
```

실습 전용 DB를 비운 뒤 기본 메뉴 그래프를 적재.

> `MATCH (n) DETACH DELETE n`은 모든 노드와 관계를 삭제하므로 실습 DB에서만 사용.

## 1. 노드 생성과 관계 연결

### 새 음료를 만들고 분류에 연결

`CREATE`로 음료 노드를 만든 뒤, 기존 `Category` 노드를 찾아 관계를 생성.

```python
# 1) 새 Drink 노드 생성
run_cypher("""
CREATE (d:Drink {
    name: '바닐라라떼',
    price: 4200,
    temp: '핫'
})
""")

# 2) 기존 커피 분류와 연결
run_cypher("""
MATCH (d:Drink {name: '바닐라라떼'}),
      (c:Category {name: '커피'})
CREATE (d)-[:IN_CATEGORY]->(c)
""")

# 3) 생성 결과 확인
row = run_cypher("""
MATCH (d:Drink {name: '바닐라라떼'})
      -[r:IN_CATEGORY]->
      (c:Category {name: '커피'})
RETURN d.name AS drink,
       d.price AS price,
       type(r) AS relation,
       c.name AS category
""")

display(row)
```

**결과**

```python
[
    {
        'drink': '바닐라라떼',
        'price': 4200,
        'relation': 'IN_CATEGORY',
        'category': '커피'
    }
]
```

핵심 구조:

```text
MATCH 기존 노드들
CREATE (노드)-[:관계]->(노드)
```

### 노드와 관계를 한 문장으로 생성

양쪽 노드가 모두 새 데이터라면 한 패턴으로 생성 가능.

```python
new_menu = run_cypher("""
CREATE (d:Drink {name: '말차라떼', price: 5200, temp: '핫'})
       -[:IN_CATEGORY]->
       (c:Category {name: '논커피'})
RETURN d.name AS name,
       c.name AS category
""")

display(new_menu)
```

**결과**

```python
[{'name': '말차라떼', 'category': '논커피'}]
```

`CREATE`는 실행할 때마다 새 노드를 만들기 때문에 같은 코드를 반복 실행하면 중복될 수 있음.

## 2. 조회와 조건 검색

### 전체 조회와 특정 속성 조회

```python
# 모든 음료 이름
all_drinks = run_cypher("""
MATCH (d:Drink)
RETURN d.name AS name
""")

# 특정 음료의 가격
cold = run_cypher("""
MATCH (d:Drink {name: '콜드브루'})
RETURN d.price AS price
""")

display(cold)
```

**결과**

```python
[{'price': 4000}]
```

패턴:

```text
MATCH (변수:레이블)
RETURN 변수.속성 AS 별칭
```

속성값까지 적으면 특정 노드를 바로 지정 가능.

```text
MATCH (d:Drink {name: '콜드브루'})
```

### WHERE로 값 필터링

단순 비교와 여러 조건은 같은 구조이므로 함께 사용.

```python
# 4000원 이상
pricey = run_cypher("""
MATCH (d:Drink)
WHERE d.price >= 4000
RETURN d.name AS name
""")

# 4000원 이하이면서 아이스
cheap_ice = run_cypher("""
MATCH (d:Drink)
WHERE d.price <= 4000
  AND d.temp = '아이스'
RETURN d.name AS name
""")

# 5000원 이상이거나 핫
warm_or_pricey = run_cypher("""
MATCH (d:Drink)
WHERE d.price >= 5000
   OR d.temp = '핫'
RETURN d.name AS name
""")

display(pricey)
display(cheap_ice)
display(warm_or_pricey)
```

**결과**

```python
# price >= 4000
[
    {'name': '콜드브루'},
    {'name': '녹차라떼'},
    {'name': '딸기스무디'},
    {'name': '바닐라라떼'}
]

# price <= 4000 AND temp = '아이스'
[
    {'name': '아이스아메리카노'},
    {'name': '콜드브루'}
]

# price >= 5000 OR temp = '핫'
[
    {'name': '아메리카노'},
    {'name': '카페라떼'},
    {'name': '녹차라떼'},
    {'name': '캐모마일티'},
    {'name': '딸기스무디'},
    {'name': '바닐라라떼'}
]
```

```text
AND → 모든 조건 만족
OR  → 하나 이상 만족
```

### 관계 패턴 자체로 검색

노드 속성뿐 아니라 `노드 → 관계 → 노드` 전체를 검색 조건으로 사용 가능.

```python
# 커피 분류에 속한 음료
coffee_names = run_cypher("""
MATCH (d:Drink)-[:IN_CATEGORY]->(c:Category {name: '커피'})
RETURN d.name AS name
""")

# 우유가 들어간 음료
milk_drinks = run_cypher("""
MATCH (d:Drink)-[:HAS_INGREDIENT]->(i:Ingredient {name: '우유'})
RETURN d.name AS name
""")

display(coffee_names)
display(milk_drinks)
```

**결과**

```python
# 커피 분류
[
    {'name': '아메리카노'},
    {'name': '카페라떼'},
    {'name': '아이스아메리카노'},
    {'name': '콜드브루'},
    {'name': '바닐라라떼'}
]

# 우유 포함
[
    {'name': '카페라떼'},
    {'name': '녹차라떼'},
    {'name': '딸기스무디'}
]
```

관계명과 오른쪽 노드만 바꾸면 같은 패턴으로 다른 조건을 표현할 수 있음.

```python
ice_menu = run_cypher("""
```

## 3. MERGE와 관계 속성

### MERGE로 중복 생성 방지

`MERGE`는 같은 패턴이 있으면 기존 데이터를 사용하고, 없을 때만 생성.

```python
run_cypher("""
MERGE (d:Drink {name: '카푸치노'})
""")

check = run_cypher("""
MATCH (d:Drink {name: '카푸치노'})
RETURN count(d) AS count
""")

display(check)
```

**결과**

```python
[{'count': 1}]
```

같은 방식으로 관계도 중복 없이 연결 가능.

```python
run_cypher("""
MATCH (d:Drink {name: '아메리카노'}),
      (c:Category {name: '커피'})
MERGE (d)-[:IN_CATEGORY]->(c)
""")

check = run_cypher("""
MATCH (d:Drink {name: '아메리카노'})
      -[r:IN_CATEGORY]->
      (c:Category {name: '커피'})
RETURN count(r) AS count
""")

display(check)
```

**결과**

```python
[{'count': 1}]
```

```text
CREATE → 항상 새로 생성
MERGE  → 없을 때만 생성
```

### 관계에 속성 저장

속성은 노드뿐 아니라 관계에도 저장 가능.

```python
bean_amount = run_cypher("""
MATCH (d:Drink {name: '바닐라라떼'}),
      (i:Ingredient {name: '원두'})
CREATE (d)-[r:HAS_INGREDIENT {amount: 18}]->(i)
RETURN r.amount AS amount
""")

display(bean_amount)
```

**결과**

```python
[{'amount': 18}]
```

관계 변수 `r`을 붙이면 관계 속성을 `r.amount`처럼 접근 가능.

## 4. 삭제 · 수정 · NULL 처리

### 관계만 삭제

노드는 유지하고 특정 관계만 제거.

```python
run_cypher("""
MATCH (d:Drink {name: '바닐라라떼'})
      -[r:HAS_INGREDIENT]->
      (i:Ingredient {name: '원두'})
DELETE r
""")

check = run_cypher("""
MATCH (d:Drink {name: '바닐라라떼'})
      -[r:HAS_INGREDIENT]->
      (i:Ingredient {name: '원두'})
RETURN r
""")

display(check)
```

**결과**

```python
[]
```

`DELETE r`이므로 관계만 삭제됨.

### 노드와 연결 관계를 함께 삭제

관계가 연결된 노드를 지울 때 `DETACH DELETE` 사용.

```python
# 삭제 전 Drink 수
print(len(run_cypher("""
MATCH (d:Drink)
RETURN d
""")))

# 바닐라라떼와 연결 관계 삭제
run_cypher("""
MATCH (d:Drink {name: '바닐라라떼'})
DETACH DELETE d
""")

# 삭제 후 Drink 수
print(len(run_cypher("""
MATCH (d:Drink)
RETURN d
""")))
```

**결과**

```text
9
8
```

### 없는 속성 찾기 → SET으로 추가

`MERGE`로 만든 카푸치노에는 아직 `price`가 없음.

```python
no_price = run_cypher("""
MATCH (d:Drink)
WHERE d.price IS NULL
RETURN d.name AS name
""")

display(no_price)
```

**결과**

```python
[{'name': '카푸치노'}]
```

`SET`으로 속성과 레이블을 함께 추가.

```python
run_cypher("""
MATCH (d:Drink {name: '카푸치노'})
SET d.price = 4300,
    d.temp = '핫',
    d:New
""")

check = run_cypher("""
MATCH (d:Drink {name: '카푸치노'})
RETURN d.name AS name,
       d.price AS price,
       d.temp AS temp
""")

new_drinks = run_cypher("""
MATCH (d:Drink:New)
RETURN d.name AS name
ORDER BY name
""")

display(check)
display(new_drinks)
```

**결과**

```python
[{'name': '카푸치노', 'price': 4300, 'temp': '핫'}]
[{'name': '카푸치노'}]
```

```text
SET d.price = 4300 → 속성 추가/수정
SET d:New          → 레이블 추가
```

### REMOVE로 속성과 레이블 제거

```python
# 속성 제거
run_cypher("""
MATCH (d:Drink {name: '캐모마일티'})
REMOVE d.temp
""")

# 레이블 제거
run_cypher("""
MATCH (d:Drink {name: '카푸치노'})
REMOVE d:New
""")
```

```text
REMOVE d.temp → 속성 제거
REMOVE d:New  → 레이블 제거
```

원본에는 `d.temp` 제거 확인 코드까지 있으나, 해당 출력 결과는 별도로 기록되어 있지 않음.

### `<>`와 `IS NULL` 구분

값이 다른 것과 속성 자체가 없는 것은 별도 조건.

```python
# temp 값이 '아이스'가 아닌 음료
not_ice = run_cypher("""
MATCH (d:Drink)
WHERE d.temp <> '아이스'
RETURN d.name AS name
""")

# temp 속성 자체가 없는 음료
no_temp = run_cypher("""
MATCH (d:Drink)
WHERE d.temp IS NULL
RETURN d.name AS name
""")

display(not_ice)
display(no_temp)
```

**결과**

```python
# temp 값이 존재하면서 '아이스'가 아님
[
    {'name': '아메리카노'},
    {'name': '카페라떼'},
    {'name': '녹차라떼'},
    {'name': '카푸치노'}
]

# temp 속성 자체가 없음
[
    {'name': '캐모마일티'}
]
```

```text
d.temp <> '아이스' → 값 비교
d.temp IS NULL     → 속성 없음
```

## 5. 결과 가공과 다양한 자료형

### DISTINCT로 관계 결과 중복 제거

아이스 음료들이 속한 분류만 추출.

```python
ice_categories = run_cypher("""
MATCH (d:Drink)-[:IN_CATEGORY]->(c:Category)
WHERE d.temp = '아이스'
RETURN DISTINCT c.name AS name
""")

display(ice_categories)
```

**결과**

```python
[{'name': '커피'}, {'name': '스무디'}]
```

여러 아이스 음료가 같은 `커피` 분류에 연결되어 있어도 `DISTINCT`로 한 번만 반환.

### ORDER BY + LIMIT으로 상위 결과 추출

```python
top3 = run_cypher("""
MATCH (d:Drink)
RETURN d.name AS name,
       d.price AS price
ORDER BY price DESC
LIMIT 3
""")

display(top3)
```

**결과**

```python
[
    {'name': '딸기스무디', 'price': 5000},
    {'name': '녹차라떼', 'price': 4500},
    {'name': '카푸치노', 'price': 4300}
]
```

```text
ORDER BY price DESC → 가격 내림차순
LIMIT 3             → 상위 3개만 반환
```

### 여러 자료형 저장과 날짜 검색

노드 속성에는 문자열·정수뿐 아니라 실수, 불리언, 날짜도 저장 가능.

```python
new_drink = run_cypher("""
CREATE (d:Drink {
    name: '제주말차',
    price: 5800,
    temp: '핫',
    rating: 4.7,
    signature: true,
    launched: date('2026-03-02')
})
RETURN d.price AS price,
       d.rating AS rating,
       d.signature AS signature,
       d.launched AS launched
""")

display(new_drink)
```

**결과**

```python
[
    {
        'price': 5800,
        'rating': 4.7,
        'signature': True,
        'launched': neo4j.time.Date(2026, 3, 2)
    }
]
```

날짜 자료형은 `date()`로 비교 가능.

```python
recent = run_cypher("""
MATCH (d:Drink)
WHERE d.launched >= date('2026-01-01')
RETURN d.name AS name
ORDER BY name
""")

display(recent)
```

**결과**

```python
[{'name': '제주말차'}]
```

## 전체 흐름 압축

```text
생성
CREATE (:Drink {...})

기존 노드 연결
MATCH (d), (c)
CREATE (d)-[:REL]->(c)

조회
MATCH (d:Drink)
WHERE 조건
RETURN 값

관계 검색
MATCH (d)-[:REL]->(x)
RETURN 값

중복 방지
MERGE 패턴
```

### 실행할 때 구분할 것

```text
CREATE  → 실행할 때마다 새로 생성
MERGE   → 같은 패턴이 있으면 기존 데이터 사용

DELETE r        → 관계만 삭제
DETACH DELETE n → 노드와 연결 관계까지 삭제

<>      → 실제 값 비교
IS NULL → 속성 자체가 없는지 확인
```
