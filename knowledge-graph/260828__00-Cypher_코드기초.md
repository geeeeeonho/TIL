# Cypher 코드 기초 - 경로 탐색·필터링·정렬

대학 선수과목 그래프를 기준으로 Cypher의 **경로 탐색**, **조건 필터링**, **관계 유무 확인**, **정렬·페이지 처리**를 코드 → 결과 구조로 정리.

---

## 0. 기본 데이터 적재

### 그래프 생성

```python
run_cypher("""
CREATE
  (c5:Course {name:'CS302 운영체제', credits:4}),
  (c3:Course {name:'CS202 알고리즘', credits:4}),
  (c6:Course {name:'CS401 머신러닝', credits:4}),
  (m2:Course {name:'수학201 선형대수', credits:3}),
  (c1:Course {name:'CS101 프로그래밍입문', credits:3}),
  (m3:Course {name:'수학202 확률통계', credits:3}),
  (c2:Course {name:'CS201 자료구조', credits:3}),
  (m1:Course {name:'수학101 미적분학', credits:3}),
  (c4:Course {name:'CS301 데이터베이스', credits:3})
CREATE
  (c1)-[:PREREQ_OF]->(c2),
  (c2)-[:PREREQ_OF]->(c3),
  (c2)-[:PREREQ_OF]->(c4),
  (c2)-[:PREREQ_OF]->(c5),
  (c3)-[:PREREQ_OF]->(c6),
  (m1)-[:PREREQ_OF]->(m2),
  (m1)-[:PREREQ_OF]->(m3),
  (m2)-[:PREREQ_OF]->(c6),
  (m3)-[:PREREQ_OF]->(c6)
""")

print(
    "선수과목 적재 완료. 과목:",
    len(run_cypher("MATCH (c:Course) RETURN c.name")),
    "개"
)
```

### 관계 확인

```python
for r in run_cypher("""
MATCH (a:Course)-[:PREREQ_OF]->(b:Course)
RETURN a.name AS 선수과목, b.name AS 다음과목
ORDER BY a.name, b.name
"""):
    print(r['선수과목'], '→', r['다음과목'])
```

**결과**

```text
CS101 프로그래밍입문 → CS201 자료구조
CS201 자료구조 → CS202 알고리즘
CS201 자료구조 → CS301 데이터베이스
CS201 자료구조 → CS302 운영체제
CS202 알고리즘 → CS401 머신러닝
수학101 미적분학 → 수학201 선형대수
수학101 미적분학 → 수학202 확률통계
수학201 선형대수 → CS401 머신러닝
수학202 확률통계 → CS401 머신러닝
```

## 1. 경로 탐색

가변 길이 관계는 다음 형태로 사용.

```text
(:노드)-[:관계*최소..최대]->(:노드)
```

- `*1..2` : 1~2단계 탐색
- `*1..` : 1단계 이상 끝까지 탐색
- `*0..2` : 자기 자신을 포함해 0~2단계 탐색

### 1-1. 가변 길이 경로 탐색

#### 1~2단계 뒤의 과목 찾기

```python
rows1_1 = run_cypher("""
MATCH (c:Course {name:'CS101 프로그래밍입문'})
      -[:PREREQ_OF*1..2]->(next:Course)
RETURN DISTINCT next.name AS name
""")

print(rows1_1)
```

**결과**

```python
[
    {'name': 'CS201 자료구조'},
    {'name': 'CS302 운영체제'},
    {'name': 'CS202 알고리즘'},
    {'name': 'CS301 데이터베이스'}
]
```

#### 특정 목적지까지 이어지는 모든 선수과목 찾기

```python
rows1_2 = run_cypher("""
MATCH (prev:Course)-[:PREREQ_OF*1..]->
      (c:Course {name:'CS401 머신러닝'})
RETURN DISTINCT prev.name AS name
""")

print(rows1_2)
```

**결과**

```python
[
    {'name': 'CS202 알고리즘'},
    {'name': '수학201 선형대수'},
    {'name': '수학202 확률통계'},
    {'name': 'CS201 자료구조'},
    {'name': '수학101 미적분학'},
    {'name': 'CS101 프로그래밍입문'}
]
```

#### 자기 자신까지 포함하기

```python
rows1_3 = run_cypher("""
MATCH (c:Course {name:'CS101 프로그래밍입문'})
      -[:PREREQ_OF*0..2]->(next:Course)
RETURN DISTINCT next.name AS name
""")

print(rows1_3)
```

**결과**

```python
[
    {'name': 'CS101 프로그래밍입문'},
    {'name': 'CS201 자료구조'},
    {'name': 'CS302 운영체제'},
    {'name': 'CS202 알고리즘'},
    {'name': 'CS301 데이터베이스'}
]
```

### 1-2. 최단 경로와 거리 계산

#### `shortestPath()`로 최단 경로 찾기

```python
rows1_4 = run_cypher("""
MATCH
  (start:Course {name:'CS101 프로그래밍입문'}),
  (end:Course {name:'CS401 머신러닝'})

MATCH p = shortestPath(
  (start)-[:PREREQ_OF*]->(end)
)

RETURN [n IN nodes(p) | n.name] AS names
""")

print(rows1_4)
```

**결과**

```python
[
    {
        'names': [
            'CS101 프로그래밍입문',
            'CS201 자료구조',
            'CS202 알고리즘',
            'CS401 머신러닝'
        ]
    }
]
```

- `nodes(p)` : 경로에 포함된 노드 목록
- `[n IN nodes(p) | n.name]` : 각 노드에서 `name`만 추출

#### 최단 경로의 단계 수 구하기

```python
rows1_5 = run_cypher("""
MATCH
  (start:Course {name:'수학101 미적분학'}),
  (end:Course {name:'CS401 머신러닝'})

MATCH p = shortestPath(
  (start)-[:PREREQ_OF*]->(end)
)

RETURN length(p) AS L
""")

print(rows1_5)
```

**결과**

```python
[{'L': 2}]
```

`length(p)`는 경로에 포함된 **관계의 개수**, 즉 이동 단계를 반환.

#### 여러 과목까지의 최단 거리 계산

```python
rows1_6 = run_cypher("""
MATCH
  (start:Course {name:'CS101 프로그래밍입문'}),
  (end:Course)

WHERE end.name <> 'CS101 프로그래밍입문'

MATCH p = shortestPath(
  (start)-[:PREREQ_OF*]->(end)
)

RETURN end.name AS name, length(p) AS L
ORDER BY L DESC, name ASC
""")

print(rows1_6)
```

**결과**

```python
[
    {'name': 'CS401 머신러닝', 'L': 3},
    {'name': 'CS202 알고리즘', 'L': 2},
    {'name': 'CS301 데이터베이스', 'L': 2},
    {'name': 'CS302 운영체제', 'L': 2},
    {'name': 'CS201 자료구조', 'L': 1}
]
```

## 2. 조건 필터링

### 2-1. 목록에 포함된 값 찾기 - `IN`

Python 목록을 파라미터로 전달하고 `IN`으로 필요한 과목만 필터링.

```python
names_list = [
    'CS201 자료구조',
    '수학201 선형대수',
    'CS999 없는과목'
]

rows2_1 = run_cypher("""
MATCH (c:Course)
WHERE c.name IN $names
RETURN c.name AS name
""", names=names_list)

print(rows2_1)
```

**결과**

```python
[
    {'name': '수학201 선형대수'},
    {'name': 'CS201 자료구조'}
]
```

- `IN` : 목록 안에 값이 있는지 검사
- `$names` : Python에서 전달한 파라미터
- 실제 그래프에 없는 `CS999 없는과목`은 결과에서 제외

### 2-2. 문자열 기준 필터링

#### 포함 여부 - `CONTAINS`

```python
rows2_2 = run_cypher("""
MATCH (c:Course)
WHERE c.name CONTAINS '201'
RETURN c.name AS name
""")

print(rows2_2)
```

**결과**

```python
[
    {'name': '수학201 선형대수'},
    {'name': 'CS201 자료구조'}
]
```

#### 접두어 - `STARTS WITH`

```python
rows2_3 = run_cypher("""
MATCH (c:Course)
WHERE c.name STARTS WITH '수학'
RETURN c.name AS name
""")

print(rows2_3)
```

**결과**

```python
[
    {'name': '수학201 선형대수'},
    {'name': '수학202 확률통계'},
    {'name': '수학101 미적분학'}
]
```

#### 접미어 - `ENDS WITH`

```python
rows2_4 = run_cypher("""
MATCH (c:Course)
WHERE c.name ENDS WITH '학'
RETURN c.name AS name
""")

print(rows2_4)
```

**결과**

```python
[{'name': '수학101 미적분학'}]
```

### 2-3. 비교·논리 조건

#### 같지 않음 - `<>`

```python
rows2_5 = run_cypher("""
MATCH (c:Course)
WHERE c.credits <> 4
RETURN c.name AS name
ORDER BY name ASC
""")

print(rows2_5)
```

**결과**

```python
[
    {'name': 'CS101 프로그래밍입문'},
    {'name': 'CS201 자료구조'},
    {'name': 'CS301 데이터베이스'},
    {'name': '수학101 미적분학'},
    {'name': '수학201 선형대수'},
    {'name': '수학202 확률통계'}
]
```

#### 두 조건 중 하나 - `OR`

```python
rows2_6 = run_cypher("""
MATCH (c:Course)
WHERE c.name STARTS WITH '수학'
   OR c.credits = 4
RETURN c.name AS name
""")

print(rows2_6)
```

**결과**

```python
[
    {'name': 'CS302 운영체제'},
    {'name': 'CS202 알고리즘'},
    {'name': 'CS401 머신러닝'},
    {'name': '수학201 선형대수'},
    {'name': '수학202 확률통계'},
    {'name': '수학101 미적분학'}
]
```

### 2-4. 정규식 필터링 - `=~`

대소문자를 구분하지 않고 `CS`로 시작하는 과목 검색.

```python
rows2_7 = run_cypher("""
MATCH (c:Course)
WHERE c.name =~ '(?i)cs.*'
RETURN c.name AS name
""")

print(rows2_7)
```

**결과**

```python
[
    {'name': 'CS302 운영체제'},
    {'name': 'CS202 알고리즘'},
    {'name': 'CS401 머신러닝'},
    {'name': 'CS101 프로그래밍입문'},
    {'name': 'CS201 자료구조'},
    {'name': 'CS301 데이터베이스'}
]
```

정규식 구성:

```text
(?i)  → 대소문자 구분 안 함
cs    → cs로 시작
.*    → 뒤에 임의의 문자가 0개 이상 이어짐
```

## 3. 관계 유무로 필터링

### 3-1. 선수과목이 없는 과목 찾기

`PREREQ_OF` 관계가 **들어오는 과목이 없는 노드**를 찾음.

```python
rows3_1 = run_cypher("""
MATCH (c:Course)
WHERE NOT (:Course)-[:PREREQ_OF]->(c)
RETURN c.name AS name
""")

print(rows3_1)
```

**결과**

```python
[
    {'name': 'CS101 프로그래밍입문'},
    {'name': '수학101 미적분학'}
]
```

### 3-2. 다음 과목이 있는 과목 찾기

`PREREQ_OF` 관계가 **밖으로 나가는 과목**만 선택.

```python
rows3_2 = run_cypher("""
MATCH (c:Course)
WHERE (c)-[:PREREQ_OF]->(:Course)
RETURN c.name AS name
""")

print(rows3_2)
```

**결과**

```python
[
    {'name': 'CS202 알고리즘'},
    {'name': '수학201 선형대수'},
    {'name': 'CS101 프로그래밍입문'},
    {'name': '수학202 확률통계'},
    {'name': 'CS201 자료구조'},
    {'name': '수학101 미적분학'}
]
```

## 4. 정렬과 결과 범위 제한

### 4-1. 정렬 후 상위 N개 - `ORDER BY` + `LIMIT`

학점은 내림차순, 같은 학점이면 이름 오름차순으로 정렬.

```python
rows4_1 = run_cypher("""
MATCH (c:Course)
RETURN c.name AS name
ORDER BY c.credits DESC, c.name ASC
LIMIT 3
""")

print(rows4_1)
```

**결과**

```python
[
    {'name': 'CS202 알고리즘'},
    {'name': 'CS302 운영체제'},
    {'name': 'CS401 머신러닝'}
]
```

### 4-2. 앞 결과를 건너뛰고 다음 N개 - `SKIP` + `LIMIT`

```python
rows4_2 = run_cypher("""
MATCH (c:Course)
RETURN c.name AS name
ORDER BY c.credits DESC, c.name ASC
SKIP 3
LIMIT 3
""")

print(rows4_2)
```

**결과**

```python
[
    {'name': 'CS101 프로그래밍입문'},
    {'name': 'CS201 자료구조'},
    {'name': 'CS301 데이터베이스'}
]
```

## 핵심 정리

| 목적 | 핵심 문법 | 의미 |
|---|---|---|
| 가변 길이 경로 | `[:REL*1..2]` | 1~2단계 관계 탐색 |
| 끝까지 경로 탐색 | `[:REL*1..]` | 1단계 이상 탐색 |
| 자기 자신 포함 | `[:REL*0..2]` | 0단계부터 탐색 |
| 최단 경로 | `shortestPath()` | 두 노드 사이 최단 경로 |
| 경로 길이 | `length(p)` | 경로의 관계 개수 |
| 목록 필터 | `IN` | 목록 안에 포함된 값 검색 |
| 문자열 포함 | `CONTAINS` | 특정 문자열 포함 여부 |
| 접두어·접미어 | `STARTS WITH`, `ENDS WITH` | 문자열 시작·끝 기준 검색 |
| 정규식 | `=~` | 패턴 기반 문자열 검색 |
| 관계 유무 | `WHERE (a)-[:R]->(b)` | 특정 관계가 존재하는 노드 선택 |
| 관계 없음 | `WHERE NOT (...)` | 특정 관계가 없는 노드 선택 |
| 정렬 | `ORDER BY ... ASC/DESC` | 결과 순서 지정 |
| 상위 결과 제한 | `LIMIT n` | 앞에서 n개만 반환 |
| 결과 건너뛰기 | `SKIP n` | 앞에서 n개 제외 |
