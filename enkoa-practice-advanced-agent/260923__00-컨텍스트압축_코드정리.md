# 컨텍스트 압축 코드 정리

검색된 문서를 그대로 LLM에 넘기지 않고, **질문에 필요한 부분만 추출해 컨텍스트를 줄이는 과정** 정리.

전체 흐름:

```text
리랭킹 결과
  -> 조건·예외 확인
  -> LLMChainExtractor로 필요한 문장 추출
  -> 압축된 근거로 답변 생성
  -> 리랭킹 + 추출 파이프라인 통합
```

---

## 1. 원문의 답변 조건·예외 확인

먼저 리랭킹된 문서 안에 질문 답변에 필요한 **조건과 예외 조항이 실제로 포함되어 있는지 확인**한다.

### 코드

```python
# 선택된 원문 확인
show_results(reranked)

# 질문에 필요한 핵심 근거를 미리 정의
review_criteria = [
    {
        "item": "국내 출장 개인 카드 결제 기준",
        "source_id": "reg01",
        "fact": "다만 제6조의 개인 카드 결제분은 법인카드·경비 정산 지침의 기한을 따른다."
    },
    {
        "item": "일반 개인 카드 청구 기한",
        "source_id": "reg03",
        "fact": "법인카드가 아직 없는 신규 입사자이거나 카드 결제가 거절된 경우처럼 불가피하게 개인 카드로 결제한 업무 비용은 결제일로부터 30일 안에 청구할 수 있다."
    },
    {
        "item": "해외 출장 개인 카드 정산 기한",
        "source_id": "reg02",
        "fact": "법인카드 결제가 거절되었거나 법인카드를 받지 않는 가맹점이라 개인 카드로 결제했다면, 귀국 후 14일 안에 개인 카드 매출전표와 영수증, 법인카드를 쓰지 못한 사유서를 함께 제출하면 정산한다."
    },
]

# 필요한 원문이 리랭킹 결과에 포함되었는지 확인
selected_ids = [doc.metadata["source_id"] for doc in reranked]

display(pd.DataFrame([
    {**row, "selected": row["source_id"] in selected_ids}
    for row in review_criteria
]))
```

### 결과

```text
결과 문서 수: 3

[1] reg03 - 법인카드·경비 정산 지침
    - 일반 개인 카드 결제: 결제일로부터 30일 안에 청구
    - 해외 출장 개인 카드 결제: 해외 출장 여비 규정의 기한을 따름

[2] reg02 - 해외 출장 여비 규정
    - 해외 출장 개인 카드 결제: 귀국 후 14일 안에 정산
    - 매출전표, 영수증, 법인카드 미사용 사유서 제출

[3] reg01 - 국내 출장 관련 규정
    - 개인 카드 결제분은 법인카드·경비 정산 지침의 기한을 따름

...
```

> 핵심: 압축 전에 필요한 근거가 검색·리랭킹 단계에서 이미 확보되었는지 먼저 확인한다.

---

## 2. 질문에 필요한 문장만 추출

`LLMChainExtractor`를 사용해 리랭킹된 문서에서 **질문과 직접 관련된 부분만 추출**한다.

### 코드

```python
# 질문과 관련된 내용만 추출하는 압축기
extractor = LLMChainExtractor.from_llm(llm)

# 리랭킹된 문서에서 필요한 부분만 추출
compressed = list(
    extractor.compress_documents(reranked, question)
)

# 압축 전후 비교
excerpt_table = excerpt_rows(
    before=reranked,
    after=compressed
)

with pd.option_context("display.max_colwidth", None):
    display(pd.DataFrame(excerpt_table))
```

### 결과

긴 원문은 생략하고 핵심 상태만 보면 다음과 같다.

| source_id | 압축 후 유지 | 원문과 연속 구간 일치 |
|---|---:|---:|
| `reg03` | True | True |
| `reg02` | True | True |
| `reg01` | True | False |

```text
original: 전체 규정 원문 ...
excerpt : 질문에 필요한 개인 카드 결제·정산 관련 문장만 추출 ...
```

- `retained=True`: 해당 문서에서 관련 내용이 압축 후에도 남음.
- `contiguous_match=False`: 추출 결과가 원문의 하나의 연속 구간과 완전히 동일한 형태는 아님.

> 압축은 문맥을 줄여 주지만, 조건·예외가 빠지지 않았는지 별도 검증이 필요하다.

## 3. 압축된 근거로 답변 생성

압축된 문서의 **원문 ID·제목·출처·본문**을 하나의 컨텍스트로 묶어 LLM에 전달한다.

### 코드

```python
def format_context(documents):
    """검색·압축된 원문을 답변용 문맥으로 변환한다."""
    context_parts = []

    for doc in documents:
        context = (
            f"[{doc.metadata['source_id']}] {doc.metadata['title']}\n"
            f"출처: {doc.metadata['url']}\n{doc.page_content}"
        )
        context_parts.append(context)

    return "\n\n".join(context_parts)
```

근거 밖의 내용을 추측하지 않도록 답변 프롬프트를 구성한다.

```python
answer_prompt = ChatPromptTemplate.from_messages([
    (
        "system",
        "제공된 원문 근거로만 답하세요. 주장마다 [원문 ID]를 인용하세요. "
        "근거에 답이 없으면 확인할 수 없다고 말하세요. 자료의 빈 부분을 추측하지 마세요."
    ),
    (
        "human",
        "질문: {question}\n\n원문 근거:\n{context}"
    ),
])

answer_chain = answer_prompt | llm | StrOutputParser()

if compressed:
    compressed_answer = answer_chain.invoke({
        "question": question,
        "context": format_context(compressed),
    })
else:
    compressed_answer = "전달할 근거가 없어 답변을 생성하지 않았습니다."

print(compressed_answer)
```

### 결과

```text
해외 출장 중 법인카드 결제가 거절되어 개인 카드로 결제한 경우,
귀국 후 14일 안에 정산을 신청해야 한다. [reg02]

제출 자료:
- 개인 카드 매출전표
- 영수증
- 법인카드를 사용하지 못한 사유서 [reg02]

개인 카드 결제 금액은 결제일의 카드사 청구 환율로 원화 환산한다. [reg02]

따라서 일반 개인 카드 결제의 30일 기준이 아니라,
해외 출장 규정의 귀국 후 14일 기준이 적용된다. [reg03] [reg02]
```

## 4. 리랭킹 + 추출을 하나의 파이프라인으로 연결

`DocumentCompressorPipeline`에 리랭커와 추출기를 순서대로 넣으면 다음 과정을 한 번에 실행할 수 있다.

```text
Hybrid 검색 -> Reranking -> 관련 문장 추출
```

### 코드

```python
next_question = (
    "회사 지원으로 외부 교육을 듣고, "
    "교육이 끝난 지 6개월 만에 이직하면 지원금을 돌려줘야 하나요?"
)

# 리랭킹 -> 문장 추출 순서로 실행
compressor = DocumentCompressorPipeline(
    transformers=[reranker, extractor]
)

compression_retriever = ContextualCompressionRetriever(
    base_retriever=hybrid,
    base_compressor=compressor
)

# 검색 -> 리랭킹 -> 추출
next_compressed = compression_retriever.invoke(next_question)

print("근거 원문 ID:", question_by_id["r02"]["evidence"])
show_results(next_compressed)

# 중요한 예외 조항이 압축 후에도 남았는지 확인
key_exception = "다만 권고사직이나 회사 사정에 따른 퇴사는 반환하지 않으며"

print(
    "예외 조항이 추출문에 남았는지:",
    any(
        key_exception in doc.page_content
        for doc in next_compressed
    )
)
```

### 결과

```text
근거 원문 ID: ['reg04']
결과 문서 수: 1

[1] reg04 - 사내 교육비 지원 규정
제6조(반환)
교육 종료 후 1년 안에 스스로 퇴사하면 지원금 전액 반환.
다만 권고사직이나 회사 사정에 따른 퇴사는 반환하지 않으며,
1년이 지난 뒤의 퇴사도 반환하지 않는다.

예외 조항이 추출문에 남았는지: True
```

---

## 핵심 정리

```text
1. 검색·리랭킹으로 필요한 원문 확보
2. 답변에 필요한 조건·예외가 포함되었는지 확인
3. LLMChainExtractor로 질문 관련 문장만 추출
4. 압축된 근거만 LLM에 전달해 답변 생성
5. DocumentCompressorPipeline으로 리랭킹 + 추출을 연결
```

**주의:** 컨텍스트 압축은 검색되지 않은 근거를 새로 찾는 과정이 아니다. 검색 단계에서 필요한 문서를 놓치면 이후 압축 단계에서도 복구할 수 없다.
