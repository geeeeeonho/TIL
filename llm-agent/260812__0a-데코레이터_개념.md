# Python 데코레이터 정리

> **데코레이터(Decorator)** = 기존 함수를 받아 기능을 덧붙인 새 함수로 감싸는 방식.
>
> 핵심 흐름: `함수도 값` → `함수를 인자로 전달` → `함수 안에서 새 함수 생성` → `@문법으로 축약`

---

## 1. 함수도 값으로 취급된다

파이썬에서는 함수 자체도 변수에 담거나 다른 함수에 전달할 수 있는 값이다.

- `greet('민수')` : 함수를 **호출**하고 결과를 얻음
- `greet` : 함수를 호출하지 않고 **함수 객체 자체**를 가리킴

```python
def greet(name):
    return f'안녕하세요, {name}님'

# 괄호가 있으면 함수 호출
print(greet('민수'))

# 괄호가 없으면 함수 자체
print(greet)

# 같은 함수에 다른 이름을 붙임
hello = greet

print(hello('민수'))
print(hello is greet)
```

### 결과

```text
안녕하세요, 민수님
<function greet at 0x...>
안녕하세요, 민수님
True
```

`hello = greet`는 함수를 복사하는 것이 아니라 **같은 함수 객체를 다른 이름으로 가리키는 것**이다.

---

## 2. 함수 자체를 다른 함수의 인자로 전달할 수 있다

함수를 호출하지 않고 이름만 넘기면 다른 함수에서 그 함수를 사용할 수 있다.

```python
def run_twice(func, value):
    """함수와 값을 받아 해당 함수를 두 번 실행한다."""
    first = func(value)
    second = func(value)
    return [first, second]

print(run_twice(greet, '민수'))
print(run_twice(len, '데코레이터'))
```

### 결과

```text
['안녕하세요, 민수님', '안녕하세요, 민수님']
[5, 5]
```

핵심은 `greet()`가 아니라 **`greet`를 전달한다는 점**이다.

## 3. 함수를 감싸서 새 함수를 만들 수 있다

데코레이터의 기본 구조.

```python
def shout(func):
    """원래 함수의 결과 뒤에 느낌표를 붙이는 새 함수를 만든다."""

    def wrapper(name):
        result = func(name)      # 원래 함수 실행
        return result + '!!!'    # 결과에 기능 추가

    return wrapper               # 실행 결과가 아니라 함수 자체 반환


loud_greet = shout(greet)

print(greet('민수'))
print(loud_greet('민수'))
```

### 결과

```text
안녕하세요, 민수님
안녕하세요, 민수님!!!
```

구조는 다음과 같다.

```text
원래 함수
   ↓
shout(func)
   ↓
wrapper 생성
   ↓
원래 함수 실행 + 추가 기능
   ↓
wrapper 반환
```

즉, **원래 함수를 직접 수정하지 않고 감싼 함수에서 기능을 추가**한다.

## 4. `@`는 데코레이터 적용을 줄여 쓰는 문법

다음 두 코드는 같은 의미다.

### 직접 작성

```python
def welcome(name):
    return f'환영합니다, {name}님'

welcome = shout(welcome)
```

### `@` 사용

```python
@shout
def welcome(name):
    return f'환영합니다, {name}님'
```

즉,

```python
@shout
def welcome(...):
    ...
```

는 아래를 축약한 표현이다.

```python
welcome = shout(welcome)
```

### 실행

```python
print(welcome('민수'))
```

### 결과

```text
환영합니다, 민수님!!!
```

## 5. 간단한 데코레이터 직접 만들기

함수의 반환값을 대괄호로 감싸는 `bracket` 데코레이터.

```python
def bracket(func):
    def wrapper(text):
        result = func(text)
        return '[' + str(result) + ']'

    return wrapper


@bracket
def title(text):
    return text


print(title('공지사항'))
print(title(1 + 2))
```

### 결과

```text
[공지사항]
[3]
```

## 6. 여러 함수에 적용하려면 `*args`, `**kwargs` 사용

문제점:

```python
def wrapper(name):
    ...
```

이렇게 만들면 인자 1개를 받는 함수만 감쌀 수 있다.

원래 함수가 몇 개의 인자를 받을지 모를 때 `*args`, `**kwargs`를 사용한다.

| 표기 | 받는 값 | 내부 형태 | 예시 |
|---|---|---|---|
| `*args` | 위치 인자 | 튜플 | `add(2, 3)` → `(2, 3)` |
| `**kwargs` | 키워드 인자 | 딕셔너리 | `add(a=2, b=3)` → `{'a': 2, 'b': 3}` |

### `*args` 예시

```python
def add(*args):
    total = 0

    for num in args:
        total += num

    return total


print(add(1, 23, 4, 5, 5, 4, 4, 5, 1, 30, 40, 40))
```

### 결과

```text
162
```

### `**kwargs` 예시

```python
def sum_kw(**kwargs):
    total = 0

    for key, val in kwargs.items():
        print(key, val)
        total += val

    return total


print(sum_kw(a=3, b=4, c=6, d=9))
```

### 결과

```text
a 3
b 4
c 6
d 9
22
```

## 7. 범용 데코레이터 구조

`wrapper`가 모든 형태의 인자를 받을 수 있게 만든다.

```python
def shout_any(func):
    """인자 개수와 상관없이 함수를 감싼다."""

    def wrapper(*args, **kwargs):
        # 받은 인자를 그대로 원래 함수에 전달
        result = func(*args, **kwargs)
        return result + '!!!'

    return wrapper
```

핵심:

```python
# 받을 때: 여러 인자를 한 번에 모음
wrapper(*args, **kwargs)

# 넘길 때: 모아 둔 인자를 다시 펼쳐서 전달
func(*args, **kwargs)
```

### 적용

```python
@shout_any
def add2(a, b):
    return f'{a} + {b} = {a + b}'


@shout_any
def hi(name):
    return f'안녕, {name}'


print(add2(2, 3))
print(add2(a=2, b=3))
print(hi('민수'))
```

### 결과

```text
2 + 3 = 5!!!
2 + 3 = 5!!!
안녕, 민수!!!
```

## 8. 데코레이터를 씌우면 함수 정보가 바뀔 수 있다

기본 데코레이터는 원래 함수 대신 `wrapper`를 반환한다.

따라서 함수 이름과 설명도 `wrapper`의 정보로 보일 수 있다.

```python
@shout_any
def introduce(name):
    """이름을 받아 자기소개 문장을 만든다."""
    return f'저는 {name}입니다'


print('이름:', introduce.__name__)
print('설명:', introduce.__doc__)
```

### 결과

```text
이름: wrapper
설명: None
```

## 9. `functools.wraps`로 원래 함수 정보 유지

`@functools.wraps(func)`를 `wrapper`에 붙이면 원래 함수의 이름과 설명을 유지할 수 있다.

```python
import functools


def shout_keep(func):
    """원래 함수의 이름과 설명을 유지하면서 감싼다."""

    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs) + '!!!'

    return wrapper


@shout_keep
def introduce2(name):
    """이름을 받아 자기소개 문장을 만든다."""
    return f'저는 {name}입니다'


print('이름:', introduce2.__name__)
print('설명:', introduce2.__doc__)
print('동작:', introduce2('민수'))
```

### 결과

```text
이름: introduce2
설명: 이름을 받아 자기소개 문장을 만든다.
동작: 저는 민수입니다!!!
```

### 핵심

```python
@functools.wraps(func)
```

주로 유지되는 정보:

- `__name__` : 함수 이름
- `__doc__` : docstring

데코레이터를 만들 때 기본적으로 붙여 두는 것이 안전하다.

## 10. 실전 예시: 함수 호출 로그 남기기

함수가 호출될 때 인자와 반환값을 출력하는 데코레이터.

```python
import functools


def log_call(func):
    """함수 호출 시 인자와 반환값을 출력한다."""

    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f'[호출] {func.__name__} args={args} kwargs={kwargs}')

        result = func(*args, **kwargs)

        print(f'[반환] {result}')
        return result

    return wrapper


@log_call
def multiply(a, b):
    return a * b


print(multiply(3, 10))
```

### 결과

```text
[호출] multiply args=(3, 10) kwargs={}
[반환] 30
30
```

기존 내장 함수도 직접 감쌀 수 있다.

```python
my_max = log_call(max)
print(my_max(1, 2, 34, 54, 2, 1, 3, 4, 19, 100))
```

### 결과

```text
[호출] max args=(1, 2, 34, 54, 2, 1, 3, 4, 19, 100) kwargs={}
[반환] 100
100
```

## 11. LangChain의 `@tool`과 연결

교안의 `@tool`도 데코레이터 구조로 이해할 수 있다.

```python
@tool
def supply_stock(item_name: str) -> int:
    """비품 이름을 받아 현재 창고 재고 수량을 돌려준다."""
    return _STOCK.get(item_name.strip(), 0)
```

개념적으로 다음 구조다.

```python
supply_stock = tool(supply_stock)
```

일반 데코레이터와 연결하면:

```text
@shout
함수 → 기능을 추가한 함수 반환

@tool
함수 → 모델이 사용할 수 있는 도구 객체로 변환
```

`tool`은 원래 함수의 정보를 활용해 도구 정보를 만든다.

- 함수 이름 → 도구 이름
- docstring → 도구 설명
- 함수 인자 → 도구가 받을 인자 명세

즉, `@tool`을 이해하려면 먼저 **파이썬 데코레이터 구조**를 이해하면 된다.

## 12. 확인 문제

### Q1. `@shout`를 사용하지 않고 같은 동작을 만들려면?

```python
def greet(name):
    return f'안녕하세요, {name}님'


greet = shout(greet)
```

`@shout`는 이 재할당을 함수 정의 위에서 줄여 쓴 문법이다.

### Q2. `wrapper(*args, **kwargs)`를 사용하는 이유는?

감싸는 함수는 원래 함수가 인자를 몇 개 받는지 알 수 없기 때문.

```python
def wrapper(*args, **kwargs):
    return func(*args, **kwargs)
```

이 구조를 사용하면 다양한 형태의 함수를 같은 데코레이터로 감쌀 수 있다.

### Q3. `functools.wraps`를 사용하는 이유는?

데코레이터 적용 후에도 원래 함수의 이름과 설명을 유지하기 위해 사용.

특히 함수의 `__name__`, `__doc__` 같은 메타데이터를 활용하는 기능에서 중요하다.

# 최종 정리

| 개념 | 핵심 |
|---|---|
| 함수도 값 | 괄호가 없으면 함수 객체 자체를 가리킴 |
| 함수 전달 | 함수를 다른 함수의 인자로 넘길 수 있음 |
| 데코레이터 | 함수를 받아 기능을 추가한 결과를 반환 |
| 내부 `wrapper` | 원래 함수를 실행하고 앞뒤에 기능을 추가하는 함수 |
| `@decorator` | `함수 = decorator(함수)`의 축약 문법 |
| `*args` | 위치 인자를 튜플로 모음 |
| `**kwargs` | 키워드 인자를 딕셔너리로 모음 |
| `func(*args, **kwargs)` | 모은 인자를 다시 펼쳐 원래 함수에 전달 |
| `functools.wraps` | 원래 함수의 이름·설명 등 메타데이터 유지 |
| `@tool` | 일반 함수를 모델이 사용할 수 있는 도구 형태로 변환 |

## 데코레이터 기본 템플릿

```python
import functools


def decorator(func):

    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        # 함수 실행 전 기능

        result = func(*args, **kwargs)

        # 함수 실행 후 기능

        return result

    return wrapper
```

가장 중요한 구조만 기억하면 된다.

```text
함수도 값이다
    ↓
함수를 다른 함수에 전달한다
    ↓
wrapper에서 원래 함수를 실행한다
    ↓
원하는 기능을 앞뒤에 추가한다
    ↓
wrapper를 반환한다
    ↓
@문법으로 간단히 적용한다
```
