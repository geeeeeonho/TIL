## 1단계: 파일시스템 서버에 붙어 도구 목록·명세를 보고 직접 호출하기

### 코드

```python
import asyncio

from langchain_mcp_adapters.client import MultiServerMCPClient

from 공통 import DATA_DIR, FILESYSTEM


async def main():
    # 파일시스템 서버: 정해 준 폴더의 파일 목록·읽기·쓰기 도구를 내준다.
    # FILESYSTEM = {
    #     "command": "npx",                                    # 서버를 띄울 실행기(Node 패키지를 받아 실행한다)
    #     "args": ["-y",                                       # 설치할지 묻지 않고 진행
    #             "@modelcontextprotocol/server-filesystem",  # 띄울 서버 패키지 이름
    #             str(DAY_DIR)],                              # 서버가 볼 수 있는 폴더. 이 밖은 건드리지 못한다
    #     "transport": "stdio",                                # 내 컴퓨터에 프로세스로 띄우고 표준입출력으로 대화
    # }

    # 1. 파일시스템 MCP 서버에 연결할 클라이언트 생성
    client = MultiServerMCPClient({"files": FILESYSTEM})

    # 2. 서버가 제공하는 도구 목록 가져오기
    fs_tools = await client.get_tools()

    # 3. {도구 이름: 도구 객체} 형태의 딕셔너리 만들기
    # 리스트 -> 딕셔너리
    fs_by_name = {}

    for tool in fs_tools:
        fs_by_name[tool.name] = tool

    # 4. list_directory 도구 꺼내기
    list_dir_tool = fs_by_name["list_directory"]    # 특정 도구를 선택

    # 5. list_directory가 받는 인자 이름 확인
    # 선택한 도구가 받는 인자 이름(키)을 꺼냄
    list_dir_args = list(list_dir_tool.args.keys())

    # 6. list_directory 도구 직접 호출
    result = await list_dir_tool.ainvoke({
        "path": str(DATA_DIR)
    })

    # 7. 결과에서 실제 텍스트만 꺼내기
    data_listing = result[0]["text"]


    # [자가채점]
    assert len(fs_tools) >= 10, f"도구가 너무 적습니다: {len(fs_tools)}개"
    assert "list_directory" in fs_by_name, "list_directory 도구가 없습니다"
    assert list_dir_args == ["path"], f"인자 이름이 다릅니다: {list_dir_args}"
    assert isinstance(data_listing, str) and "cvs_sales.csv" in data_listing, "data 폴더 목록이 아닙니다"
    print("문제 1 통과 -- 도구", len(fs_tools), "개 · 인자:", list_dir_args)


if __name__ == "__main__":
    asyncio.run(main())
```


## 2단계: 코드 실행 서버를 에이전트에 붙여 스스로 계산하게 하기

**전체 흐름**  
`MCP 설정표 -> 클라이언트 생성 -> 실제 도구 가져오기 -> 에이전트에게 도구 장착 -> 비동기로 질문`

### 과제 내용

> """📝 과제 문제 2: 코드 실행 서버를 에이전트에 붙여 스스로 계산하게 하기
>
> `# 여기에 코드를 작성하세요` 자리를 채우고 이 파일을 실행하세요.
> 아래 `# [자가채점]` 이 답을 검사하고, 통과하면 "문제 2 통과" 가 찍힙니다.
>
> MCP 도구는 비동기 전용이라 `await 도구.ainvoke({...})` 로 부릅니다.
>
> 준비물: OPENAI_API_KEY(일차 폴더 .env) · npx(Node.js)
> 실행: 이 파일이 있는 폴더에서  uv run 문제2_코드실행_에이전트.py
> """

### 코드

```python
import asyncio

from langchain.agents import create_agent
from langchain.agents.middleware import ModelCallLimitMiddleware
from langchain_core.messages import AIMessage
from langchain_mcp_adapters.client import MultiServerMCPClient
from langchain_openai import ChatOpenAI

from 공통 import CODE_RUNNER, DAY_DIR, load_api_key
from utils import print_trajectory   # 공통.py 가 일차 폴더를 경로에 넣어 둔다

load_api_key(DAY_DIR)   # 모델을 부르는 문제라 키를 맨 앞에서 확인한다

Q2 = "1 부터 100 까지 더하면 얼마인지 알려 줘. 암산하지 말고 반드시 코드를 실행해서 계산해."


async def main():

    # 1. 사용할 모델 설정
    model = ChatOpenAI(
        model="gpt-4o-mini",
        temperature=0,
        timeout=60
    )

    # 2. 모델 호출 횟수 제한 설정
    # middleware의 일종인 ModelCallLimitMiddleware 사용
    middleware = [
        ModelCallLimitMiddleware(
            run_limit=8,
            exit_behavior="end"
        )
    ]

    # 3. CODE_RUNNER 설정으로 MCP 클라이언트 생성
    client = MultiServerMCPClient({
        "code_runner": CODE_RUNNER
    })
    # CODE_RUNNER = {
    # "command": "npx",                          # Node 패키지 실행기
    # "args": ["-y", "mcp-server-code-runner"],  # 묻지 않고 진행 + 띄울 서버 패키지 이름
    # "transport": "stdio",
    # "env": CHILD_ENV,                          # 위에서 만든 환경 변수(서버가 python 을 찾게 한다)
    # }  

    # 4. MCP 서버가 제공하는 실제 도구 목록 가져오기
    code_tools = await client.get_tools()

    # 5. 모델 + 코드 실행 도구를 가진 에이전트 생성
    math_agent = create_agent(
        model=model,        # 미리 생성한 OpenAI 모델
        tools=code_tools,   # 가져온 도구 목록 등록
        # 시스템 프롬프트 : 에이전트가 따라야 할 행동 규칙 설정
        system_prompt="""  
        수치 계산은 반드시 코드 실행 도구로 한다.
        코드의 결과는 print로 출력해야 값이 돌아온다.
        결과가 비어 있다면 print를 빠뜨린 것이다.
        """,
        middleware=middleware
    )

    # 6. 에이전트에게 Q2 질문하기
    result = await math_agent.ainvoke({
        "messages": [ {
                "role": "user",
                "content": Q2
            } ]
    })

    # 7. 에이전트가 어떤 과정을 거쳤는지 출력
    print_trajectory(result)


    # [자가채점]
    called = [c["name"] for m in result["messages"] if isinstance(m, AIMessage) for c in (m.tool_calls or [])]
    answer = result["messages"][-1].text
    assert any("run-code" in name for name in called), f"코드 실행 도구를 쓰지 않았습니다: {called}"
    assert "5050" in answer, f"답에 5050 이 없습니다: {answer[:120]}"
    print("문제 2 통과 -- 호출한 도구:", called)


if __name__ == "__main__":
    asyncio.run(main())
```

## 3단계: 원격(HTTP) 문서 서버 Context7을 에이전트에 붙여 최신 문서를 찾게 하기

> """📝 과제 문제 3: 원격(HTTP) 문서 서버 Context7 을 에이전트에 붙여 최신 문서를 찾게 하기

>
> MCP 도구는 비동기 전용이라 `await 도구.ainvoke({...})` 로 부릅니다.

### 최종 답 — 교정본

원본의 최종 답은 `ChatPromptTemplate`과 `StrOutputParser`를 실제로 사용하지 않아 질문의 요구사항과 맞지 않았다.  
기초 체인은 다음처럼 **프롬프트 -> 채팅 모델 -> 문자열 출력 파서**를 `|`로 연결한다.

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate([
    ("system", "You are a helpful assistant."),
    ("human", "{question}")
])

model = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)

chain = prompt | model | StrOutputParser()

result = chain.invoke({
    "question": "파이썬이 무엇인지 한 문장으로 설명해 줘."
})

print(result)
```

- `ChatPromptTemplate`: 입력값을 채팅용 프롬프트로 만든다.
- `ChatOpenAI`: 프롬프트를 받아 모델 응답을 만든다.
- `StrOutputParser`: 모델의 메시지 응답에서 문자열 결과를 꺼낸다.
- `|`: 앞 단계의 출력을 다음 단계의 입력으로 연결한다.

### 최종 답 — 교정본

원본 최종 코드는 `ChatPromptTemplate`, `StrOutputParser`, 파이프(`|`) 체인을 사용하지 않아 문제 요구사항과 맞지 않았다.  
요구사항에 맞는 최종 코드는 다음과 같다.

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

# 1. 프롬프트 템플릿
prompt = ChatPromptTemplate([
    ("system", "You are a helpful assistant."),
    ("human", "{question}")
])

# 2. 채팅 모델
model = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0
)

# 3. 문자열 출력 파서
parser = StrOutputParser()

# 4. 프롬프트 -> 모델 -> 출력 파서를 파이프(|)로 연결
chain = prompt | model | parser

# 5. 체인 실행
result = chain.invoke({
    "question": "What is the capital of France?"
})

print(result)
```

## 핵심 정리

1. **로컬 MCP 서버**는 보통 `command`, `args`, `transport="stdio"` 형태로 실행한다.
2. `MultiServerMCPClient(...).get_tools()`로 서버가 제공하는 실제 도구 객체를 가져온다.
3. MCP 도구는 비동기이므로 직접 호출할 때 `await tool.ainvoke(...)`를 사용한다.
4. 에이전트에서는 `create_agent(model=..., tools=...)`로 모델과 도구를 묶는다.
5. 원격 Context7 MCP 서버는 `url`과 `transport="streamable_http"`로 연결한다.
6. 여러 종류의 도구는 리스트로 합쳐 하나의 에이전트에 전달할 수 있다.
7. 일반 LangChain 체인은 에이전트와 다르다. 기초 체인은 `ChatPromptTemplate | 채팅 모델 | StrOutputParser`처럼 **Runnable을 파이프로 연결**해서 만든다.

## 자주 헷갈리는 부분

- `create_agent(...)`로 만든 것은 **에이전트**이고, `prompt | model | parser`는 **체인**이다.
- 도구를 한 번 호출했다고 해서 작업이 성공한 것은 아니다. **도구 결과에 오류가 없는지도 확인**해야 한다.
- 자가채점이 통과했다고 해서 문제의 모든 요구사항을 만족했다는 뜻은 아니다. **자가채점이 무엇을 검사하는지**도 함께 봐야 한다.
