```text

   ↓

   ↓
3. Langfuse Client + CallbackHandler 준비
   ↓
4. 모델 호출에 Callback 연결
   ↓
5. Langfuse Trace에서 실행 확인
   ↓
6. usage_metadata로 토큰 사용량 확인
   ↓
7. Prompt를 Langfuse 서버에 저장
   ↓
8. Prompt 버전·production 라벨 관리
   ↓
9. get_prompt()로 사용할 Prompt 불러오기
   ↓
10. compile()로 변수 채우기
   ↓
11. 모델 호출 + Trace 기록
   ↓
12. Prompt 버전과 Trace 연결
   ↓

```

# 1. 관측성(Observability)

## 개념

**관측성**

```text
밖에 남은 기록만 보고
시스템 내부에서 무슨 일이 있었는지 파악할 수 있는 상태
```

LLM 애플리케이션에서는 다음을 확인하는 데 사용.

```text
어떤 프롬프트를 보냈는가
어떤 응답이 나왔는가
어떤 Tool이 호출됐는가
토큰을 얼마나 사용했는가
어느 단계가 느렸는가
어느 Prompt 버전을 사용했는가
```

## 기록 종류

| 종류 | 의미 | 예 |
|---|---|---|
| Log | 발생한 일을 시간순으로 기록 | Prompt, Response |
| Metric | 숫자로 집계 | Token, Latency |
| Trace | 요청 하나의 실행 경로 | Model → Tool → Model |

---

# 2. Monitoring vs Observability

```text
Monitoring
→ 미리 정한 지표를 감시
→ "실패율이 높아졌다"

Observability
→ 저장된 기록으로 원인을 추적
→ "왜 이 요청에서 실패했는가"
```

즉:

```text
Monitoring = 문제가 생겼는지 확인
Observability = 왜 문제가 생겼는지 추적
```

# 3. Langfuse 실행 구조

Langfuse는 실행을 계층 구조로 기록.

```text
Trace
 └─ Span
     └─ Generation
```

| 단위 | 의미 | 예 |
|---|---|---|
| `trace` | 사용자 요청 하나의 전체 실행 | 리포트 생성 1회 |
| `span` | Trace 내부의 작업 단계 | 비평 단계 |
| `generation` | 실제 모델 호출 | Prompt → LLM Response |

예:

```text
Trace
└─ 리포트 생성
   ├─ Generation : generate()
   ├─ Span       : critique 단계
   │   └─ Generation : critique()
   └─ Generation : revise()
```

핵심:

```text
Trace
= 전체 요청

Span
= 요청 내부 단계

Generation
= LLM 호출 하나
```

# 7. 토큰 확인: `usage_metadata`

모델 응답에는 토큰 사용 정보가 포함됨.

```python
response = model.invoke(
    "한국의 수도는?"
)

print(
    response.usage_metadata
)
```

대표 값:

```text

output_tokens
total_tokens
```

예:

```python
total = response.usage_metadata.get(
    "total_tokens",
    0,
)
```

핵심:

```text
토큰을 별도로 계산하는 것이 아님
→ 모델 응답에 들어 있는 usage_metadata를 읽음
```

# 8. 여러 호출의 토큰 합산

Self-reflection이나 Agent는 모델을 여러 번 호출할 수 있음.

```python
questions = [
    "1+1은?",
    "지구에서 가장 큰 바다는?",
    "무지개는 몇 색?",
]

total_tokens = 0

for q in questions:

    response = model.invoke(q)

    total_tokens += (
        response
        .usage_metadata
        .get("total_tokens", 0)
    )
```

구조:

```text
호출 1 Token
+
호출 2 Token
+
호출 3 Token
=
전체 Token
```

Self-reflection:

```text

+

+

```

모델 호출이 증가하면 토큰 사용량도 함께 증가.

# 25. Tool 호출 기록 확인

메시지 기록에서 Tool 이름 추출.

```python
from langchain_core.messages import (
    AIMessage,
)


def tool_trace(result):

    names = []

    for message in result["messages"]:

        if (
            isinstance(
                message,
                AIMessage,
            )
            and message.tool_calls
        ):

            for call in (
                message.tool_calls
            ):
                names.append(
                    call["name"]
                )

    return names
```

사용:

```python
tool_trace(result)
```

결과 예:

```text
[
    "course_price"
]
```

# 26. Langfuse로 Agent 라우팅 디버깅

확인.

```python
@tool
def lookup(category: str) -> str:

```

```text
무슨 정보를 제공하는 Tool인지
모델이 판단하기 어려움
```

```python
@tool
def course_price(
    category: str,
) -> int:
    """
    강의 카테고리 이름을 받아
    대표 수강료(원)를 돌려준다.

```

핵심:

```text

+
Docstring

```


```python
        "callbacks": handlers

# 6. Prompt 등록

        "production"

# 7. production Prompt 조회
production = (
    langfuse.get_prompt(
        "insight-report-writer",
        label="production",
        cache_ttl_seconds=0,

# 8. LangChain Prompt로 변환
template = (

            production
```

# 29. 기능별 핵심 정리

| 목적 | 코드 |
|---|---|
| Langfuse Client | `get_client()` |
| LangChain 실행 관측 | `CallbackHandler()` |
| Callback 연결 | `config={"callbacks": handlers}` |
| Token 확인 | `response.usage_metadata` |
| Prompt 등록 | `langfuse.create_prompt()` |
| Prompt 조회 | `langfuse.get_prompt()` |
| Prompt 변수 채우기 | `prompt.compile()` |
| LangChain Prompt 변환 | `get_langchain_prompt()` |
| Prompt Version ↔ Trace 연결 | `metadata={"langfuse_prompt": prompt}` |
| 관측 데이터 즉시 전송 | `langfuse.flush()` |
| Agent Tool 확인 | `AIMessage.tool_calls` |

# 30. 최종 흐름

```text
.env
↓
ChatOpenAI
↓
Langfuse Client
↓
CallbackHandler
↓
model / chain / agent.invoke()
↓
Trace 생성
↓
Prompt·Response·Tool·Token 확인
```

Prompt 관리까지 포함하면:

```text
Langfuse create_prompt()
↓
Version 누적
↓
production 라벨 지정

get_prompt()
↓
compile()
↓
Model 실행
↓
Trace 기록
↓
Prompt Version 연결
```

Agent 디버깅까지 포함하면:

```text
Agent 실행
↓
Langfuse Trace
↓
Tool Call 확인

Tool 이름·Docstring 문제 발견
↓
수정
↓
재실행
↓
이전 Trace와 비교
```

# 31. 핵심 암기

```text
Callback
= 실행 기록을 Langfuse로 보냄

Trace
= 요청 하나의 전체 실행

Span
= Trace 내부 단계

Generation
= LLM 호출 하나

usage_metadata
= Token 사용량

create_prompt
= Prompt 서버 등록 + Version 생성

production
= 현재 기본 사용 버전

get_prompt
= 사용할 Prompt 조회

compile
= {{변수}}에 실제 값 주입

langfuse_prompt metadata
= Prompt Version과 Trace 연결
```
