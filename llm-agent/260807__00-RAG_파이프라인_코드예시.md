## 2. 인용한 쪽을 실제로 열어서 확인

검색 결과나 답변에서 사용한 인용문이 실제 원본 페이지에 존재하는지 확인하는 절차.

```python
def check_quote(doc_id, quote):
    # 1. doc_id에 해당하는 행에서 쪽 번호 찾기
    # qna_docs[qna_docs['id'] == doc_id] : 해당 id의 행만 선택
    # ['쪽']                                : 쪽 열만 선택
    # .iloc[0]                             : 첫 번째 값을 꺼냄
    qna_page_num = qna_docs[qna_docs['id'] == doc_id]['쪽'].iloc[0]
    qna_page_num = int(qna_page_num)

    # 2. 해당 쪽 하나만 PDF에서 파싱
    page = pymupdf4llm.to_markdown(
        'data/원본/개인정보_질의응답_모음집.pdf',
        page_chunks=True,
        pages=[qna_page_num - 1]  # pages는 0부터 시작하므로 1을 뺌
    )

    # 3. 파싱 결과의 첫 번째 페이지에서 본문 문자열 꺼내기
    # page는 페이지별 딕셔너리의 리스트이므로 첫 번째 요소의 text를 사용
    page_text = page[0]['text']

    # 4. 본문 안에 quote 문자열이 포함되어 있는지 확인
    return quote in page_text


print(check_quote('q1', 'ID 등으로 이미 보유한'))
print(check_quote('q16', 'ID 등으로 이미 보유한'))
```

### 결과

```text
True
False
```

- `q1`의 해당 페이지에는 인용문이 존재함.
- `q16`의 해당 페이지에는 같은 인용문이 존재하지 않음.

## 3. 오버랩 청킹 함수 만들기

글자 수로만 문서를 끊으면 청크 경계에서 문맥이 끊길 수 있음.

앞 청크의 일부를 다음 청크에 겹쳐 넣어 경계 문맥을 어느 정도 유지함.

```python
def chunk_overlap(text, size, overlap):
    # 다음 청크 시작점까지 이동할 글자 수
    # 예: size=4, overlap=2이면 2글자씩 이동
    step = size - overlap

    # 잘라낸 문자열을 저장할 리스트
    chunks = []

    # 0부터 문자열 길이까지 step만큼 이동
    for start in range(0, len(text), step):
        # start 위치부터 최대 size 글자까지 자르기
        chunk = text[start:start + size]
        chunks.append(chunk)

    return chunks


# 테스트
print(chunk_overlap('abcdefgh', 4, 2))
print(chunk_overlap('abcdefgh', 4, 0))
```

### 결과

```text
['abcd', 'cdef', 'efgh', 'gh']
['abcd', 'efgh']
```

## 4. 여러 청킹 전략 비교

같은 질의응답 본문을 서로 다른 방식으로 잘라 결과를 비교함.

### 추가 청킹 함수

```python
def chunk_fixed(text, size):
    """고정 크기(글자 수)로 자른다."""
    return [text[i:i + size] for i in range(0, len(text), size)]


def chunk_paragraph(text, size):
    """빈 줄로 나뉜 문단을 순서대로 모아 size 근처에서 끊는다.
    한 문단 자체는 쪼개지 않는다.
    따라서 문단 하나가 size보다 길면 해당 청크는 size를 넘을 수 있다.
    """
    chunks, cur = [], ''

    for para in [p.strip() for p in text.split('\n\n') if p.strip()]:
        if cur and len(cur) + len(para) > size:
            chunks.append(cur)
            cur = para
        else:
            cur = f'{cur}\n{para}' if cur else para

    if cur:
        chunks.append(cur)

    return chunks
```

### 청킹 방식별 조각 개수 비교

```python
# qna_docs에서 id가 q70인 행의 본문을 선택
long_text = qna_docs[qna_docs['id'] == 'q70']['본문'].iloc[0]

# 각 청킹 방식으로 만든 조각 개수
fixed = len(chunk_fixed(long_text, 400))
# 400글자씩 고정 크기로 청킹

overlap = len(chunk_overlap(long_text, 400, 100))
# 최대 400글자 크기, 100글자씩 겹치도록 청킹

paragraph = len(chunk_paragraph(long_text, 400))
# 문단 자체는 자르지 않고 400자 근처에서 청킹

# 청킹 방식별 조각 개수를 딕셔너리로 정리
chunk_counts = {
    'fixed': fixed,
    'overlap': overlap,
    'paragraph': paragraph
}

print(chunk_counts)
```

### 결과

```text
{'fixed': 3, 'overlap': 4, 'paragraph': 3}
```

import chromadb

# qna_docs의 id 열을 파이썬 리스트로 변환

## 7. 임베딩 색인

문서 본문을 임베딩한 뒤 ChromaDB에 저장하여 의미 검색용 벡터 DB를 구성함.

```python
# 1. qna 본문을 임베딩하고 각 벡터의 길이를 1로 정규화
qna_embed = embed_model.encode(
    qna_texts,
    normalize_embeddings=True
)

# 2. 메모리에서 사용할 ChromaDB 클라이언트 생성
client = chromadb.EphemeralClient()

# 3. 코사인 거리 방식을 사용하는 컬렉션 생성
qna_collection = client.create_collection(
    name='qna_lv1_docs',
    metadata={'hnsw:space': 'cosine'}
)

# 4. 컬렉션에 문서 데이터 적재
qna_collection.add(
    ids=qna_ids,
    embeddings=qna_embed.tolist(),
    documents=qna_texts,
    metadatas=qna_metas
)

# 5. 저장된 문서 수 확인
print(qna_collection.count())
```

### 결과

```text
93
```

## 9. 메타데이터로 검색 범위 좁히기

벡터 유사도 검색 전에 메타데이터 조건을 적용해 특정 분야의 문서만 검색할 수 있음.

```python
# 검색 질문
ask2 = "개인정보를 얼마나 오래 보관할 수 있나요"

# 문서를 저장할 때와 같은 임베딩 모델 + 같은 정규화 옵션 사용
ask2_emb = embed_model.encode(
    [ask2],
    normalize_embeddings=True
)

# 1. 조건 없이 전체 문서에서 가장 가까운 문서 3개 검색
result_p = qna_collection.query(
    query_embeddings=ask2_emb.tolist(),
    n_results=3
)

# 검색 결과에서 doc_id 추출
plain_ids = [
    meta['doc_id']
    for meta in result_p['metadatas'][0]
]

# 2. field가 '영상정보'인 문서만 대상으로 검색
result_f = qna_collection.query(
    query_embeddings=ask2_emb.tolist(),
    where={'field': '영상정보'},
    n_results=3
)

# 필터링된 검색 결과에서 doc_id 추출
filtered_ids = [
    meta['doc_id']
    for meta in result_f['metadatas'][0]
]

print("1:", plain_ids)
print("2:", filtered_ids)
```

### 결과

```text
1: ['q59', 'q64', 'q77']
2: ['q22', 'q14', 'q19']
```

- 조건 없음: 전체 문서에서 의미적으로 가까운 문서 검색
- `where={'field': '영상정보'}`: `영상정보` 분야 안에서만 의미 검색
