# 임베딩 모델 선택 — 코드·결과 정리

## 1. 후보 선정 및 사양표 구성

의약품 안내문 **394개**와 평가 질문 **24개**를 대상으로 임베딩 모델을 비교한다. 리더보드 성적은 참고 자료로 활용하고, 최종 선택은 실제 데이터셋의 검색 성능을 기준으로 판단한다.

- **비교 대상:** OpenAI `text-embedding-3-small`(1536·512차원), `multilingual-e5-small`, `KURE-v1`

## 2. 후보별 문서·질문 임베딩

문서 394개와 질문 24개를 각각 임베딩하고 벡터를 정규화한다. **처리 시간은 문서 임베딩에 대해서만 측정**한다.

### 2-1. OpenAI 3-small (1536·512차원)

**코드**

```python
import time
import numpy as np
import pandas as pd
from langchain_openai import OpenAIEmbeddings


def normalize(vectors):
    """각 벡터의 L2 노름을 1로 정규화."""
    vectors = np.asarray(vectors, dtype=np.float32)
    return vectors / np.linalg.norm(vectors, axis=1, keepdims=True)


doc_vectors_by_model = {}
question_vectors_by_model = {}
doc_seconds = {}

# 1536차원
small_1536_model = OpenAIEmbeddings(
    model="text-embedding-3-small",
    chunk_size=100,
)

start = time.perf_counter()
doc_vectors_by_model["3-small (1536)"] = normalize(
    small_1536_model.embed_documents(drug_texts)
)
doc_seconds["3-small (1536)"] = time.perf_counter() - start

question_vectors_by_model["3-small (1536)"] = normalize(
    small_1536_model.embed_documents(eval_texts)
)

# 512차원: 같은 모델에 출력 차원만 변경
small_512_model = OpenAIEmbeddings(
    model="text-embedding-3-small",
    dimensions=512,
    chunk_size=100,
)

start = time.perf_counter()
doc_vectors_by_model["3-small (512)"] = normalize(
    small_512_model.embed_documents(drug_texts)
)
doc_seconds["3-small (512)"] = time.perf_counter() - start

question_vectors_by_model["3-small (512)"] = normalize(
    small_512_model.embed_documents(eval_texts)
)

print({name: round(seconds, 1) for name, seconds in doc_seconds.items()})
```

**결과**

```text
{'3-small (1536)': 4.8, '3-small (512)': 1.9}
```

### 2-2. 로컬 모델 (me5-small·KURE-v1)

사양표에 지정한 접두어를 적용하고 `encode(..., normalize_embeddings=True)`로 벡터를 생성한다.

**코드**

```python
local_models = {
    "me5-small (384)": me5_model,
    "KURE-v1 (1024)": kure_model,

    # 문서 접두어 적용 → 임베딩 시간 측정
    doc_prefix = model_specs[name]["doc_prefix"]
    prefixed_docs = [doc_prefix + text for text in drug_texts]

    start = time.perf_counter()
    doc_vectors_by_model[name] = model.encode(
        prefixed_docs,
        normalize_embeddings=True,
    )
    doc_seconds[name] = time.perf_counter() - start

    # 질문 접두어 적용 → 질문 임베딩
    query_prefix = model_specs[name]["query_prefix"]
    prefixed_queries = [query_prefix + text for text in eval_texts]

    question_vectors_by_model[name] = model.encode(
        prefixed_queries,
        normalize_embeddings=True,
    )

print({name: round(seconds, 1) for name, seconds in doc_seconds.items()})
```

## 3. BM25와 임베딩 모델의 검색 성능 비교

질문 24개에 대해 같은 정답 문서 ID를 기준으로 평가한다.

- **Recall@5:** 상위 5개 검색 결과에서 관련 문서를 찾은 비율의 평균
- **MRR:** 첫 번째 정답 문서가 검색된 순위의 역수를 평균한 값
- **잘림 비율(`truncated_ratio`):** 최대 입력 길이를 초과한 문서의 비율
- 정규화된 임베딩 벡터의 **내적 = 코사인 유사도**. 유사도가 높은 상위 10개 ID를 검색하고 평가 함수에서 상위 5개 등을 확인한다.

### 코드

> `bm25_top_ids`, `drug_ids`, `token_counts`, `search_top_ids()`, `evaluate_model()`, `truncated_ratio()`는 앞 단계에서 준비된 값·함수. 정의 코드는 원본 문서에 없음.

## 4. 선정 기준 함수화

동일한 규칙으로 후보를 필터링하고 모델을 선택한다.

1. BM25 기준선 제외
2. 잘림 비율이 0인 모델만 유지
3. 정답을 가장 많이 맞힌 모델과 **1문항 이내** 차이가 나는 모델만 유지
4. 남은 후보 중 **벡터 차원이 가장 작은 모델** 선정

### 코드

```python
def best_within(rows, column, tolerance):
    """최댓값과 tolerance 이내로 차이 나는 행만 반환."""
    best = rows[0][column]
    for row in rows:
        if row[column] > best:
            best = row[column]

    kept = []
    for row in rows:
        if best - row[column] <= tolerance:
            kept.append(row)
    return kept


def smallest(rows, column):
    """지정 컬럼이 가장 작은 행 반환. 동률이면 먼저 나온 행."""
    choice = rows[0]
    for row in rows[1:]:
        if row[column] < choice[column]:
            choice = row
    return choice


def select_drug_model(rows):
    candidates = [row for row in rows if row["model"] != "BM25"]
    print("0단계 (BM25 제외):", [row["model"] for row in candidates])

    candidates = [row for row in candidates if row["truncated_ratio"] == 0]
    print("1단계 (잘림 비율 0):", [row["model"] for row in candidates])

    candidates = best_within(candidates, "맞힌 문항", 1)
    print("2단계 (정확도 1문항 이내):", [row["model"] for row in candidates])

    selected = smallest(candidates, "dimension")
    print("3단계 (최소 차원):", selected["model"])
    return selected


selected_model = select_drug_model(compare_rows)
```

## 6. ADR — 최종 선택 근거

**ADR-001: 의약품 안내문 검색용 KURE-v1 채택** · 상태: 채택

- **결정:** `KURE-v1 (1024)` 사용.
- **근거:** 24문항 중 **18개 정답**, Recall@5 **0.708**, MRR **0.517**로 비교 후보 중 최고. 입력 길이 초과 문서도 없고, 외부 API에 의존하지 않음.
- **감수할 점:** CPU 기준 394개 문서 임베딩에 **839.6초(약 14분)** 소요. 1024차원 벡터로 메모리·저장 공간 부담 존재.
- **재평가 조건:** 문서 수·길이 변화, 처리 시간 요구 변경, GPU 등 실행 환경 변경, 임베딩 모델 교체. 평가 질문도 현재 **24개**뿐이므로 확대 검증 필요.

**정리:** 이 실습의 선정 기준은 `입력 잘림 없음 → 검색 정확도 → 최소 차원`. 단, 실제 운영에서는 정확도 외에도 임베딩 시간과 자원 사용량을 함께 검토해야 함.
