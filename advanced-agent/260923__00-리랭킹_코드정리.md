# 리랭킹 코드 정리

검색된 후보를 더 정밀한 모델로 다시 평가해 순위를 조정하는 과정 정리.

전체 흐름:

```text
Hybrid 검색
  → 후보 문서 확보
  → Cross Encoder / ColBERT 점수 계산
  → 상위 문서 재정렬
  → 최종 검색기에 리랭커 연결
  → 리랭커 모델별 성능 비교
```

## 1. 리랭킹 후보 검색

먼저 Hybrid Retriever로 후보 문서를 확보하고, 정답 근거 문서가 후보 안에서 몇 위인지 확인.

```python
# 질문과 정답 근거 ID
question = (
    "해외 출장 중 호텔 와이파이에서 사내 VPN이 몇 분마다 끊겨요. "
    "해외 접속 신청을 다시 해야 하나요?"
)
evidence_ids = {"help03"}

# 후보 검색
candidates = hybrid.invoke(question)
initial_top = candidates[:3]

print("후보 수:", len(candidates), "/ 최종으로 남길 수: 3")
print(
    "후보 안에서 근거 원문의 순위:",
    evidence_rank(candidates, evidence_ids)
)
```

### 결과

```text
후보 수: 7 / 최종으로 남길 수: 3
후보 안에서 근거 원문의 순위: 2
```

초기 상위 3개:

| 순위 | source_id | 제목 |
| ---: | --- | --- |
| 1 | help02 | 해외에서 사내 VPN 접속 신청하기 |
| 2 | help03 | 호텔·카페 와이파이에서 VPN이 자주 끊길 때 |
| 3 | help41 | 해외 출장 전 IT 준비 목록 |

## 2. Cross Encoder로 관련성 점수 계산

Cross Encoder는 **질문과 문서 하나를 한 쌍으로 입력**받아 관련성 점수를 계산.

```python
# 후보 문서를 (질문, 문서 본문) 쌍으로 구성
pairs = [
    (question, doc.page_content)
    for doc in candidates
]

# 한 번에 관련성 점수 계산
scores = cross_encoder.score(pairs)

score_rows = [
    {
        "source_id": doc.metadata["source_id"],
        "title": doc.metadata["title"],
        "score": float(score),
    }
    for doc, score in zip(candidates, scores)
]

# 높은 점수부터 확인
display(
    pd.DataFrame(score_rows)
    .sort_values("score", ascending=False)
)
```

### 결과

| source_id | 제목 | score |
| --- | --- | ---: |
| help03 | 호텔·카페 와이파이에서 VPN이 자주 끊길 때 | 10.5000 |
| help41 | 해외 출장 전 IT 준비 목록 | 6.8125 |
| help02 | 해외에서 사내 VPN 접속 신청하기 | 6.0625 |
| help06 | VPN은 연결됐는데 사내 시스템이 열리지 않을 때 | 1.6250 |
| help21 | 출장·교육용 노트북 단기 대여 | 0.9375 |
| help04 | 집에서 VPN 연결이 되지 않을 때 | 0.6250 |
| help38 | 방문객용 게스트 와이파이 | -0.3750 |

근거 문서 `help03`이 가장 높은 점수를 받음.

## 3. CrossEncoderReranker로 후보 재정렬

Cross Encoder 점수를 직접 계산하는 대신 `CrossEncoderReranker`를 사용해 후보를 재정렬하고 상위 3개만 남김.

```python
rerank_started = perf_counter()

reranker = CrossEncoderReranker(
    model=cross_encoder,
    top_n=3,
)

reranked = list(
    reranker.compress_documents(candidates, question)
)

rerank_seconds = perf_counter() - rerank_started

# 전후 순위 비교
display(
    pd.DataFrame(
        rank_rows(candidates, reranked),
        dtype=object,
    )
)

print(
    "근거 원문의 순위(리랭킹 전 상위 3개):",
    evidence_rank(initial_top, evidence_ids),
)
print(
    "근거 원문의 순위(리랭킹 후):",
    evidence_rank(reranked, evidence_ids),
)
print(f"재정렬 시간: {rerank_seconds:.1f}초 / 후보 {len(candidates)}개")
```

### 결과

| source_id | before_rank | after_rank |
| --- | ---: | ---: |
| help02 | 1 | 3 |
| help03 | 2 | 1 |
| help41 | 3 | 2 |
| help04 | 4 | None |
| help21 | 5 | None |
| help38 | 6 | None |
| help06 | 7 | None |

```text
근거 원문의 순위(리랭킹 전 상위 3개): 2
근거 원문의 순위(리랭킹 후): 1
재정렬 시간: 49.4초 / 후보 7개
```

리랭킹 결과:

```text
help03 → help41 → help02
```

## 4. 후보가 너무 적으면 리랭킹으로 복구할 수 없음

리랭커는 **전달받은 후보 안에서만** 순위를 다시 계산함.

```python
# BM25 상위 5개에서 근거 문서의 위치 확인
print(
    "BM25 상위 5개 안에서 근거 원문의 순위:",
    evidence_rank(bm25.invoke(question), evidence_ids),
)

# 후보를 상위 2개로 제한
narrow_bm25 = BM25Retriever.from_documents(
    documents,
    preprocess_func=kiwi_tokenize,
    k=2,
)

narrow_started = perf_counter()

narrow_candidates = narrow_bm25.invoke(question)

narrow_reranked = list(
    reranker.compress_documents(narrow_candidates, question)
)

narrow_seconds = perf_counter() - narrow_started
print(narrow_seconds, "초")
```

### 결과

```text
BM25 상위 5개 안에서 근거 원문의 순위: 3
12.642430400010198 초
```

근거 문서는 BM25 기준 3위인데 후보를 `k=2`로 제한했기 때문에 리랭커에 전달되지 않음.

```text
검색 단계에서 누락
    ↓
리랭커 입력 후보에 없음
    ↓
리랭킹으로도 복구 불가
```

## 5. ColBERT 방식으로 같은 후보 재정렬

질문과 문서를 토큰 단위 벡터로 변환한 뒤, 질문 토큰마다 가장 잘 맞는 문서 토큰을 이용해 점수를 계산.

```python
from FlagEmbedding import BGEM3FlagModel

# 토큰별 벡터만 사용
colbert_model = BGEM3FlagModel(
    "BAAI/bge-m3",
    devices="cpu",
    use_fp16=False,
    batch_size=2,
    query_max_length=1024,
    passage_max_length=1024,
    return_dense=False,
    return_sparse=False,
    return_colbert_vecs=True,
)

# 질문을 토큰별 벡터로 변환
query_vectors = colbert_model.encode_queries(
    [question]
)["colbert_vecs"][0]

# 후보 문서를 토큰별 벡터로 변환
document_vectors = colbert_model.encode_corpus(
    [doc.page_content for doc in candidates]
)["colbert_vecs"]

# 질문-문서 ColBERT 점수 계산
colbert_scores = [
    float(
        colbert_model.colbert_score(
            query_vectors,
            document_vector,
        )
    )
    for document_vector in document_vectors
]

# 높은 점수부터 정렬 후 상위 3개 선택
colbert_order = sorted(
    range(len(candidates)),
    key=lambda index: colbert_scores[index],
    reverse=True,
)

colbert_reranked = [
    candidates[index]
    for index in colbert_order[:3]
]

print(
    "질문 벡터 모양(토큰 수, 벡터 차원):",
    query_vectors.shape,
)

# Cross-Encoder와 비교
display(
    pd.DataFrame(
        [
            {
                "method": "Qwen Cross-Encoder",
                "source_ids": [
                    doc.metadata["source_id"]
                    for doc in reranked
                ],
                "evidence_rank": evidence_rank(
                    reranked,
                    evidence_ids,
                ),
            },
            {
                "method": "BGE-M3 ColBERT",
                "source_ids": [
                    doc.metadata["source_id"]
                    for doc in colbert_reranked
                ],
                "evidence_rank": evidence_rank(
                    colbert_reranked,
                    evidence_ids,
                ),
            },
        ],
        dtype=object,
    )
)
```

### 결과

```text
질문 벡터 모양(토큰 수, 벡터 차원): (30, 1024)
```

| method | source_ids | evidence_rank |
| --- | --- | ---: |
| Qwen Cross-Encoder | `[help03, help41, help02]` | 1 |
| BGE-M3 ColBERT | `[help03, help02, help41]` | 1 |

두 방식 모두 근거 문서 `help03`을 1위로 올림.

## 6. 검색과 리랭킹을 하나의 Retriever로 연결

`ContextualCompressionRetriever`를 사용해 **Hybrid 검색 → Cross Encoder 리랭킹**을 하나의 검색기로 연결.

```python
# 새 질문
new_question = (
    "회의실 TV에 노트북 화면이 안 나와요. "
    "무엇을 확인해야 하나요?"
)

# Hybrid 검색 결과를 Cross-Encoder로 리랭킹
ranked_retriever = ContextualCompressionRetriever(
    base_retriever=hybrid,
    base_compressor=reranker,
)

# 검색 + 리랭킹 실행
new_results = ranked_retriever.invoke(new_question)

print(
    "근거 원문의 순위:",
    evidence_rank(
        new_results,
        set(question_by_id["q07"]["evidence"]),
    ),
)

show_results(new_results)
```

### 결과

```text
근거 원문의 순위: 1
결과 문서 수: 3
```

| 순위 | source_id | 제목 |
| ---: | --- | --- |
| 1 | help34 | 회의실 화면에 노트북 연결하기 |
| 2 | help35 | 화상회의에서 소리가 들리지 않을 때 |
| 3 | help39 | 사내 와이파이에 업무용 노트북 연결하기 |

## 7. Qwen과 BGE Cross Encoder 비교

같은 Hybrid 검색 후보를 두 리랭커에 넣어 **근거 문서 순위와 처리 시간**을 비교.

```python
# 이후 사용하지 않는 ColBERT 모델 해제
colbert_model = None

# 평가 질문 q02~q06
check_questions = [
    row
    for row in questions
    if row["question_id"] in {
        "q02", "q03", "q04", "q05", "q06"
    }
]

# 같은 후보를 두 모델에 사용
check_candidates = hybrid.batch(
    [row["question"] for row in check_questions]
)

# BGE Cross Encoder
bge_encoder = HuggingFaceCrossEncoder(
    model_name="BAAI/bge-reranker-v2-m3",
    model_kwargs={
        "device": "cpu",
        "max_length": 1024,
    },
)

bge_reranker = CrossEncoderReranker(
    model=bge_encoder,
    top_n=3,
)

# 두 리랭커 비교
compare_rows = []

for row, found in zip(check_questions, check_candidates):
    evidence = set(row["evidence"])

    result = {
        "question_id": row["question_id"],
        "candidate_count": len(found),
        "no_rerank": evidence_rank(found[:3], evidence),
    }

    for name, model_reranker in {
        "qwen": reranker,
        "bge": bge_reranker,
    }.items():
        started = perf_counter()

        selected = list(
            model_reranker.compress_documents(
                found,
                row["question"],
            )
        )

        result[name] = evidence_rank(selected, evidence)
        result[name + "_seconds"] = round(
            perf_counter() - started,
            2,
        )

    compare_rows.append(result)

# 개별 질문 결과
display(pd.DataFrame(compare_rows, dtype=object))

# 근거가 1위인 질문 수
print(
    "근거가 1위인 질문 수:",
    {
        name: sum(row[name] == 1 for row in compare_rows)
        for name in ["no_rerank", "qwen", "bge"]
    },
)

# 질문당 평균 처리 시간
print(
    "질문당 평균 처리 시간(초):",
    {
        name: round(
            sum(
                row[name + "_seconds"]
                for row in compare_rows
            ) / len(compare_rows),
            2,
        )
        for name in ["qwen", "bge"]
    },
)
```

### 결과

| question_id | 후보 수 | 리랭킹 없음 | Qwen | Qwen 시간(초) | BGE | BGE 시간(초) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| q02 | 7 | 2 | 1 | 44.17 | 1 | 2.80 |
| q03 | 6 | 3 | 1 | 39.82 | 1 | 2.66 |
| q04 | 7 | 2 | 1 | 46.32 | 1 | 2.80 |
| q05 | 8 | 1 | 1 | 52.08 | 1 | 3.04 |
| q06 | 8 | 1 | 1 | 80.36 | 1 | 3.46 |

```text
근거가 1위인 질문 수:
{'no_rerank': 2, 'qwen': 5, 'bge': 5}

질문당 평균 처리 시간(초):
{'qwen': 52.55, 'bge': 2.95}
```

## 핵심 정리

- 리랭커는 검색된 **후보 내부의 순위만 재조정**함.
- 후보 검색 단계에서 근거 문서가 빠지면 리랭킹으로 복구할 수 없음.
- Cross Encoder와 ColBERT 모두 예제에서 근거 문서를 1위로 재정렬함.
- `ContextualCompressionRetriever`로 검색과 리랭킹을 하나의 Retriever처럼 연결 가능.
- q02~q06 비교에서 리랭킹 전에는 5개 중 2개만 근거가 1위였고, Qwen/BGE 리랭커는 모두 5개를 1위로 올림.
- 해당 실행 결과에서는 평균 처리 시간이 Qwen `52.55초`, BGE `2.95초`로 기록됨.
